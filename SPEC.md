# Полное исправление проблем Starframe Abyss

## Контекст
Репозиторий находится на базовом commit `285c90f` с чистой веткой `main`. Требуется исправить подтверждённые дефекты безопасности, стабильности и корректности терминального браузера на Go, сохранив HTML → DOM → CSS → Layout → Framebuffer → ANSI → Bubble Tea и JavaScriptCore на macOS. Перечень областей и обязательных сценариев задан handoff пользователя.

## Цель
Последовательно улучшить безопасность вывода терминала, ограничить потребление ресурсов и обеспечить автономность бинарника; затем исправить жизненный цикл вкладок, JS, рендеринг и инфраструктуру. Каждое исправление подтверждается детерминированными регрессионными тестами; результаты, непроверенные пункты и ограничения отражаются в итоговом отчёте.

## Что изменится
Изменения будут ограничены относящимися к подтверждённым дефектам компонентами `internal/{js,ascii,browser,fetcher,framebuffer,asciirender}`, тестами и фикстурами, `go.mod`, конфигурацией CueTTY/CI, `.gitignore`, README/инструкциями, benchmarks и этим документом. Точный перечень файлов будет уточняться после аудита реализации. Пользовательские и генерируемые данные не удаляются без анализа.

## Детали реализации
Работать этапами, каждый — воспроизведение тестом, исправление первопричины, целевые и общие проверки, отдельный логический commit:

1. **A — P0:** исследовать пути недоверенного терминального вывода; разрешать только контролируемые SGR от рендерера и безопасно выводить текст/ошибки. Ввести проверяемые лимиты сетевых ответов, изображений после декодирования, DOM-узлов/глубины, CSS-значений/repeat, framebuffer с проверками переполнения, кэш изображений, контексты отмены и ограниченный параллелизм. Встроить JS-ресурсы через `go:embed`.
2. **B — Lifecycle:** исследовать владение JSC/cgo и повторные callback-вызовы до выбора синхронизации. Обеспечить изоляцию состояния вкладок, корректную очистку контекстов/callbacks/timers, идентификацию и отмену устаревших запросов, остановку фоновых процессов и защиту от дублирующихся ticks. Ограничение JS-исполнения реализовать безопасно либо зафиксировать обоснованное ограничение, если JSC не предоставляет безопасного прерывания.
3. **C — Correctness:** добавить тесты и исправить подтверждённые ошибки HTML recovery/fragments, CSS cascade/inheritance/Grid/Flex/media/supports, layout/координат/Unicode, изображений и перерисовки без потери состояния.
4. **D — Performance:** снять воспроизводимые baseline и benchmarks для DOM/CSS/Layout/Rendering/ANSI; менять только подтверждённые горячие пути и сравнивать время и аллокации.
5. **E — Release:** привести module path к `github.com/starframe-dev/abyss`, убрать абсолютные пути CueTTY, настроить macOS CI и проверки, проверить игнорирование генерируемых файлов, обновить документацию и headless-ограничения; выполнить полный аудит и записать результаты.

Для тестов использовать локальные HTTP-серверы и детерминированные фикстуры. Не отключать проверки, не подменять реализации заглушками, не заявлять об успешности непроведённых проверок. Не менять или удалять пользовательские данные без анализа.

## Текущий статус (не считать готовым к релизу)

Официальные Go 1.26.2 (версия из `go.mod` и CI) и Go 1.27.2 arm64 toolchains временно установлены в `/tmp` и проверены по SHA-256. На Go 1.26.2 прошли `go build`, uncached `go test ./...`, uncached `go test -race ./...` и `go vet ./...`; на Go 1.27.2 также пройдены uncached тесты, race и vet. Изменённые Go-файлы отформатированы. После обновления `golang.org/x/net` до v0.60.0 `govulncheck -mode=source ./...` сообщил ноль уязвимостей. `InitDOM` и закрытие текущего JSC-контекста теперь сбрасывают карты DOM/styles/layout старой страницы; при закрытии вкладки освобождается принадлежащий ей текущий JSC-контекст; добавлены lifecycle-регрессии. Добавлен ограниченный `dom.ParseFragment`; `innerHTML`, `outerHTML` и `insertAdjacentHTML` используют непосредственные fragment children, включая текст, вместо синтетического wrapper; `getElementById` ищет только подключённые узлы и сохраняет возможность повторно вставить detached node по его NodeID. Image `Quantize` теперь отклоняет исходники сверх лимита пикселей до sampling; изменение ширины viewport инициирует повторный CSS/layout/render pass. Это не реализует независимые контексты для каждой вкладки. CSS cascade теперь учитывает `!important`, inline priority и source order; CSS custom properties разрешаются независимо от порядка объявления, `var()` циклы/глубина ограничены, а вложенность at-rules ограничена 32 уровнями, чтобы исключить переполнение стека на враждебном CSS. `@media` поддерживает `screen` и `min-width`/`max-width` в CSS px с фактической шириной viewport, включая `media` атрибуты `<style>` и `<link>`; неизвестные media features и неподдержанные nested at-rules (`@container`, `@layer`) не применяются безусловно; базовые `@supports` проверки ограничены `display` и `position`. Специфичность учитывает тип перед pseudo/attribute selector и pseudo-elements; пустое `{}` CSS правило игнорируется. Invalid HEX теперь не становится чёрным цветом, а `BoxModel.IsZero` различает нулевые px от auto/percent/fr. Дополнительный `go test -tags legacy ./internal/css` остаётся красным только из-за legacy-ожиданий specificity (например, `div.class1.class2` ожидает 12 вместо CSS-взвешенного 21) и одно-десятичных строк Length при текущей сериализации до двух знаков; обычный CI не включает эти build-tagged тесты. Headless-бинарник успешно запущен из временного каталога вне исходного дерева на локальном fixture. Первый тестовый прогон выявил и помог исправить утечку raw C1 CSI параметров как текста. CueTTY E2E один раз не получил введённый URL; тест теперь проверяет адресное поле, ждёт перехода в `Loading` и повторяет ввод/submit при оставшемся address mode; 10 последовательных запусков предыдущей версии helper и 5 повторов текущей версии прошли. Измерен baseline и подтверждена ANSI-оптимизация: около 39.3% быстрее, на 40.2% меньше байтов и на 97.3% меньше аллокаций на fixture. Это не полная приёмка: JavaScriptCore-контекст остаётся общим для вкладок, бесконечный синхронный JS не прерывается. В установленном публичном `JSContextRef.h` просмотрены доступные C API; execution-time-limit/termination API не обнаружен, а освобождать контекст во время синхронного вызова небезопасно. Grid `fr` распределяется при явной высоте; auto-height строки имеют регрессию intrinsic sizing, но полная CSS Grid track sizing semantics не реализована. Flexbox и Unicode также покрыты не полностью. Commits `fd3c865` (Graphloom cleanup), `85fe243` (macOS CI/документация), `134f537` (CSS cascade и bounded `var()`), `db829d8` (статус отчёта) и `4204a29` (security/lifecycle/CSS/layout regressions и gofmt), `7d3586d` (ограничение входа image quantizer) и `37bb19d` (HTML fragments и connected ID lookup) и `eaf531a` (rerender при resize и устойчивый CueTTY E2E) фиксируют основные результаты этапов. 357 Graphloom-файлов сохранены на диске; рабочее дерево после commit чистое. Все локальные CI-equivalent проверки прошли, но GitHub Actions удалённо не запускался; перед релизом нужны code review, закрытие оставшихся рисков и проверка workflow в GitHub.

## Текущий benchmark baseline

Измерено 2026-10-14 на Go 1.27.2, darwin/arm64, Apple M4, `go test -bench . -benchmem -count=3`:

| Benchmark | ns/op (3 runs) | B/op | allocs/op |
|---|---:|---:|---:|
| DOM Parse | 22608 / 22619 / 22610 | 39776 | 33 |
| CSS Compute | 3820 / 3834 / 3869 | 13176 | 98 |
| Layout Build | 55850 / 56214 / 56909 | 198521–198522 | 613 |
| ANSI Conversion | 1309265 / 1319408 / 1341671 | 2401866–2401867 | 39206 |

Это baseline текущего дерева до дальнейших оптимизаций, не сравнение с исходным commit. Для ANSI conversion в искусственном 120×80 цветном grid fixture измерены высокая стоимость и 39 206 аллокаций. После замены промежуточной сборки строк цветов на прямую запись RGB-параметров в builder три запуска дали 802859 / 803036 / 803750 ns/op, 1 437 385–1 437 389 B/op и 1 046 allocs/op: среднее время улучшилось на 39.3%, bytes/op на 40.2%, allocations/op на 97.3%. `TestWriteANSIColorFormatsChannelsAndCombinedColors` проверяет точную последовательность RGB-байтов; после оптимизации повторно прошли полный `go test ./...`, `go test -race ./...` и `go vet ./...`.

- [x] Сетевые загрузки отменяемы; параллелизм и кэш ресурсов ограничены.
- [x] JS-ресурсы встроены; бинарник проверен запуском из каталога вне исходного дерева.
