# Спецификация: analyze_habr

## Назначение

`cmd/analyze_habr/main.go` — CLI-утилита, которая загружает `https://habr.com`, разбирает HTML с помощью `internal/dom` и печатает сведения о стилях, тегах и тексте страницы.

## Поведение

1. Вызывает `fetcher.Fetch("https://habr.com")`.
2. Если fetch завершается ошибкой, печатает `Fetch error: <ошибка>` в stderr и завершает процесс с кодом 1.
3. Разбирает полученный HTML вызовом `dom.Parse`.
4. Печатает количество найденных селектором `link[rel=stylesheet]` элементов, затем их `href`. Значения `href` длиннее 100 байт обрезаются до первых 100 байт с добавлением `...`.
5. Печатает количество элементов `style`, затем текст каждого. Текст длиннее 500 байт обрезается до первых 500 байт с добавлением `...`.
6. Рекурсивно обходит DOM от корневого узла. Считает элементы по `TagName`; уникальные имена тегов выводятся в порядке первого появления, с количеством каждого.
7. Если найден хотя бы один `body`, берёт текст первого, удаляет пробелы по краям через `strings.TrimSpace`, обрезает его до первых 2000 байт с `...`, если длиннее, и печатает. В заголовке указывается длина исходного `TextContent()` первого `body` в байтах.

Порядок вывода: внешние стили, встроенные стили, статистика тегов, текст `body` (если он найден). Для операций с DOM отдельная обработка ошибок не предусмотрена.

## Зависимости и реализация

Используются `github.com/starframe-dev/abyss/internal/dom` и `github.com/starframe-dev/abyss/internal/fetcher`. Программа не принимает аргументы и не использует глобальное состояние. `main` не имеет параметров и возвращаемого значения.
