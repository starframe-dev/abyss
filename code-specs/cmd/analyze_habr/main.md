# Specification: analyze_habr

## Overview

`cmd/analyze_habr/main.go` — CLI-утилита для анализа содержимого веб-страницы `habr.com`. Приложение fetch-ит HTML-документ, парсит его с помощью модуля `internal/dom`, и выводит на stdout информацию о стилях, тегах и тексте страницы (ошибки — на stderr).

## Public API

### `main()`

Экспортная функция `main()` — точка входа в приложение.

**Поведение:**

1. Fetch-ит HTML из `https://habr.com`.
2. Парсит полученный HTML в DOM-дерево.
3. Анализирует DOM и выводит статистику:
   - Внешние CSS-стили (теги `<link rel="stylesheet">`)
   - Инлайн-стили (теги `<style>`)
   - Список всех используемых HTML-тегов с количеством вхождений
   - Текст тега `<body>` (обрезанный до 2000 символов)
4. При ошибке fetch-а выводит сообщение на stderr и завершает код 1.

**Обратная совместимость:** Функция `main()` не имеет параметров и не возвращает значения. Изменения возможны только внутри (без изменения сигнатуры).

## Types

### `main`

Пакет `main` — исполняемый файл CLI-утилиты.

**Зависимости:**
- `github.com/starframe-dev/abyss/internal/dom` — парсинг HTML
- `github.com/starframe-dev/abyss/internal/fetcher` — сетевой fetch

**State:** Приложение не использует глобальное состояние. Все данные локальны к `main()`.

## Behavior Details

### Fetch

```
fetcher.Fetch(url string) -> (string, error)
```

- Возвращает HTML-строку или ошибку.
- При ошибке приложение завершает с кодом 1 и выводом `Fetch error: %v` на stderr.

### Parse

```
dom.Parse(html string) -> *dom.Node
```

- Конвертирует HTML-строку в DOM-дерево.
- Возвращает корневой узел — `*dom.Node` с `Type == DocumentNode`.
- Используется для последующих запросов к элементам.

### Query

```
doc.QueryAll(selector string) -> []*dom.Node
```

- Возвращает срез всех элементов, соответствующих селектору CSS.
- Поддерживаются простые селекторы: теги, атрибуты.

### Node

```
*dom.Node
```

**Методы:**
- `GetAttr(name string) string` — возвращает значение атрибута.
- `TextContent() string` — возвращает текст узла и потомков.
- `QueryAll(selector string) []*Node` — все потомки, соответствующие селектору.

**Поля:**
- `Type` — тип узла (ElementNode, TextNode, DocumentNode и т.д.)
- `TagName` — имя тега для элементов
- `Attributes` — атрибуты элемента (map[string]string)
- `Children` — срез дочерних узлов
- `Text` — текстовое содержимое текстового узла
- `Parent` — родительский узел

## Constraints

1. **URL:** Зафиксирован `https://habr.com`. Изменения возможны только если явно указано в спецификации.
2. **Тренировка вывода:**
   - URL стилей обрезается до 100 символов с троеточием, если >100.
   - Текст стилей обрезается до 500 символов с троеточием.
   - Текст body обрезается до 2000 символов с троеточием.
3. **Порядок вывода:**
   - Сначала внешние стили.
   - Затем инлайн-стили.
   - Затем список тегов.
   - Наконец, текст body.
4. **Ошибки:** Все ошибки выводятся на stderr. Код завершения — 0 для успеха, 1 для ошибок.

## Implementation Notes

### Fetcher

- Использует `fetcher.Fetch()` для HTTP-запросов.
- Детали реализации (таймауты, ретраи) не указаны — следует использовать как есть.

### DOM Parser

- Использует `dom.Parse()`.
- Поддерживает CSS-селекторы для поиска элементов.

### Walking DOM

```
walk(n *dom.Node)
```

- Рекурсивная функция для обхода DOM-дерева.
- Считает количество каждого тега.
- Используется для статистики тегов.

### String Truncation

- URL: `>100` → обрезается до 100 + `...`
- Style текст: `>500` → обрезается до 500 + `...`
- Body текст: `>2000` → обрезается до 2000 + `...`

## Errors

Все ошибки от `fetcher.Fetch()` обрабатываются в `main()`:

```go
if err != nil {
    fmt.Fprintf(os.Stderr, "Fetch error: %v\n", err)
    os.Exit(1)
}
```

- Ошибки парсинга и DOM-операций — не обрабатываются явно (предполагается, что `dom.Parse` возвращает `nil` при успехе и может паниковать при критических ошибках).
