# Спецификация: cmd/cuetty_test/main.go

## Назначение

Файл содержит тестовый клиент библиотеки `cue-tty`, который запускает `./bin/abyss` в PTY, вводит `example.com`, выводит содержимое экрана и хвост сырого лога, затем отправляет `q`.

## Поток выполнения

1. Вызывает `cue.Launch("./bin/abyss", ...)` с размером терминала 200x60, рабочей директорией `.` и переменной окружения `TERM=xterm-256color`.
2. При ошибке запуска печатает `Launch error: <ошибка>` и завершает `main`; иначе откладывает `app.Close()`.
3. Получает страницу через `app.Page()` и ждёт одну секунду.
4. Вводит `example.com`, ждёт 200 мс и отправляет клавишу `Enter`.
5. Ждёт пять секунд.
6. Получает `page.Lines()`, игнорируя ошибку. Печатает заголовок с количеством строк и размером 200x60. Для каждой строки удаляет конечные пробелы; пустую печатает как `[%2d] (empty)`, непустую — как `[%2d] %q`.
7. Получает `app.RawLog()` и печатает не более последних 2000 байт. ESC отображается как `\\033`, LF — как `\\n` с последующим переводом строки, CR пропускается, печатные ASCII-байты печатаются напрямую, остальные — как `\\xNN`. В конце печатает перевод строки.
8. Отправляет `q` и ждёт 200 мс; отложенный `app.Close()` завершает приложение.

Ошибки вызовов `page.Type`, `page.Press` и `page.Lines` игнорируются. Эта спецификация описывает только поведение данного `main.go` и не перечисляет API и внутреннее устройство библиотеки.
