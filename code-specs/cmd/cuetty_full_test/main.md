# Спецификация `cmd/cuetty_full_test/main.go`

## Назначение

Интеграционная программа запускает `./bin/abyss` через библиотеку `cue-tty` и последовательно проверяет начальный экран, загрузку `example.com`, прокрутку, обновление, страницу ошибки и завершение приложения.

## Поток выполнения

1. Запускает приложение с размером терминала 120×40, рабочей директорией `.` и окружением `TERM=xterm-256color`. При ошибке запуска печатает `FAIL: launch: ...` в stderr и завершает процесс с кодом 1. Для приложения регистрируется отложенный `Close()`.
2. Получает страницу приложения, ждёт стабильности 2 секунды, считывает и печатает её текст с длиной. Проверяет наличие `Abyss` и `Enter URL`; при ошибках проверки печатает соответствующее сообщение `FAIL:` в stderr и завершает процесс с кодом 1. Ошибка `Page.Text()` игнорируется.
3. Вводит `example.com`, ждёт стабильности 300 мс, нажимает Enter, ожидает `Example Domain` до 15 секунд, считывает и печатает экран. Затем проверяет наличие `Example Domain` и завершает с ошибкой при неудаче. Ошибка `Page.Text()` игнорируется.
4. Сохраняет текущий текст (ошибка чтения игнорируется), восемь раз нажимает Down, ждёт стабильности 300 мс и снова считывает текст. Если строки равны, сообщает об ошибке прокрутки и завершает процесс с кодом 1.
5. Нажимает `r`, ждёт стабильности 2 секунды, считывает и печатает экран, проверяет наличие `Example Domain`; ошибка чтения текста игнорируется.
6. Нажимает Escape, ждёт 200 мс, вводит `not-a-valid-url-12345.xyz`, ждёт 100 мс, нажимает Enter и ожидает `Error:` до 10 секунд. Проверяет наличие `Error:`; при неудаче завершает процесс с кодом 1.
7. Нажимает `q`, ждёт 500 мс и явно вызывает `app.Close()`. Если закрытие возвращает ошибку, печатает `FAIL: exit error: ...` и завершает процесс с кодом 1. При успехе печатает `PASS: Clean exit` и `✅ ALL TESTS PASSED`.

Каждая успешная проверка сопровождается соответствующим сообщением `PASS:`. Ошибки ожидания в `WaitFor` явно не проверяются: их поведение не описывается как возвращающее результат, а наличие текста затем проверяется отдельно через `cue.Expect(page).ToContain(...)`.

## Используемый API

Файл использует `cue.Launch`, опции `cue.WithSize`, `cue.WithDir`, `cue.WithEnv`, а также методы приложения и страницы `Close`, `Page`, `WaitStable`, `Text`, `Type`, `Press`, `WaitFor` и проверку `cue.Expect(page).ToContain(text)`. Зависимости и детали внутренней реализации этих API в данном файле не определяются.
