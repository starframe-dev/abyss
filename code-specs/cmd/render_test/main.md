# Спецификация `cmd/render_test/main.go`

## Назначение

Вспомогательная программа разработки для получения HTML по URL, построения DOM/CSS/layout и рендеринга страницы в ANSI-арт. Результаты записываются во временные файлы, а непустые строки текстового представления дополнительно выводятся в stdout. Это не библиотечный пакет и не предназначено для пользовательского production-интерфейса.

## Интерфейс запуска

Запуск: `render_test <url> [width]`.

- Отсутствие URL: печатает в stderr `usage: render_test <url>` и завершает процесс с кодом 2.
- URL берётся из `os.Args[1]`.
- Ширина по умолчанию — 120. Если передан аргумент ширины, он читается через `fmt.Sscanf` с форматом `%d`; ошибка разбора игнорируется, поэтому при неудаче сохраняется прежнее значение (либо частично разобранное значение согласно поведению `Sscanf`). Проверки положительности и диапазона нет.
- Ошибка `fetcher.Fetch` печатается в stderr с префиксом `fetch error:`; процесс завершается с кодом 1.
- Ошибки записи файлов намеренно игнорируются.

## Последовательность обработки

1. Сбрасывает глобальный кэш изображений в пустую map под эксклюзивной блокировкой.
2. Устанавливает `render.ImageProvider`: функция ищет изображение по точной строке `src` в кэше под `RLock`, возвращая `nil`, если записи нет.
3. Получает HTML через `fetcher.Fetch(url)` и разбирает его посредством `dom.Parse`.
4. Извлекает и загружает ресурсы изображений функцией `fetchImages`.
5. Вычисляет стили через `css.Compute`, строит дерево layout через `layout.Build` с шириной в `float64`, выполняет `render.Render`, затем формирует ANSI-строки посредством `ascii.RenderANSI`.
6. Объединяет строки ANSI, добавляя перевод строки после каждой, и записывает результат в `/tmp/img_fixture_ansi.txt` с режимом `0644`.
7. Удаляет ANSI-последовательности, обрезает конечные пробелы каждой строки и сохраняет текст в `/tmp/img_fixture_plain.txt`, также добавляя перевод строки после каждой строки.
8. Печатает сообщение о путях файлов, затем заголовок `non-empty plain lines:` и строки, не состоящие только из пробельных символов. Нумерация начинается с нуля; номер форматируется как минимум двумя символами.

## Функции и типы

Все функции и переменные имеют package scope пакета `main`; экспортируемого API нет.

- `main()` — выполняет описанный процесс, управляет кодами завершения и выводом.
- `stripANSI(s string) string` — побайтово удаляет распознаваемые ANSI SGR-последовательности вида ESC `[` цифры/точки с запятой `m`. Для ESC, за которым не следует `[`, ESC и следующий байт пропускаются. Последовательности с неподдерживаемым окончанием обрабатываются побайтовым алгоритмом функции; это не универсальный ANSI-парсер.
- `fetchImages(doc *dom.Node, baseURL string)` — находит узлы `img`, читает атрибут `src`, удаляет внешние пробелы, игнорирует пустые значения и дедуплицирует источники. Data URL оставляет без изменений; прочие значения передаёт в `resolveURL`. PNG data URL с точным префиксом `data:image/png;base64,` декодируется локально. Остальные источники загружаются через `fetcher.FetchBytes`, затем декодируются через `asciirender.Decode`. Ошибки и пустые ответы пропускаются; успешно декодированные изображения сохраняются в кэш под исходным разрешённым URL.
- `resolveURL(base, rel string) string` — возвращает абсолютные `http://` и `https://` URL без изменений; путь с начальным `/` конкатенирует с `base`; любой другой относительный путь возвращает сам `base` (не выполняет полноценного разрешения URL).
- `decodeBase64PNG(b64 string) (image.Image, error)` — декодирует строку стандартным Base64-кодеком, затем передаёт байты `asciirender.Decode`.
- `decodeBase64(s string) ([]byte, error)` — тонкая обёртка над `base64.StdEncoding.DecodeString`.

Публичных объявлений (с заглавной буквы) и собственных типов в файле нет. Используемые типы: `image.Image` и `*dom.Node`.

## Состояние и синхронизация

`imageCache` — глобальная map `map[string]image.Image`, а `imageCacheMu` — `sync.RWMutex`, защищающий чтение и запись кэша. Кэш сбрасывается при запуске `main`. Глобальный `render.ImageProvider` заменяется на функцию доступа к этому кэшу. Код предполагает, что изменяемый провайдер и кэш используются в рамках этого запуска; прочие глобальные эффекты библиотеки файлом не контролируются.

## Важные ограничения

- Разрешение относительных URL намеренно упрощено и может некорректно обрабатывать URL без завершающего `/`, `../`, query-компоненты и другие формы ссылок.
- Загружаются только обнаруженные элементы `img`; ошибки загрузки/декодирования не сообщаются вызывающему коду.
- Пути выходных файлов фиксированы в `/tmp`, поэтому последующие запуски перезаписывают результаты.
- Ширина напрямую передаётся подсистемам layout и render без валидации.
