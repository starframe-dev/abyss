# Спецификация: `cmd/debug_render/main.go`

## Обзор

Командная утилита загружает страницу `https://example.com`, выполняет подготовку DOM и JavaScript, рендерит страницу в строки ASCII и сохраняет полную и сокращённую версии в `/tmp`.

## Зависимости

Используются пакеты `internal/ascii`, `internal/css`, `internal/dom`, `internal/fetcher`, `internal/js`, `internal/layout` и `internal/render`, а также стандартные пакеты `fmt`, `os` и `strings`.

## `main()`

1. Вызывает `fetcher.Fetch("https://example.com")`. При ошибке печатает `Fetch error: ...` в stderr и завершает процесс кодом 1.
2. Передаёт полученный HTML в `dom.Parse`.
3. Создаёт JS-контекст через `js.NewContext()` и откладывает `Close()` до выхода из функции (ошибка закрытия игнорируется).
4. Вызывает `js.InitDOM(doc)`; возвращаемого значения нет.
5. Регистрирует bridge-функции. При ошибке выводит `Bridge error: ...` в stderr и завершает процесс с кодом 1.
6. Выполняет `js.DOMAPIScript()` через `jsc.Evaluate`. При ошибке выводит `DOM API error: ...` в stderr и завершает процесс с кодом 1.
7. Вызывает `js.ExecuteScripts(jsc, doc, url)`. При ошибке печатает `Script exec error: ...` в stdout и продолжает работу.
8. Получает DOM через `js.GetFinalDOM()`, вычисляет CSS через `css.Compute`, строит макет шириной 800, рендерит его шириной 800 и получает строки через `ascii.Render`.
9. Записывает строки, соединённые символом `\n` без добавления завершающего перевода строки, в `/tmp/abyss_full_ansi.txt`. ANSI-последовательности сохраняются.
10. Для каждой строки формирует короткую версию: удаляет ANSI-коды функцией `stripANSI`, обрезает байтовую строку до 120 байт, если она длиннее, затем удаляет конечные ASCII-пробелы через `strings.TrimRight(clean, " ")`. Записывает строки, соединённые `\n`, в `/tmp/abyss_short_ansi.txt`.
11. Игнорирует ошибки обоих вызовов `os.WriteFile` (права доступа файла — `0644`). Печатает сообщение о сохранённых файлах и их описаниях в stdout.
12. Считает непустыми строки короткой версии, для которых `strings.TrimSpace` не пуст, и выводит количество в формате `Non-empty lines: N out of M`. Затем выводит каждую такую строку с нулевым индексом в формате `  [%2d] %s`.

## `stripANSI(s string) string`

Посимвольно обходит строку. Обычные байты добавляются в результат. При байте ESC (`\033`) пропускает его и проверяет следующий байт: если это `[`, пропускает последующие цифры и `;`, а затем, если встречен `m`, также пропускает его. Если формат не соответствует ожидаемой последовательности, обработка продолжается согласно фактической позиции цикла; произвольные ANSI-последовательности функция не разбирает. Возвращает собранную строку.

## Примечания

- Ширина рендеринга фиксирована и равна 800.
- Обрезание до 120 выполняется по байтам, а не по Unicode-символам, и может разорвать многобайтовый символ.
- Короткие строки очищаются от ANSI, полные — нет.
- Ошибки выполнения пользовательских скриптов не останавливают рендеринг; ошибки загрузки, регистрации моста и DOM API завершают процесс.
