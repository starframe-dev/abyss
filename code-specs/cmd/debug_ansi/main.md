# Спецификация: cmd/debug_ansi/main.go

## Назначение
Утилита отладки вывода TUI-приложения Abyss. Запускает приложение через cue-tty, удаляет распознаваемые ANSI-секвенции из лога и проверяет наличие ожидаемых строк.

## Функции

### `stripANSI(s string) string`
Удаляет из строки совпадения с регулярным выражением `\033\[[0-9;]*[a-zA-Z]`. Это ограниченный шаблон ANSI-секвенций, а не обработчик всех возможных ANSI-кодов.

### `min(a, b int) int`
Возвращает меньшее из двух целых чисел. Используется для ограничения объёма печатаемого текста.

### `main()`
1. Запускает `./bin/abyss` через `cue.Launch` с размером терминала 120x40, рабочим каталогом `.` и переменной `TERM=xterm-256color`.
2. При ошибке запуска печатает `FAIL: launch: ...` в stderr и завершает процесс с кодом 1. При успешном запуске откладывает `app.Close()`.
3. Получает страницу, ждёт стабилизации 2 секунды, вызывает `page.Text()` (ошибку игнорирует) и печатает длину и первые не более 500 символов текста.
4. Получает `app.RawLog()`, удаляет совпадения ANSI-регулярного выражения и печатает длину и первые не более 500 символов очищенного лога.
5. Проверяет очищенный лог на подстроки `Abyss` и `Enter URL`, печатая для каждой проверки сообщение `OK` либо `FAIL`. Эти проверки не завершают программу с ошибкой.
6. Вводит `example.com`, ждёт стабилизации 300 мс и нажимает Enter. До 15 секунд повторно читает и очищает сырой лог, проверяя наличие `Example Domain`; между проверками спит 200 мс. По результату печатает `OK` либо `FAIL`, не устанавливая код завершения в зависимости от результата.
7. Нажимает `q` и ждёт стабилизации 500 мс. После выхода из `main` отложенный вызов закрывает приложение.

## Зависимости
Используются `bytes`, `fmt`, `os`, `regexp`, `time` из стандартной библиотеки и `github.com/starframe-dev/cue-tty/pkg/cue`.

## Ввод и побочные эффекты
Предполагается, что доступен исполняемый файл `./bin/abyss` относительно текущего рабочего каталога процесса. Программа взаимодействует с TUI через cue-tty и выводит диагностические сообщения в stdout, а ошибку запуска — в stderr. Функция `page.Text()` возвращает текст и ошибку, но ошибка в этой программе игнорируется.
