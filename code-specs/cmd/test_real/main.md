# Спецификация: cmd/test_real/main.go

## Обзор

Файл содержит точку входа утилиты, которая последовательно загружает две заданные веб-страницы, выполняет доступную цепочку обработки HTML, JavaScript, CSS, макета и ASCII-рендеринга, а затем печатает статистику и часть результата.

## `main()`

Функция не принимает аргументов и не возвращает значения. Обрабатывает URL `https://en.wikipedia.org/wiki/ASCII_art` и `https://news.ycombinator.com` в указанном порядке. Для каждого URL:

1. Запоминает время начала и вызывает `fetcher.Fetch(url)`. При ошибке печатает сообщение `FETCH ERROR` с URL и ошибкой и переходит к следующему URL.
2. После успешной загрузки фиксирует время fetch, разбирает HTML посредством `dom.Parse` и фиксирует время от начала обработки как время parse.
3. Создает JS-контекст, инициализирует DOM, регистрирует bridge-функции, вычисляет и выполняет скрипт DOM API, затем выполняет скрипты документа с исходным URL. Закрывает контекст.
4. Получает итоговый DOM через `js.GetFinalDOM`, вычисляет стили, строит макет шириной 800, выполняет рендеринг и преобразует результат в ASCII при ширине 800.
5. Фиксирует общее время, считает общее число строк и число строк, непустых после `strings.TrimSpace`.
6. Печатает заголовок URL, размер HTML в байтах, времена Fetch/Parse/Total, оба счетчика строк и до 20 первых непустых строк. Перед выводом строки удаляются только завершающие пробелы через `strings.TrimRight(line, " ")`; индекс в выводе соответствует исходному индексу строки. После каждого успешно обработанного URL печатает пустую строку.

Ошибки, возвращаемые зависимыми функциями парсинга/JS/рендеринга, в этой функции отдельно не обрабатываются (вызовы не возвращают проверяемые ошибки). Ошибка загрузки не прекращает обработку последующих URL.

## Зависимости

Используются пакеты `fmt`, `strings`, `time` и внутренние пакеты `ascii`, `css`, `dom`, `fetcher`, `js`, `layout`, `render` из `github.com/starframe-dev/abyss`.

## Ограничения и побочные эффекты

Ширина макета и ASCII-рендера фиксирована на 800. Вывод осуществляется в stdout. URL и предел вывода (20 непустых строк на документ) заданы в коде; аргументы командной строки не читаются.
