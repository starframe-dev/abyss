# Спецификация `internal/browser/headless_dump.go`

## Назначение

Файл предоставляет режим без графического TUI для загрузки веб-страницы и сохранения результата полного конвейера рендеринга в виде ANSI-арта. Основное назначение — детерминированные end-to-end проверки, которым не требуется запускать TUI или PTY.

## Публичный API

### `HeadlessDump(pageURL string, width int, outputPath string)`

Загружает страницу по `pageURL`, обрабатывает её тем же основным конвейером отображения, что и `loadPage`, и записывает сформированное представление в `outputPath`.

- `pageURL` — адрес страницы, передаваемый загрузчику.
- `width` — ширина результата в символьных ячейках. Для CSS-вычислений и layout она переводится в пиксели умножением на `cellmetrics.WidthPx`.
- `outputPath` — путь файла для результата.
- Функция не возвращает значение или ошибку. При ошибке загрузки либо записи она печатает сообщение в stderr и завершает весь процесс кодом `1` через `os.Exit`.

## Последовательность выполнения

1. Сбрасывает кэш изображений вызовом `resetImageCache()`.
2. Устанавливает `render.ImageProvider` в `cachedImage`, чтобы конвейер рендеринга использовал кэшируемого поставщика изображений.
3. Загружает HTML через `fetcher.Fetch(pageURL)`. При ошибке пишет в stderr `headless dump: fetch: <ошибка>` и завершает процесс с кодом `1`.
4. Разбирает HTML в DOM с помощью `dom.Parse`.
5. Загружает изображения документа вызовом `fetchImages(doc, pageURL)`.
6. Вычисляет стили с внешними CSS: `css.ComputeWithExternalAtWidth(doc, fetchExternalCSS(doc, pageURL), float64(width*cellmetrics.WidthPx))`.
7. Строит layout через `layout.Build`, передавая DOM, стили и ту же ширину в пикселях.
8. Рендерит layout через `render.Render` с шириной `width*cellmetrics.WidthPx`.
9. Преобразует буфер кадров в строки ANSI через `ascii.RenderANSI(fb, box, width)`.
10. Объединяет строки символом перевода строки (`\n`) без дополнительного завершающего перевода строки.
11. Записывает байты полученной строки в `outputPath` с правами файла `0o644`. При ошибке пишет `headless dump: write: <ошибка>` в stderr и завершает процесс с кодом `1`.
12. При успешной записи выводит в stderr сообщение `headless dump: <число байт> bytes -> <путь>`; число байт — длина строки dump в байтах.

## Побочные эффекты и границы

- Выполняются сетевые/ресурсные операции через загрузчик страницы, `fetchImages` и `fetchExternalCSS`.
- Функция изменяет глобальное состояние `render.ImageProvider` и очищает кэш изображений перед обработкой. Восстановление прежнего поставщика после выполнения не производится.
- Результат записывается на диск; существующий файл по `outputPath` перезаписывается согласно поведению `os.WriteFile`.
- Ошибки загрузки и записи не представлены как возвращаемые значения: оба случая приводят к `os.Exit(1)`, что завершает вызывающий процесс.
- В коде нет явной проверки диапазона или положительности `width`; значение используется непосредственно в умножении и далее передаётся этапам конвейера.
- TUI не запускается.

## Зависимости

Используются пакеты `fmt`, `os`, `strings` и внутренние пакеты `ascii`, `cellmetrics`, `css`, `dom`, `fetcher`, `layout`, `render`. Функции `resetImageCache`, `cachedImage`, `fetchImages` и `fetchExternalCSS` принадлежат пакету `browser` и определены вне этого файла.
