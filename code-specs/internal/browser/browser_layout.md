# Specification: browser_layout

## Обзор

Этот модуль предоставляет функции для построения карты абсолютных прямоугольников (bounding rect) для узлов DOM на основе дерева layout.

## Публичный API

### `buildLayoutBoxMap(root *layout.LayoutBox) map[*dom.Node]js.Rect`

Функция для построения карты узлов DOM -> абсолютные прямоугольники.

**Параметры:**

- `root` — корневой узел layout дерева.

**Возвращаемое значение:**

- `map[*dom.Node]js.Rect` — карта, где ключ — узел DOM, значение — абсолютный прямоугольник (X, Y, Width, Height).

**Описание:**

Функция рекурсивно проходит по дереву layout и вычисляет абсолютные координаты каждого узла относительно левого верхнего угла (0, 0).

---

### Внутренняя функция: `buildLayoutBoxRecursive(box *layout.LayoutBox, offsetX, offsetY float64, result map[*dom.Node]js.Rect)`

Вспомогательная рекурсивная функция для построения layout box map.

**Параметры:**

- `box` — текущий layout box для обработки.
- `offsetX` — смещение по X (координата левого верхнего угла родителя).
- `offsetY` — смещение по Y (координата левого верхнего угла родителя).
- `result` — карта узлов -> прямоугольники для заполнения.

**Описание:**

1. Проверяет валидность входного `box`: если `box` или `box.Node` nil, функция возвращает.
2. Вычисляет абсолютные координаты: `absX = box.Content.X + offsetX`, `absY = box.Content.Y + offsetY`.
3. Записывает прямоугольник в карту: `result[box.Node] = js.Rect{X: absX, Y: absY, Width: box.Content.Width, Height: box.Content.Height}`.
4. Рекурсивно обрабатывает всех дочерних узлов.

## Типы

### `layout.LayoutBox`

Структура layout box (импортируется из `github.com/starframe-dev/abyss/internal/layout`):

- Содержит поле `Node` — ссылка на DOM узел.
- Содержит поле `Content` — прямоугольник контента с полями `X`, `Y`, `Width`, `Height`.
- Содержит поле `Children` — список дочерних layout box'ов.

### `dom.Node`

Структура DOM узла (импортируется из `github.com/starframe-dev/abyss/internal/dom`).

### `js.Rect`

Структура прямоугольника (импортируется из `github.com/starframe-dev/abyss/internal/js`):

- `X float64` — координата по X.
- `Y float64` — координата по Y.
- `Width float64` — ширина.
- `Height float64` — высота.

## Взаимодействия

### Экспортные зависимости

- `github.com/starframe-dev/abyss/internal/dom` — тип `Node`
- `github.com/starframe-dev/abyss/internal/js` — тип `Rect`
- `github.com/starframe-dev/abyss/internal/layout` — тип `LayoutBox`

### Импортные зависимости

Этот модуль не имеет внешних импортов (кроме внутренних).

## Поведение

### Алгоритм построения layout box map

1. Создаётся пустая карта `map[*dom.Node]js.Rect`.
2. Вызывается рекурсивная функция `buildLayoutBoxRecursive` с корневым узлом и начальными координатами (0, 0).
3. Рекурсивная функция:
   - Проверяет nil-условия для `box` и `box.Node`.
   - Вычисляет абсолютные координаты, добавляя смещение родителя.
   - Записывает прямоугольник в карту.
   - Обрабатывает всех детей рекурсивно.
4. Возвращается карта узлов -> прямоугольников.

### Сложность

- **Временная сложность:** O(n), где n — количество узлов в дереве layout.
- **Пространственная сложность:** O(n) для карты и рекурсивного стека.

## Границы и ошибки

### Валидация

- Функция обрабатывает nil `box` и nil `box.Node` — в таких случаях возвращает без записи в карту.
- Координаты `offsetX` и `offsetY` могут быть любыми float64 (отрицательными, положительными).

### Ограничения

- Требуется, чтобы `box` и `box.Node` были не nil для записи в результат.
- Рекурсия идёт по структуре `Children` — предполагается, что это корректное дерево без циклических ссылок.

## Пример использования

```go
root := &layout.LayoutBox{...} // корневой layout box
boxMap := buildLayoutBoxMap(root)
// boxMap[<node>] => js.Rect{X: ..., Y: ..., Width: ..., Height: ...}
```

## Примечания

- Функция `buildLayoutBoxMap` является публичной функцией модуля.
- Функция `buildLayoutBoxRecursive` является внутренней вспомогательной функцией.
- Координаты прямоугольников абсолютны относительно (0, 0) на уровне корня.
