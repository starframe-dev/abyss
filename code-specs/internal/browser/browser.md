# browser — Спецификация пакета

## Общее описание

Пакет `browser` реализует TUI браузера на Bubble Tea с поддержкой вкладок, загрузки и отображения страниц, масштабирования, прокрутки, управления JS-таймерами и сохранения сессии.

## Типы и публичный API

### Режимы

`Mode` — целочисленный тип. Константы: `ModeAddress` (0), `ModeLoading` (1), `ModeView` (2), `ModeError` (3).

### `Tab`

Состояние вкладки содержит экспортируемые поля `ID uint64`, `RequestID uint64`, `URL string`, `Mode Mode`, `ANSILines []string`, `ASCIILines []string`, `ExternalCSS []string`, `Err error`, `ZoomFactor float64`, `OffsetX int`, `OffsetY int`. Также имеется частное поле `cancelLoad context.CancelFunc`.

### `Model`

Модель содержит экспортируемые поля `Mode Mode`, `Address textinput.Model`, `Viewport viewport.Model`, `Tabs []Tab`, `ActiveTab int`, `Width int`, `Height int`; частные поля `nextTabID uint64` и `loadedPageContent string`.

Публичные методы/функции: `New() Model`, `TickCmd() tea.Cmd`, методы модели `Init() tea.Cmd`, `Update(msg tea.Msg) (tea.Model, tea.Cmd)`, `GetActiveTab() *Tab`, `SaveActiveTab()`, `RestoreActiveTab()`, `ANSILines() []string`, `ASCIILines() []string`, `ZoomFactor() float64`, `OffsetX() int`, `Err() error`.

`PageLoadedMsg` содержит `TabID`, `RequestID` (`uint64`), `Lines`, `ANSI` (`[]string`), `URL string`, `ExternalCSS []string`. `PageRenderedMsg` содержит `TabID`, `RequestID`, `Lines`, `ANSI`. `PageErrorMsg` содержит `TabID`, `RequestID uint64` и `Err error`. `tickMsg` — частный тип сообщения.

## Создание и состояние сессии

`New` настраивает поле ввода с плейсхолдером `Enter URL...`, фокусом и шириной 50, viewport размером 80×24, модель в `ModeAddress`, размеры 80×24 и одну пустую вкладку. Затем восстанавливает URL из `~/.abyss/session.json`: при непустом списке создаёт для URL вкладки в `ModeAddress`, оставляет поле ввода незаполненным и выбирает последнюю вкладку. Вкладкам назначаются ненулевые ID.

Сессия сериализуется как JSON-объект с полем `urls`. `saveSession` (частная функция) ничего не делает, если вкладок нет или нет непустых URL; создаёт каталог с правами 0755 и записывает файл с правами 0644. Ошибки создания каталога, кодирования и записи игнорируются. `loadSession` возвращает URL из файла; при ошибках чтения или декодирования возвращает nil. Путь вычисляется при инициализации пакета из `HOME` как `~/.abyss/session.json`.

## Работа модели

`Init` объединяет мигание `textinput.Blink` и `TickCmd`; тик запускается каждые 500 мс. `active` возвращает указатель на активную вкладку либо nil при недопустимом индексе. `tabForResult` принимает только ненулевой TabID, совпадающие ID и RequestID.

`SaveActiveTab` сохраняет в активную вкладку текущий URL из Address, режим, ANSI/ASCII-контент, масштабирование, горизонтальное смещение и текущий YOffset. `RestoreActiveTab` восстанавливает режим, URL, содержимое viewport из ASCII-строк и YOffset, ограниченный допустимым диапазоном; верх страницы принудительно не устанавливается.

Методы `ANSILines` и `ASCIILines` возвращают соответствующие строки активной вкладки либо nil. `ZoomFactor` возвращает масштаб активной вкладки либо 1.0; `OffsetX` возвращает горизонтальное смещение либо 0; `Err` возвращает ошибку либо nil.

`Update` назначает ID вкладкам при необходимости. При завершении приложения отменяет загрузки и закрывает JS-контекст. Размер окна обновляет размеры адресного поля и viewport; в режиме просмотра обновляет содержимое и при изменении ширины запускает перерисовку.

В режиме ввода Enter игнорирует пустой адрес, добавляет `https://`, если нет префикса `http://` или `https://`, отменяет прежнюю загрузку вкладки, создаёт контекст отмены, увеличивает RequestID, сбрасывает масштаб и смещения и запускает `loadTabPage`. Клавиша `q` сохраняет сессию и завершает работу.

В режиме просмотра `ctrl+l` переходит к адресу; `r` перерисовывает; `+`/`=` увеличивают масштаб на 0.5 до 3.0, `-`/`_` уменьшают до 0.5; стрелки меняют горизонтальное смещение; `t` создаёт вкладку; `w` закрывает текущую, если есть другие, отменяя её загрузку и закрывая её JS-контекст; Tab/Shift+Tab переключают вкладки. `q` сохраняет сессию и завершает работу. Остальные клавиши передаются viewport. В режиме ошибки `ctrl+l` возвращает к вводу, а `q` завершает работу с сохранением сессии.

Тики при загрузке только планируют следующий тик. Иначе активная вкладка проверяется через `processJSTimers`; при изменении запускается перерисовка, после чего планируется следующий тик. `PageRenderedMsg` применяется только к вкладке с соответствующими ID и RequestID. `PageLoadedMsg` для совпавшей вкладки очищает отмену, сохраняет URL, представления, CSS и сбрасывает вертикальное смещение; активная вкладка переключается в режим просмотра, получает содержимое viewport и запускает таймер. `PageErrorMsg` для совпавшей вкладки очищает отмену и сохраняет ошибку и режим ошибки.

Внешние функции `loadTabPage`, `reRenderCmd`, `processJSTimers`, `closeJSCContext` и `closeJSCContextForTab` вызываются этим файлом, но реализованы вне него.
