# browser — Спецификация пакета

## Общее описание

Пакет `browser` реализует текстовый интерфейс пользователя (TUI) браузера на основе библиотеки Bubble Tea (Bubble Tea). Приложение позволяет отображать содержимое веб-страниц в терминале с поддержкой вкладок.

## Публичный API

### Типы

#### `Mode` (тип: `int`)

Перечисление режимов интерфейса:

| Константа   | Значение | Описание                  |
|-------------|----------|---------------------------|
| `ModeAddress` | 0        | Режим ввода URL-адреса    |
| `ModeLoading` | 1        | Режим загрузки страницы   |
| `ModeView`    | 2        | Режим отображения         |
| `ModeError`   | 3        | Режим отображения ошибки  |

#### `Tab` (структура)

Структура для хранения состояния отдельной вкладки:

| Поле          | Тип       | Описание                                     |
|---------------|-----------|----------------------------------------------|
| `URL`         | `string`  | URL-адрес вкладки                            |
| `Mode`        | `Mode`    | Текущий режим вкладки                        |
| `ANSILines`   | `[]string`| ANSI-представление контента (с escape-кодами)|
| `ASCIILines`  | `[]string`| ASCII-представление контента (без escape)    |
| `Err`         | `error`   | Ошибка, возникшая при загрузке              |
| `ZoomFactor`  | `float64`| Фактор масштабирования                       |
| `OffsetX`     | `int`     | Смещение по горизонтали                       |

#### `Model` (структура)

Главная модель Bubble Tea для браузера:

| Поле          | Тип            | Описание                                     |
|---------------|----------------|----------------------------------------------|
| `Mode`        | `Mode`         | Текущий режим интерфейса                     |
| `Address`     | `textinput.Model`| Поле ввода URL-адреса                       |
| `Viewport`    | `viewport.Model` | Виджет прокрутки для отображения контента   |
| `Tabs`        | `[]Tab`        | Массив всех вкладок                          |
| `ActiveTab`   | `int`          | Индекс активной вкладки                       |
| `Width`       | `int`          | Ширина терминала                             |
| `Height`      | `int`          | Высота терминала                             |
| `loadedPageContent` | `string` | (частное) Загруженный контент страницы       |

#### `pageLoadedMsg` (структура)

Сообщение, отправляемое при завершении загрузки страницы:

| Поле  | Тип       | Описание        |
|-------|-----------|-----------------|
| `Lines`| `[]string`| Строки контента |
| `ANSI` | `[]string`| ANSI-строки     |
| `URL`  | `string`  | URL-адрес       |

#### `pageErrorMsg` (структура)

Сообщение, отправляемое при ошибке загрузки:

| Поле | Тип    | Описание        |
|------|--------|-----------------|
| `Err`| `error`| Ошибка загрузки |

#### `tickMsg` (структура)

Сообщение, отправляемое периодически для проверки таймерных DOM-обновлений.

### Функции

#### `tickCmd() tea.Cmd`

Возвращает команду, которая ожидает следующего тика.

Таймер срабатывает каждые 500 миллисекунд.

#### `saveSession(tabs []Tab)`

Сохраняет текущие URL-адреса вкладок в файл сессии.

**Поведение:**
- Если вкладок нет, функция возвращает бездействие
- Создает директорию файла сессии (`.abyss` в домашней директории) с правами `0755`
- Сохраняет данные в формате JSON в файл `.abyss/session.json` с правами `0644`
- При ошибках (marshal, write, mkdir) функция игнорирует ошибки и возвращает бездействие

**Путь к файлу сессии:** `~/.abyss/session.json`

#### `loadSession() []string`

Читает файл сессии и возвращает сохранённые URL-адреса.

**Поведение:**
- Если файл не существует или чтение невозможно — возвращает пустой слайс
- Если парсинг JSON неудачен — возвращает пустой слайс
- Возвращает слайс URL-адресов из сохранённой сессии

#### `New() Model`

Создаёт новую модель браузера.

**Поведение:**
- Создаёт `textinput` с плейсхолдером `"Enter URL..."`
- Создает `viewport` размером 80x24
- Инициализирует модель в режиме `ModeAddress`
- Попытка восстановить сессию из сохранённых URL-адресов:
  - Если URL-адресов есть — создаёт вкладки для каждого
  - Активная вкладка — последняя в списке
  - Поле ввода адреса не заполняется
- Возвращает готовую модель

#### `Init() tea.Cmd`

Возвращает команду инициализации.

**Поведение:**
- Комбинация двух команд:
  - `textinput.Blink` — мигание курсора в поле ввода
  - `tickCmd()` — таймер DOM-обновлений

#### `active() *Tab`

Возвращает указатель на текущую активную вкладку.

**Поведение:**
- Если индекс `ActiveTab` выходит за границы — возвращает `nil`
- Иначе возвращает указатель на вкладку `Tabs[ActiveTab]`
- Метод требует вызова через указатель модели

#### `saveActiveTab()`

Сохраняет состояние текущего представления в активную вкладку.

**Поведение:**
- Извлекает значение из поля ввода `Address.Value()`
- Сохраняет текущий режим `Mode`
- Сохраняет ANSI-строки, ASCII-строки, фактор масштабирования, смещение
- Если активной вкладки нет — бездействие

#### `restoreActiveTab()`

Восстанавливает состояние представления из активной вкладки.

**Поведение:**
- Восстанавливает `Mode` из сохранённого состояния
- Устанавливает URL из `t.URL` в поле ввода `Address`
- Устанавливает содержимое `Viewport.SetContent()` из ASCII-строк
- Перемещает viewport на верх `Viewport.GotoTop()`
- Если активной вкладки нет — бездействие

#### `ANSILines() []string`

Возвращает ANSI-представление контента активной вкладки.

**Поведение:**
- Если активной вкладки нет — возвращает `nil`

#### `ASCIILines() []string`

Возвращает ASCII-представление контента активной вкладки.

**Поведение:**
- Если активной вкладки нет — возвращает `nil`

#### `ZoomFactor() float64`

Возвращает фактор масштабирования активной вкладки.

**Поведение:**
- Если активной вкладки нет — возвращает `1.0`

#### `OffsetX() int`

Возвращает смещение по горизонтали активной вкладки.

**Поведение:**
- Если активной вкладки нет — возвращает `0`

#### `Err() error`

Возвращает ошибку активной вкладки.

**Поведение:**
- Если активной вкладки нет — возвращает `nil`

## Частные методы модели

### `ANSILines() []string`

Возвращает ANSI-строки активной вкладки.

### `ASCIILines() []string`

Возвращает ASCII-строки активной вкладки.

### `ZoomFactor() float64`

Возвращает фактор масштабирования активной вкладки.

### `OffsetX() int`

Возвращает смещение по горизонтали активной вкладки.

### `Err() error`

Возвращает ошибку активной вкладки.

## Внутренние детали реализации

### Структура данных

1. **Модель хранит состояние:**
   - Текущий режим (`Mode`)
   - Поле ввода URL (`textinput.Model`)
   - Виджет прокрутки (`viewport.Model`)
   - Массив вкладок (`[]Tab`)
   - Индекс активной вкладки (`ActiveTab`)
   - Размеры терминала (`Width`, `Height`)
   - Загруженный контент (частное поле `loadedPageContent`)

2. **Вкладки сохраняют состояние:**
   - URL-адрес
   - Текущий режим
   - Контент в двух представлениях (ANSI и ASCII)
   - Параметры масштабирования и смещения
   - Возможную ошибку

### Управление сессией

Файл сессии (`~/.abyss/session.json`) содержит JSON-структуру:

```json
{
  "urls": ["https://example.com", "https://another.com"]
}
```

При запуске приложения:
1. Загружаются URL-адреса из файла сессии
2. Создаются вкладки для каждого URL
3. Последняя вкладка становится активной
4. Поле ввода адреса остаётся пустым (для ручного ввода нового URL)

### Жизненный цикл

1. **Создание (`New`):**
   - Инициализация полей ввода и viewport
   - Восстановление сессии
   - Возврат модели

2. **Инициализация (`Init`):**
   - Запуск мигания курсора
   - Запуск таймера DOM-обновлений

3. **Обработка событий:**
   - Загрузка страницы → `pageLoadedMsg`
   - Ошибка загрузки → `pageErrorMsg`
   - Периодические тики → `tickMsg`

### Обработка ошибок

- Ошибки чтения/записи файла сессии игнорируются и возвращают nil/пустой слайс
- Ошибки marshal/unmarshal JSON возвращают nil/пустой слайс
- Ошибки активной вкладки сохраняются в поле `Err`

### Внешние зависимости

- `github.com/charmbracelet/bubbles/textinput` — поле ввода URL
- `github.com/charmbracelet/bubbles/viewport` — виджет прокрутки
- `github.com/charmbracelet/bubbletea` — библиотека Bubble Tea
