# Спецификация: browser_view.go

## Обзор

Файл реализует метод `View()` для `Model` (интерфейс `tea.Model`) и вспомогательные функции очистки/обрезки текста и центрирования. Представление состоит из таб-бара, хедера и контента выбранного режима.

## Метод `View() string`

### Таб-бар

Для каждого элемента `m.Tabs` отображается URL, обработанный `safeTerminalText`. Пустое значение выводится как `New Tab`. Иначе удаляются префиксы `https://`, затем `http://`; если ширина строки в терминальных колонках превышает 20, текст обрезается по графемам до ширины 19 и добавляется `…`. Неактивный стиль: горизонтальный padding 1, фон `#313244`, текст `#cdd6f4`. Активный стиль: горизонтальный padding 1, фон `#45475a`, текст `#f5c2e7`, жирный. После табов добавляется перевод строки.

### Хедер

Стиль: фон `#1e1e2e`, текст `#cdd6f4`, горизонтальный padding 1.

В `ModeAddress` значение адресного поля предварительно очищается через `safeTerminalText`, устанавливается в копию `m.Address`, после чего выводится `Abyss ` и `View()` поля. В остальных режимах берётся `m.Address.Value()`; пустое значение заменяется на `Abyss`. Если `ZoomFactor()` не равен `1.0`, к адресу добавляется масштаб в формате `[%.0f%%]`. Адрес очищается от непечатаемых символов перед отображением. В конце хедера всегда добавляется перевод строки.

### Контент

- `ModeLoading`: пустая строка-разделитель и `Loading...`, центрированный функцией `center` относительно `m.Width`.
- `ModeError`: пустая строка-разделитель, очищенное сообщение `Error: ` с `m.Err()`, центрированное относительно `m.Width`, затем перевод строки и центрированная подсказка `Press Ctrl+L to edit URL or Q to quit`.
- `ModeAddress`: пустая строка-разделитель и очищенное значение адреса, центрированное относительно `m.Width`.
- `ModeView`: берутся `m.ANSILines()`, Y-смещение — `m.Viewport.YOffset`, высота — `m.Viewport.Height`; если высота не положительна, используется 24. Если смещение вне числа строк, оно заменяется на `len(lines)-height`, но не меньше нуля. Конец диапазона ограничивается количеством строк. Каждая видимая строка обрабатывается с шириной `m.Width` (если она не положительна — 80) и `m.OffsetX()`. При нулевом смещении и видимой ширине не больше ширины строки оригинал передаётся без изменений; иначе применяется ANSI-осознанная `clipANSI`. Результат собирается через перевод строки. Для результата используется новый срез, чтобы не изменять строки исходного буфера, на который может ссылаться `visible`.

## Вспомогательные функции

- `safeTerminalText(text)` заменяет каждый непечатаемый rune на `�`, кроме U+200C и U+200D.
- `truncateTerminalText(text, maxWidth)` проходит по графемам с помощью `uniseg`, добавляя их, пока ширина не превысит лимит; графемы нулевой ширины сохраняются, а отрицательная ширина при подсчёте считается нулём.
- `center(text, width)` вычисляет ширину через `runewidth.StringWidth`. Если ширина текста не меньше целевой, возвращает исходный текст; иначе добавляет слева `(width-textWidth)/2` пробелов. Дополнительное заполнение справа не производится.

## Зависимости и контекст

ANSI-разбор и обрезка `clipANSI`/`visibleWidth` определены вне этого файла. Метод использует их для горизонтального отображения содержимого. `Model`, его режимы и методы определены вне этого файла. Высота `m.Height` в этом методе не используется; вертикальная область определяется `m.Viewport`.
