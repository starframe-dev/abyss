# Спецификация модуля `browser_page.go`

## Обзор

Модуль `browser_page.go` реализует систему загрузки и рендеринга веб-страниц в TUI (Text User Interface) с использованием фреймворка Bubble Tea. Модуль отвечает за:

- Загрузку HTML-контента из сети
- Парсинг HTML в DOM-дерево
- Инициализацию JavaScript-контекста
- Выполнение внешних скриптов
- Вычисление CSS-стилей
- Построение макета (layout)
- Рендеринг в ASCII/ANSI формат

## Публичный API

### Функции

#### `loadPage(url string, viewportWidth int) tea.Cmd`

Загружает веб-страницу по указанному URL.

**Параметры:**
- `url` - URL адрес для загрузки страницы
- `viewportWidth` - ширина вьюпорта в пикселях

**Возвращаемое значение:**
- Возвращает `tea.Cmd`, который при выполнении возвращает `pageLoadedMsg` с рендерингом страницы или `pageErrorMsg` при ошибке.

**Последовательность действий:**
1. Загружает HTML через `fetcher.Fetch(url)`
2. Парсит HTML в DOM через `dom.Parse(html)`
3. Замыкает текущий JS-контекст через `js.CloseCurrentContext()`
4. Создает новый JS-контекст через `js.NewContext()`
5. Устанавливает текущий контекст через `js.SetCurrentContext(jsc, url)`
6. Инициализирует DOM через `js.InitDOM(doc)`
7. Регистрирует bridge-функции через `jsc.RegisterBridgeFunctions()`
8. Инициализирует систему событий через `js.InitEventSystem()`
9. Вычисляет и устанавливает CSS-стили через `css.ComputeWithExternal()`
10. Строит макет через `layout.Build()`
11. Рендерит через `render.Render()`
12. Конвертирует в ASCII через `ascii.Render()`

**Обработка ошибок:**
- При ошибке fetch возвращается `pageErrorMsg{Err: err}`
- При ошибке инициализации JS bridge возвращается ошибка с префиксом "js bridge init:"
- При ошибке выполнения DOM API возвращается ошибка с префиксом "js dom api error:"
- Ошибки при выполнении скриптов игнорируются (без возврата сообщения об ошибке)

---

#### `reRenderCmd(viewportWidth int, zoomFactor float64) tea.Cmd`

Перерисовывает текущую страницу с учётом коэффициента зума.

**Параметры:**
- `viewportWidth` - ширина вьюпорта в пикселях
- `zoomFactor` - коэффициент зума

**Возвращаемое значение:**
- Возвращает `tea.Cmd`, который возвращает `pageLoadedMsg` с обновлённым рендерингом или `nil` при отсутствии активного контекста.

**Последовательность действий:**
1. Получает текущий JS-контекст через `js.GetCurrentContext()`
2. Если контекст nil, возвращает `nil`
3. Помечает контекст как чистый через `js.MarkClean()`
4. Получает финальный DOM через `js.GetFinalDOM()`
5. Если DOM nil, возвращает `nil`
6. Вычисляет новую ширину вьюпорта с учётом зума
7. Если новая ширина меньше 10, устанавливает 10
8. Пересчитывает CSS-стили через `css.Compute()`
9. Пересчитывает макет через `layout.Build()`
10. Пересчитывает рендеринг через `render.Render()`
11. Возвращает сообщение с обновлённым рендерингом

---

#### `fetchExternalCSS(doc *dom.Node, baseURL string) []string`

Загружает внешние CSS-файлы из `<link rel="stylesheet">` тегов.

**Параметры:**
- `doc` - DOM-дерево страницы
- `baseURL` - базовый URL страницы

**Возвращаемое значение:**
- Слайс стрингов с CSS-контентом (максимум 3 файла)

**Поведение:**
1. Находит все `<link rel="stylesheet">` теги через `doc.FindLinkStylesheets()`
2. Если нет ссылок, возвращает nil
3. Берёт максимум 3 ссылки
4. Для каждой ссылки:
   - Получает href атрибут
   - Если href пуст, пропускает
   - Резолютирует URL через `resolveURL()`
   - Если результирующий URL пуст, пропускает
   - Создает HTTP-запрос с таймаутом 2 секунды
   - Устанавливает User-Agent: "Mozilla/5.0"
   - Получает ответ
   - Читает тело ответа
   - Добавляет CSS-контент в результат
5. Возвращает собранный CSS

**Обработка ошибок:**
- Ошибки URL парсинга игнорируются
- HTTP-ошибки игнорируются
- Ошибки чтения ответа игнорируются

---

#### `resolveURL(base, rel string) string`

Резолютирует относительный URL относительно базового.

**Параметры:**
- `base` - базовый URL
- `rel` - относительный URL

**Возвращаемое значение:**
- Полностью сформированный URL или `rel` если базовый URL невалиден

**Поведение:**
1. Парсит базовый URL
2. Если парсинг не удался, возвращает `rel`
3. Парсит относительный URL
4. Если парсинг не удался, возвращает пустую строку
5. Использует `url.ResolveReference()` для резолюции
6. Возвращает полученный URL

## Типы

### `pageLoadedMsg`

Сообщение об успешной загрузке страницы.

**Поля:**
- `Lines []string` - строки для рендеринга
- `ANSI []byte` - ANSI-кодированные данные
- `URL string` - загруженный URL

### `pageErrorMsg`

Сообщение об ошибке загрузки страницы.

**Поля:**
- `Err error` - ошибка, произошедшая при загрузке

## Внутренние функции

### `buildLayoutBoxMap(box layout.Box) map[string]layout.Box`

Конвертирует слайс макетных блоков в карту.

**Возвращаемое значение:**
- Карта с ключами-идентификаторами и значениями-блоками

**Примечание:** Карта боксов передаётся в JS через `setLayoutBoxes`.

## Архитектура

Модуль следует принципам композиции:

1. **Разделение ответственности:**
   - Загрузка контента: `fetcher`
   - Парсинг: `dom`
   - JS-контекст: `js`
   - CSS-вычисления: `css`
   - Layout: `layout`
   - Рендеринг: `render`
   - ASCII-конвертация: `ascii`

2. **Поток выполнения:**
   ```
   fetcher.Fetch → dom.Parse → js.InitDOM → css.ComputeWithExternal 
   → layout.Build → render.Render → ascii.Render → pageLoadedMsg
   ```

3. **Обработка ошибок:**
   - Критические ошибки (fetch, bridge init, DOM API) возвращаются в message
   - Не критические ошибки (scripts, events) игнорируются для непрерывности работы

## Важные детали реализации

### Безопасность URL

URL экранируется перед вставкой в JavaScript:
- `'` заменяется на `\'`
- `\"` заменяется на `\\`
- `\n` заменяется на `\\n`

### Загрузка CSS

- Максимум 3 внешних CSS-файла
- Таймаут 2 секунды на каждый запрос
- Ошибки загрузки CSS не прерывают загрузку страницы

### Управление контекстом JS

- Контекст замыкается перед загрузкой новой страницы
- Новый контекст создаётся для каждой страницы
- Текущий контекст устанавливается после создания

### Зумирование

- При перерисовке с зумом ширина вьюпорта масштабируется
- Минимальная ширина 10 пикселей

## Ограничения

- Максимум 3 внешних CSS-файла
- Таймаут 2 секунды на CSS-запрос
- Минимальная ширина вьюпорта 10 пикселей
- Игнорирование ошибок выполнения скриптов
- Игнорирование ошибок инициализации событий
