# Исправление ввода URL в E2E Abyss

## Контекст
В собранном `bin/abyss`, запущенном через cue-tty, команды `type` и `press` не изменяют адресную строку. Причина в обработчике `Model.Update`: сообщения клавиатуры не передаются в `textinput.Model.Update`, а нажатие Enter не запускает загрузку страницы. E2E-тесты также должны запускать бинарник с изолированным `HOME`, чтобы сессия не зависела от файла в рабочем каталоге.

## Цель
Восстановить штатный ввод URL и переход по Enter в TUI, затем подтвердить работу свежесобранного `bin/abyss` через cue-tty.

## Что изменится
1. `internal/browser/browser.go` — обработка клавиш адресной строки и делегирование обычного ввода в `textinput`.
2. `internal/browser/browser_page.go` — команда загрузки страницы, если отсутствует в текущем исходном коде.
3. `internal/browser/browser_cuetty_test.go` — изоляция `HOME` для child-процесса и регрессионная проверка ввода.
4. `code-specs/internal/browser/e2e-input-fix.md` — эта спецификация.

## Детали реализации
1. В режиме `ModeAddress` передавать обычные сообщения в `Address.Update`.
2. При Enter нормализовать URL, переключать модель в `ModeLoading` и запускать загрузку.
3. Сохранить существующие режимы, вкладки и команды выхода.
4. В E2E явно задавать временный `HOME` для запуска бинарника и удалять только созданные временные данные.
5. Добавить unit-тест, который подтверждает изменение `Address.Value()` после `tea.KeyMsg` с rune.
