# Улучшение отображения Habr в Abyss

## Контекст
Habr загружается в Abyss, но текущий pipeline загружает только три внешние таблицы стилей. Поэтому карточки публикаций теряют CSS-компоновку. Элементы `img` также имеют нулевую высоту и не дают видимого представления в терминале.

## Цель
Сделать отображение Habr в Abyss читаемым: применять внешние стили страницы, сохранять блочную/колоночную структуру и показывать изображения как терминальные placeholders с альтернативным текстом.

## Что изменится
1. `internal/browser/browser_page.go` — загрузка всех уникальных stylesheet-ресурсов с ограниченным параллелизмом.
2. `internal/css/parser.go` и `internal/css/computed.go` — поддержка вложенных at-rule и CSS custom properties, необходимых для внешних стилей Habr.
3. `internal/layout/layout.go` — размеры и текстовые placeholders для `img`.
4. `internal/ascii/*` или `internal/render/*` — видимый терминальный вывод image placeholder, если потребуется.
5. Тесты соответствующих пакетов — детерминированные проверки.

## Детали реализации
1. Найти все `<link rel="stylesheet">`, убрать дубликаты, загрузить ресурсы параллельно с ограничением числа одновременных запросов и сохранить порядок таблиц.
2. Разбирать правила внутри `@media`/`@supports`, не превращая at-rule в обычный селектор.
3. Собрать CSS custom properties из правил и разрешать `var(--name)` перед применением деклараций; неизвестные переменные игнорировать безопасно.
4. Для `img` использовать заданные CSS размеры, а при `height: auto` — детерминированную высоту placeholder; текст брать из `alt` или показывать `[image]`.
5. Не выполнять JS-бандлы Habr и не загружать бинарные изображения: терминальный placeholder является целевым представлением изображения.

## Критерии приёмки
- [ ] Тест подтверждает загрузку более трёх stylesheet-ресурсов и сохранение порядка.
- [ ] Тест подтверждает правила внутри `@media` и подстановку CSS-переменных.
- [ ] Тест подтверждает ненулевой layout для `img` и видимый alt/placeholder.
- [ ] Habr в cue-tty показывает не только фильтры, но и читаемую ленту с placeholders изображений.
- [ ] `go test ./...`, `go vet ./...` проходят.
