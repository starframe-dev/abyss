# Спецификация `internal/asciirender`

## Назначение

Пакет преобразует растровое изображение в сетку ASCII-ячеек с цветами переднего и заднего плана. Дополнительно предоставляет декодирование поддерживаемых `image` форматов и уплощение сетки в текст без ANSI-кодов. PNG, JPEG и GIF регистрируются импортами-драйверами стандартной библиотеки.

## Публичный API

### Константы ограничений

- `MaxImageWidth = 8192`, `MaxImageHeight = 8192` — предельные размеры изображения.
- `MaxImagePixels = 8 * 1024 * 1024` — предельное произведение ширины и высоты.
- `MaxOutputColumns = 4096` — максимальное число выходных столбцов.
- `MaxOutputCells = 1 << 18` — максимальное число выходных ячеек.

Изображение допустимо, если ширина и высота положительны, не превышают соответствующие лимиты и `width <= MaxImagePixels/height`.

### `Decode(data []byte) (image.Image, error)`

Сначала вызывает `image.DecodeConfig`, чтобы определить формат и размеры без декодирования пикселей. Ошибка анализа передаётся вызывающему коду. Недопустимые размеры приводят к ошибке с описанием размеров и поддерживаемых лимитов. Для допустимого изображения выполняется `image.Decode`; его ошибку также возвращает функция. Декодирование использует форматы, зарегистрированные в процессе, включая PNG, JPEG и GIF.

### `Cell`

Одна терминальная ячейка:

- `Char rune` — символ палитры.
- `FG css.Color` — цвет переднего плана, полученный из среднего цвета исходного участка.
- `BG css.Color` — цвет фона.
- `IsHalfRow bool` — признак верхнего полупикселя, спаренного с нижней половиной следующей строки. Текущий алгоритм `Quantize` это поле не устанавливает, поэтому оно остаётся `false`.

### `Palette`

Экспортируемый изменяемый срез рун, используемый для сопоставления яркости: `" .,:;i1tfLCG08@#"`. Первая руна соответствует светлому участку, последняя — тёмному. Изменение палитры вызывающим кодом влияет на последующие вызовы `Quantize`.

### `Options`

- `Columns int` — число терминальных столбцов. Значение `<= 0` заменяется на 60; затем ограничивается `MaxOutputColumns`.
- `Rows int` — число строк. Значение `<= 0` означает вычисление по соотношению сторон; положительное значение ограничивается лимитом ячеек.
- `BGColor css.Color` — цвет подложки. Если `IsSet` не установлен, используется `css.RGB(226, 232, 240)`.

### `Quantize(img image.Image, opts Options) [][]Cell`

Возвращает прямоугольную сетку `rows × cols`. Для `nil` изображения или недопустимых размеров возвращает `nil`.

Число столбцов нормализуется согласно `Options`. Для каждого значения столбцов вычисляется `maxRows = max(1, MaxOutputCells/cols)`. При неуказанном числе строк оно выводится из соотношения сторон источника с поправкой на терминальную ячейку высотой примерно в два пикселя: `cols * srcH / srcW / 2`; результат ограничивается `maxRows` и снизу единицей. Явное положительное число строк ограничивается `maxRows`.

Каждая ячейка покрывает соответствующий прямоугольный участок изображения. Координаты рассчитываются целочисленным масштабированием относительно `Bounds`, поэтому размеры участков могут различаться; при чрезмерно малом источнике некоторые участки могут оказаться пустыми. Для пустого участка вспомогательная выборка даёт нулевые цвет и яркость.

Пиксели участка усредняются. Каждый цветовой канал пикселя предварительно компонуется с белым фоном с учётом альфа-канала. Средний RGB используется для `FG`; символ выбирается по яркости. `BG` одинаков для всех ячеек и определяется `Options.BGColor` либо значением по умолчанию. Изображение не изменяется.

### `Flatten(grid [][]Cell) string`

Конкатенирует символы ячеек построчно и добавляет `\n` после каждой строки, включая последнюю. Ячейка с `Char == 0` выводится как пробел; остальные символы записываются без преобразования. Пустая сетка даёт пустую строку. Функция не выводит цветовые коды.

## Алгоритм цвета и символа

Каналы извлекаются через `color.Color.RGBA()` и сдвигаются вправо на 8 бит. Альфа-композиция выполняется над диапазоном 0–255 с белым фоном. Яркость рассчитывается по ITU-R BT.601: `(299R + 587G + 114B) / 1000`. Значение ограничивается 255 при выборе символа. Индекс палитры рассчитывается как `(255 - luminance) * (len(Palette)-1) / 255`, затем ограничивается допустимым диапазоном. Таким образом, меньшая яркость выбирает более плотный символ.

Функции выборки, расчёта яркости, выбора руны и проверки размеров являются внутренними деталями пакета и не входят в публичный API.
