# Спецификация `internal/cellmetrics/cellmetrics.go`

## Назначение

Пакет `cellmetrics` задаёт общие размеры терминальной ячейки в CSS-пикселях. Эти значения предназначены для согласованного расчёта размеров области просмотра, отрисовки и ASCII-сэмплирования.

## Публичный API

Пакет предоставляет две целочисленные константы (`int`):

- `WidthPx = 10` — ширина одной терминальной ячейки в CSS-пикселях.
- `HeightPx = 20` — высота одной строки терминала в CSS-пикселях.

Обе константы доступны импортирующим пакетам, поскольку их имена начинаются с заглавной буквы. Пакет не предоставляет функций, типов, переменных или операций с состоянием.

## Поведение и инварианты

Размеры предназначены для общего использования всеми компонентами, которым требуется геометрия текстовой сетки. Для области шириной `N` столбцов ширина в пикселях вычисляется как `N * WidthPx`. Вертикальный шаг строк составляет `HeightPx` пикселей; строки размещаются с интервалом в одну высоту строки.

Значения являются константами времени компиляции, неизменяемы во время выполнения и не имеют побочных эффектов. В этом файле нет проверок, ошибок, ввода-вывода или платформенных зависимостей.

## Детали реализации

Реализация состоит только из объявления пакета и блока целочисленных констант. Комментарии к пакету фиксируют назначение общих метрик и связь ширины области просмотра с числом столбцов; комментарии констант указывают единицы измерения.
