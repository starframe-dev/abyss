# Спецификация `internal/layout/layout_table.go`

## Назначение

Файл реализует внутреннюю раскладку табличных ячеек пакета `layout`. Таблица обрабатывается построчно: ячейки каждой строки располагаются горизонтально, строки — вертикально. Геометрия вычисляется только для ячеек; строки и секции таблицы не получают собственной раскладки в этом коде.

## API

Все функции непубличные (с именами, начинающимися со строчной буквы) и доступны только внутри пакета `layout`.

### `layoutTable(box *LayoutBox, contentWidth float64) float64`

Раскладывает строки таблицы, найденные внутри `box`, и возвращает суммарную высоту строк.

Для каждой строки:
1. Получает непосредственные ячейки `td` и `th` в порядке детей.
2. Пропускает строку без ячеек.
3. Распределяет ширину строки на основании ширины таблицы `contentWidth` и заданных ширин ячеек.
4. Вызывает `layoutBox` для каждой ячейки с вычисленной шириной, координатами `box.Content.X + x` и `box.Content.Y + y`, а также аргументом `false`.
5. Временно заменяет `cell.Style.Width` на ширину в пикселях, переданную в `layoutBox`, после чего восстанавливает исходное значение.
6. Высотой строки считает максимальное значение `cell.Margin.Height` среди ячеек. Затем прибавляет эту высоту к вертикальному смещению следующих строк.

Горизонтальное смещение `x` увеличивается на ширину каждой ячейки. Пустые строки не влияют на вертикальную позицию. Функция не задаёт ширину самого `box` и не возвращает ошибки.

### `tableRows(box *LayoutBox) []*LayoutBox`

Рекурсивно обходит `box` и его потомков в порядке обхода дерева, собирая узлы, которые одновременно являются DOM-элементами (`dom.ElementNode`) с тегом `tr`. Найденная строка добавляется в результат, после чего её потомки не обходятся. Поэтому строки вложенных таблиц внутри найденной строки этим обходом не включаются. Возвращается пустой или заполненный срез; входное дерево не изменяется.

### `rowCells(row *LayoutBox) []*LayoutBox`

Возвращает непосредственных детей `row`, являющихся DOM-элементами `td` или `th`, в исходном порядке. Вложенные ячейки и узлы иных типов игнорируются. Вход не изменяется.

### `tableColumnWidths(cells []*LayoutBox, tableWidth float64) []float64`

Возвращает срез ширин той же длины и с тем же порядком, что и `cells`.

- Для ширин, не являющихся автоматическими (`Style.Width.IsAuto == false`), вызывается `Resolve(tableWidth)`; результат записывается как ширина ячейки и учитывается в сумме `fixed`.
- Для автоматических ширин подсчитывается число ячеек `autoCount`.
- Если автоматические ячейки есть, остаток `max(0, tableWidth-fixed)` делится поровну между ними.
- Если автоматических ячеек нет, заданные ширины сохраняются без перераспределения; сумма может быть больше ширины таблицы.

Функция не применяет ограничения к явно заданным ширинам, не масштабирует фиксированные ячейки и не возвращает ошибки. Используемые типы `css` и `LayoutBox` принадлежат существующим пакетам/модулю; новые публичные типы данным файлом не объявляются.

## Важные детали реализации и границы поведения

- Раскладка строк основывается на структуре `LayoutBox` и типах/тегах DOM из `internal/dom`.
- Ширины задаются через `internal/css`; переданная в дочернюю раскладку ширина временно становится пиксельной шириной стиля ячейки.
- Максимальная высота ячеек строки определяет положение следующей строки; отдельные высоты строк не извлекаются из CSS.
- Колонки разных строк разрешаются независимо: функция распределения вызывается отдельно для ячеек каждой строки.
- Функции не проверяют `nil`-аргументы и предполагают корректные `LayoutBox` и доступные поля, как это принято в вызывающем коде.
