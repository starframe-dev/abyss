# layout_grid

## Обзор

Файл реализует внутреннюю раскладку Grid для `LayoutBox`: рассчитывает ширины столбцов, размещает детей по строкам и возвращает общую высоту сетки. Функции не экспортируются.

## `layoutGrid`

`layoutGrid(box *LayoutBox, contentWidth float64) float64`:

1. Разрешает `style.Gap` относительно `contentWidth`.
2. Если `GridTemplateColumns` пуст, использует один столбец шириной `contentWidth`.
3. Если `GridTemplateRows` пуст, использует одну строку `auto`.
4. Помечает строки как допускающие рост, если исходный трек — `auto`, `fr` либо процент при автоматической высоте контейнера.
5. Вызывает `resolveGridFractionalRows` с высотой `style.Height.Resolve(contentWidth)`, разрешает ширины столбцов, размещает детей с учётом возможности роста строк и возвращает сумму высот строк с промежутками.

## Вычисление ширины столбцов

`resolveGridColumnWidths(columns, contentWidth, gap)` обрабатывает каждый трек так:

- процентный трек разрешается относительно ширины контента;
- `fr` получает вес `Fraction`; отрицательные, бесконечные и NaN веса заменяются нулём;
- `auto` получает начальную ширину 0;
- остальные треки используют `Px`.

Оставшаяся ширина равна максимуму из нуля и `contentWidth - сумма фиксированных ширин - gap*(число столбцов-1)`. Она распределяется между треками `fr` пропорционально весам, если сумма весов положительна.

## Вычисление строк

`resolveGridFractionalRows(rows, availableHeight, gap)` распределяет оставшуюся высоту между `fr`-строками пропорционально конечным неотрицательным весам. Из доступной высоты предварительно вычитаются разрешённые высоты не-`fr` треков и промежутки между всеми заданными строками; остаток ограничивается снизу нулём. Проценты разрешаются относительно `availableHeight`. Если сумма допустимых `fr` весов не положительна, функция возвращает копию строк, разрешая в ней только проценты. Остальные значения сохраняются.

`finiteNonNegative` принимает конечные значения, не меньшие нуля.

## Размещение детей

`placeGridChildren` — вспомогательная обёртка: формирует флаги роста для `auto` и `fr` строк и передаёт работу `placeGridChildrenWithTrackSizing`.

`placeGridChildrenWithTrackSizing` размещает детей последовательно, заполняя строки слева направо. Для каждой строки из `rows` берётся начальная высота разрешённого трека (относительно `contentWidth`); для строк за пределами шаблона начальная высота равна нулю. Позиции рассчитываются от `box.Content.X` и `box.Content.Y`. Ширина дочернего `Style.Width` временно заменяется шириной соответствующего столбца для вызова `layoutBox`, после чего восстанавливается. Высота строки увеличивается до `child.Margin.Height`, только если строке разрешён рост; неописанные шаблоном строки могут расти. Возвращается массив только строк, содержащих детей.

## Координаты и итоговая высота

- `gridOffsetX` прибавляет ширины предшествующих столбцов и промежутки.
- `gridOffsetY` прибавляет высоты предшествующих строк и промежутки.
- `sumRowHeights` суммирует высоты и добавляет промежутки между строками (без конечного промежутка). Для пустого списка результат равен нулю.

## Ограничения и точные особенности реализации

- Если ширина фиксированных треков и промежутков превышает ширину контента, остаток для `fr` равен нулю.
- `auto`-столбцам не выделяется ширина по содержимому: их ширина остаётся нулевой.
- Отрицательные, бесконечные и NaN веса `fr` столбцов не участвуют в сумме и заменяются нулём.
- Рост строк определяется исходными значениями шаблона до разрешения `fr` и процентов. В частности, `fr`-строки могут расти по содержимому, а процентные — только если высота контейнера автоматическая.
- Шаблон строк не циклически повторяется для дополнительных строк: их начальная высота нулевая.
- Хотя вспомогательная `placeGridChildren` разрешает рост `auto`/`fr`, `layoutGrid` использует вариант с явно сформированными флагами, включая условие для процентов.
