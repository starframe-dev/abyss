# Спецификация: internal/layout/layout.go

## Обзор

Пакет `layout` строит дерево геометрии DOM для терминального рендерера. Расчёты выполняются в CSS-пикселях; ширину текста в терминальных ячейках определяет `go-runewidth`, а размеры ячейки — `cellmetrics`. Для изображений поле `AsciiCells` хранит предварительно квантованную ASCII-сетку.

## Типы и API

- `ViewportWidth` — значение ширины вьюпорта по умолчанию: 800.
- `Rect` содержит `X`, `Y`, `Width`, `Height` типа `float64`.
- `TextLine` содержит текст и координаты `X`, `Y`.
- `LayoutBox` содержит DOM-узел, родителя, вычисленный стиль, прямоугольники `Content`, `Padding`, `Border`, `Margin`, дочерние блоки, строки текста и `AsciiCells` для изображений.
- `Build(doc, styles, viewportWidth)` строит дерево, исключая текстовые узлы, `style`, `script`, `head` и элементы с `display:none`; для узлов без стиля использует `css.Default()`. Текстовые узлы среди детей элемента с элементными детьми представлены анонимными inline-блоками, если текст не пуст после TrimSpace. Затем вызывает `Layout`, если корень существует.
- `Layout(box, containerWidth)` рассчитывает дерево, начиная с корневого блока.

## Построение и раскладка

`layoutBox` определяет ширину через `resolveWidth`, получает margin, padding и толщину границ и ограничивает ширину содержимого снизу нулём. Автоширина обычного элемента заполняет контейнер за вычетом горизонтальных полей margin; отрицательный результат ограничивается нулём. Для изображения с автошириной положительный атрибут `width` переопределяет её. Для кнопочных input с автошириной ширина вычисляется по подписи и горизонтальному padding.

Корневой блок начинается от нулевых координат margin; для остальных смещение задаётся родителем. Абсолютное позиционирование использует ближайшего предка с `position:relative` или `absolute` и учитывает заданные `top`, `left`, либо `right`/`bottom` при отсутствии соответствующей стороны. Координаты и размеры четырёх областей записываются в `LayoutBox`. После раскладки детей высота содержимого заменяется заданной CSS-высотой, если она не auto; итоговые высоты padding, border и margin включают соответствующие отступы и границы.

Дочерний поток выбирается в таком порядке: изображение, таблица, flex, grid, block/inline-block, затем inline. Таблицы и изображения используют специальные обработчики. Для block/inline-block применяется `layoutBlockFlow`: дети обычно располагаются вертикально с учётом высоты margin; последовательности кнопок, текстовых узлов и текстовых ссылок могут размещаться строками с переносом и выравниванием. Если вертикальная высота не накоплена, используется inline-flow.

`layoutFlex` и `layoutGrid` вызываются для соответствующих display; их реализации находятся вне данного файла. `layoutTable` также вызывается для таблицы.

## Текст и элементы формы

`layoutInlineFlow` пропускает содержимое внутри `style` и `script`, собирает текст через `collectInlineText`, обрабатывает input (скрытые не занимают места; непустые показывают value или placeholder) и textarea. Пустое поле формы занимает одну высоту ячейки; пустое поисковое поле дополнительно получает ASCII-иконки. Текст разбивается на слова посредством `strings.Fields`, переносится `wordWrap`, а высота определяется количеством строк и `cellmetrics.HeightPx`.

Изображение отображает текстовые строки `[image]` и подпись alt (либо `image`); положительный атрибут height задаёт высоту, но итог не может быть меньше 48 CSS-пикселей.

`wordWrap` учитывает ширину символов через `runewidth.StringWidth`, ширину доступного места и один пробел между словами; координаты строк основаны на `box.Content` и высоте ячейки. Длинное отдельное слово не разбивается.

## Вспомогательные функции

В файле также реализованы `resolveHeight`, `isSearchField`, `drawSearchIcons`, `buttonOf`, `drawsNothing`, `isRowItem`, `isBlankText`, `nextIsRowItem`, `isTextLink`, `rowItemWidth`, `placeRowItem`, `rowAlign`, `layoutButtonRow`, `isButtonInput`, `buttonInputWidth`, `inputLabel`, `inStyleOrScript`, `estimateTextWidth`, `findPositionedAncestor`, `collectInlineText`, `collectVisibleText` и `layoutImage`.

`collectVisibleText` рекурсивно собирает текст, пропуская `script` и `style`. `collectInlineText` объединяет текстовые фрагменты видимых потомков, обрезая края каждого фрагмента. Кнопками считаются input типов submit, button и reset. Подпись input берётся из непустого value, затем placeholder.

## Ограничения

Размеры и позиционирование реализуют используемое здесь упрощённое подмножество CSS, а не полную спецификацию браузера. Ошибки не возвращаются: некорректные числовые HTML-атрибуты игнорируются. `TextLines` заполняется соответствующими обработчиками текста и изображений; `AsciiCells` объявлен в структуре и заполняется внешним рендерером.
