# Спецификация: layout_flex.go

## Обзор

Файл реализует внутреннюю раскладку flex-контейнеров в пакете `layout`. Поддерживаются row, column, перенос строк, CSS `order`, `gap`, `justify-content`, `flex-grow` и `flex-shrink`. Функции оперируют `*LayoutBox` и используют стили из пакета `css`.

## Основной алгоритм

### `layoutFlex(box *LayoutBox, contentWidth float64) float64`

Если дочерних элементов нет, возвращает 0. При `FlexDirectionColumn` вызывает `layoutFlexColumn`. Иначе временно сортирует детей стабильным порядком по `Style.Order` (если ненулевой порядок задан хотя бы у одного ребёнка), восстанавливая исходный срез после раскладки. Для `FlexWrap` вызывает раскладку строками, иначе раскладывает одну строку.

### Сортировка и перенос

`orderedFlexChildren` сохраняет DOM-порядок при равном `Order`; если все значения равны нулю, возвращает исходный срез. `layoutFlexWrapped` собирает строки по `flexBasis`: если следующий элемент не помещается вместе с gap в `contentWidth`, текущая строка раскладывается отдельно. Строки располагаются вертикально; между ними добавляется gap. Во время раскладки временно задаются `box.Children` и `box.Content.Y`, после чего они восстанавливаются.

## Режим row

`layoutFlexRow` учитывает gap между детьми и вычисляет доступную ширину как `contentWidth - totalGap`. Суммирует basis и grow через `flexTotals`, вычисляет свободное пространство через `flexRemaining`, а также отдельный вес shrink. `flexJustification` распределяет свободное положительное пространство для `justify-content`: center, flex-end, space-between, space-around. Если есть grow, justify-content не распределяет пространство.

Для каждого ребёнка `layoutFlexChild` вычисляет basis. При положительном свободном пространстве распределяет его пропорционально `flex-grow`. При недостатке места уменьшает ширину пропорционально `basis * flex-shrink`, не опуская её ниже минимальной ширины содержимого. Минимальная ширина определяется как наибольшая ширина вложенного textarea или input; hidden input игнорируется. Размер textarea берётся из `cols`, input — из CSS pixel width, если задан, иначе из `size`; отсутствующее или некорректное значение даёт 20 колонок. Затем ширина ребёнка временно задаётся стилю, вызывается `layoutBox`, после чего стиль восстанавливается.

`flexBasis` использует разрешённую CSS width, если она ненулевая; иначе измеряет inline-контент, состоящий только из текста и текстовых ссылок; при отсутствии такого измерения использует 100. Inline-текст измеряется в ячейках с помощью `runewidth` и `cellmetrics`; последовательные ссылки разделяются двумя ячейками.

Высота строки равна максимальной `Margin.Height` детей. `flexContainerSize` для row возвращает эту высоту.

## Режим column

`layoutFlexColumn` раскладывает детей вертикально, суммируя их `Margin.Height` и промежутки gap. При автоматической высоте возвращает эту сумму. При заданной высоте вычисляет неотрицательное оставшееся пространство и распределяет его между детьми пропорционально `FlexGrow`. Для выросших детей временно задаёт высоту как `child.Content.Height + growth` и повторно вызывает `layoutBox`; затем восстанавливает исходную высоту. Оставшееся пространство может быть размещено через `flexJustification`. Возвращаемое значение — рассчитанная высота содержимого до сдвигов justify.

## Вспомогательные функции

- `flexAvailableSpace`: для row возвращает `contentWidth - totalGap`; для column возвращает placeholder `100000`.
- `flexTotals`: суммирует `flexBasis`, `FlexGrow` и `FlexShrink` детей.
- `flexRemaining`: для row возвращает доступное пространство минус суммарный basis, для column — 0.
- `flexShrinkWeight`: суммирует `basis * FlexShrink` только для детей с положительным shrink.
- `flexJustification`: при положительном remaining и отсутствии grow вычисляет смещение и/или дополнительный gap для center, flex-end, space-between и space-around; иначе возвращает нули.
- `flexContainerSize`: для row возвращает максимальную высоту детей; для column — `pos - gap`.
- `fieldColumns`: разбирает положительное целое число атрибута, иначе возвращает 20.

## Состояние и взаимодействия

Раскладка временно меняет ширину/высоту стилей отдельных детей, а для сортировки и переноса — срез детей и Y контейнера; эти значения восстанавливаются. Позиции и геометрия детей задаются вызовами `layoutBox`. Возвращаемая высота сама по себе не записывается в `box.Content.Height`.
