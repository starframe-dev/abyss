# CSS Parser Specification

## Обзор

Модуль `css/parser.go` предоставляет утилиты для парсинга CSS-стилей. Пакет поддерживает парсинг:

- `inline`-атрибутов стилей (например, `style="color:red;font-size:14px;"`)
- Полноценных CSS-стилейheets (селекторы, правила, комментарии)
- Вычисления специфичности CSS-селекторов

## Публичные типы

### `Declaration`

Содержит пару свойство-значение CSS.

| Поле | Тип | Описание |
|------|-----|----------|
| `Property` | `string` | Имя CSS-свойства (например, `color`) |
| `Value` | `string` | Значение свойства (например, `red`) |

### `Rule`

Содержит правило CSS с селекторами и декларациями.

| Поле | Тип | Описание |
|------|-----|----------|
| `Selectors` | `[]string` | Список селекторов (разделены запятыми) |
| `Declarations` | `[]Declaration` | Список деклараций внутри правила |

## Публичный API

### `ParseInline(style string) []Declaration`

Парсит строку атрибута `style` в массив деклараций.

**Входные данные:**
- `style` — строка в формате CSS (например, `"color:red;font-size:14px;"`)

**Поведение:**
1. Разбивает строку по разделителям `;` (учитывая скобки для正确处理 вложенных конструкций)
2. Игнорирует пустые части
3. Разделяет каждую часть по `:` на свойство и значение
4. Обрезаёт пробелы вокруг свойств и значений

**Возвращает:**
- `[]Declaration` — массив пар свойств-значений
- При отсутствии корректных пар возвращает пустой массив (не ошибка)

---

### `ParseStyleSheet(css string) []Rule`

Парсит полный CSS-stylesheet в массив правил.

**Входные данные:**
- `css` — строка CSS-кода

**Поведение:**
1. Удаляет CSS-комментарии (`/* ... */`)
2. Находит открывающие фигурные скобки `{`
3. Разбивает селекторы перед открывающей скобкой по `,`
4. Находит закрывающую фигурную скобку `}` (учитывая вложенность)
5. Парсит декларативную часть между скобками
6. Повторяет процесс до конца строки

**Возвращает:**
- `[]Rule` — массив правил
- При некорректной структуре возвращает частично парсированные правила

---

### `Specificity(selector string) int`

Вычисляет специфичность CSS-селектора по упрощённой модели `(a, b, c)`.

**Модель специфичности:**
- `a` = количество ID-селекторов (`#`)
- `b` = количество класс-селекторов (`.`), атрибуторелекторов (`[`), псевдоклассов (`:`)
- `c` = количество тип-селекторов (элементы типа `div`, `span`, и т.п.)

**Входные данные:**
- `selector` — строка CSS-селектора

**Поведение:**
1. Убирает пробелы по краям
2. Разбивает селектор по комбинаторам (`>`, `+`, `~`)
3. Для каждого сегмента считает вхождения `#`, `.`, `[`
4. Считает псевдоклассы (подсчитывает `:` если за ним не следует второй `:`)
5. Вычисляет итоговую специфичность как `a*100 + b*10 + c`

**Возвращает:**
- `int` — специфичность в виде числа

## Вспомогательные функции

### `stripComments(css string) string`

Удаляет CSS-комментарии из строки.

**Поведение:**
- Ищет конструкции `/*`
- Перебирает символы до `*/`
- Пропускает содержимое комментариев

---

### `findClosingBrace(s string, start int) int`

Находит закрывающую фигурную скобку с учётом вложенности.

**Поведение:**
- Начинает поиск с позиции `start`
- Считает вложенность фигурных скобок
- Возвращает индекс закрывающей скобки или `-1` при некорректной структуре

---

### `parseDeclarations(block string) []Declaration`

Парсит блок деклараций CSS (содержимое между `{` и `}`).

**Поведение:**
- Разбивает по `;` (учитывая скобки)
- Обрабатывает каждую пару `property: value`
- Возвращает массив `Declaration`

---

### `splitBySemicolon(s string) []string`

Разбивает строку по разделителю `;`, учитывая вложенные скобки.

**Поведение:**
- Считает вложенность скобок `(` и `)`
- Разбивает только на уровне `parenDepth == 0`
- Возвращает массив частей

---

### `tokenizeSelector(selector string) []string`

Разбивает CSS-селектор на токены.

**Поведение:**
- Сохраняет содержимое внутри квадратных скобок `[]` как единый токен
- Разбивает по комбинаторам `>`, `+`, `~`
- Разбивает по пробелам (потомкам)
- Возвращает массив токенов

---

### `splitByClassID(s string) []string`

Разбивает сегмент селектора на части, разделённые `.` и `#`.

**Поведение:**
- Сегмент `div.class#id` разбивается на `["div.class", "#", "id"]`

---

### `isValidTypeSelector(s string) bool`

Проверяет, является ли строка допустимым тип-селектором.

**Правила:**
- Содержит только буквы, дефисы и нижние подчеркивания

---

## Обработка ошибок

Пакет не использует паники и возврат типов `error`. Вместо этого:

- Некорректные входные данные обрабатываются частично
- Пустые результаты возвращаются как пустые массивы или `-1`
- Комментарии удаляются, не вызывая ошибок
- Неполные конструкции игнорируются при парсинге

---

## Примеры использования

```go
// Парсинг inline-стилей
style := "color:red;font-size:14px;background:#fff"
decls := css.ParseInline(style)
// Result: [{Property:"color", Value:"red"}, ...]

// Парсинг stylesheet
cssCode := `.container { color: red; } .highlight { background: yellow; }`
rules := css.ParseStyleSheet(cssCode)
// Result: [{Selectors: [".container"], Declarations: [...]}, ...]

// Вычисление специфичности
selector := "div.container#main:hover"
spec := css.Specificity(selector)
// Result: ~37 (a=1, b=3, c=1 → 100+30+1)
```

---

## Примечания

- Пакет не валидирует CSS-свойства (не проверяет, существует ли свойство в CSS-спецификации)
- Значения свойств сохраняются как строки без экранирования
- Пакет поддерживает только базовый синтаксис CSS, не поддерживает сложные конструкции
