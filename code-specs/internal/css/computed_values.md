# computed_values

## Общее описание

Файл реализует парсеры CSS-значений в типизированные значения пакета `css`. Все функции ниже непубличные, кроме `Hex`.

## Парсеры

- `Hex(s string) Color`: принимает `#RGB` и `#RRGGBB`; некорректная длина, префикс или цифры дают `Transparent()`. Трёхзначные каналы расширяются повторением цифры.
- `parseTextAlign(val string) TextAlignType`: обрезает пробелы и игнорирует регистр; `center` → center, `right` и `end` → right, иначе left.
- `parseDisplay`: распознаёт `block`, `inline`, `inline-block`/`inline-box`, `flex`/`-webkit-flex`/`-webkit-box`, `grid`, `none`; неизвестное значение → `DisplayBlock`. Сравнение чувствительно к регистру и пробелам.
- `parsePosition`: распознаёт `static`, `relative`, `absolute`; иначе `PositionStatic`.
- `parseOverflow`: распознаёт `hidden`, `visible`; иначе `OverflowVisible`.
- `parseLength`: обрезает внешние пробелы; `auto` → `Auto()`, суффиксы `px`, `%`, `rem`/`em`, `fr` интерпретируются соответственно как Px, Percent, Px (коэффициент 16), Fr. Без суффикса число трактуется как Px. Неудачный, NaN или бесконечный ввод → `Auto()`. Числа ограничиваются диапазоном от `-1e6` до `1e6`; `fr` с отрицательным значением недопустим. Проверка суффиксов чувствительна к регистру.
- `parseBoxModel`: CSS shorthand из 1–4 полей (разделители `strings.Fields`) распределяется по сторонам; иные количества дают нулевой `BoxModel`. Каждое поле отдельно разбирается как длина.
- `parseBorder`: разбивает по пробелам; исходное значение по умолчанию `Border{Style: BorderNone}`. `none` и `solid` (после перевода токена в нижний регистр) задают стиль; токены с `px` или распознаваемые `isNumber` задают ширину через `ParseFloat`; остальные токены трактуются как цвет. Значение ширины напрямую не ограничивается.
- `parseBorderWidth`: удаляет конечный `px` и вызывает `ParseFloat`; ошибку игнорирует, результат при ошибке нулевой.
- `parseBorderStyle`: `none` → `BorderNone`, `solid` → `BorderSolid`, иначе `BorderNone`; регистр не нормализуется.
- `parseColor`: нормализует пробелы и регистр; ищет цвет в таблице из 16 имён, затем HEX и `rgb()`, иначе `Transparent()`.
- `parseRgb`: принимает форму `rgb(r, g, b)` с ровно тремя целочисленными каналами; неверная форма или число → `(Color{}, false)`. Каналы ограничиваются диапазоном 0–255.
- `parseInt`: `Atoi` после обрезки пробелов; ошибка игнорируется и даёт ноль.
- `parseFloat`: `ParseFloat` после обрезки пробелов; ошибка, NaN или бесконечность дают ноль, конечный результат ограничивается диапазоном `-1e6..1e6`.
- `parseFlexDirection`: `row`/`column` → соответствующие значения, иначе `FlexDirectionRow`.
- `parseJustifyContent`: распознаёт `flex-start`, `center`, `flex-end`, `space-between`, `space-around`; иначе `JustifyFlexStart`.
- `parseAlignItems`: распознаёт `flex-start`, `center`, `flex-end`, `stretch`; иначе `AlignStretch`.
- `parseLengthList`: разбирает список длин по пробелам и запятым, используя `parseLength`. Распознаёт `repeat(N, value)` только при точном префиксе `repeat(` и закрывающей скобке; положительный N повторяет разобранное значение, отрицательное/нулевое или неверное количество игнорируется. Результат ограничен 256 элементами; при достижении лимита дальнейший разбор прекращается. Вложенный repeat не поддерживается.
- `isNumber`: возвращает результат `strconv.ParseFloat` без дополнительных ограничений на NaN и бесконечность.

## Цвета

Таблица именованных цветов содержит `transparent`, `black`, `white`, `red`, `green`, `blue`, `yellow`, `cyan`, `magenta`, `gray`, `lightgray`, `darkgray`, `orange`, `purple`, `pink`, `brown` с соответствующими RGB-значениями из исходного кода. `transparent` задаётся `Transparent()`.

## Ограничения

В файле также присутствуют комментарии о поддерживаемых структурах типов, однако определения типов и их методов находятся вне этого файла и здесь не специфицируются.
