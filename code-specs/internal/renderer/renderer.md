# Спецификация пакета `renderer`

## Обзор

Пакет `renderer` устарел. Его комментарий пакета рекомендует использовать `internal/render` вместо него.

## Текущее состояние

- **Статус**: Устаревший (deprecated)
- **Пакет**: `internal/renderer`
- **Реализация**: файл содержит только комментарий пакета и объявление пакета `renderer`.
- **Зависимости**: отсутствуют.
- **Публичный API**: функции, типы и константы не объявлены.

## Комментарий пакета

В `renderer.go` находится комментарий:

```go
// Package renderer is deprecated. Use internal/render instead.
```

Он указывает использовать `internal/render` вместо устаревшего пакета. Сам код не запрещает импорт или использование пакета; запрет является рекомендацией документации, а не реализованным ограничением.
