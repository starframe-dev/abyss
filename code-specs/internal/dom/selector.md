# Спецификация пакета `internal/dom/selector`

## Обзор

Пакет `internal/dom/selector` реализует парсинг CSS-подобных селекторов и проверку соответствия элементов DOM-дереву. Предоставляет API для:
- Парсинга селекторов в структурированные объекты
- Проверки соответствия элемента селектору
- Запроса всех элементов, соответствующих селектору
- Запроса первого элемента, соответствующего селектору

## Типы данных

### `SelectorGroup`

Группа селекторов — запятая-separated список сложных селекторов.

```go
type SelectorGroup struct {
    Selectors []ComplexSelector
}
```

#### Поле `Selectors`

- Тип: `[]ComplexSelector`
- Описание: Срез сложных селекторов, образующих группу
- Значение: Может быть пустым при отсутствии селекторов

### `ComplexSelector`

Комплексный селектор — последовательность простых селекторов, соединённых комбинаторами.

```go
type ComplexSelector struct {
    Parts []SelectorPart
}
```

#### Поле `Parts`

- Тип: `[]SelectorPart`
- Описание: Срез частей (простых селекторов)
- Значение: Может быть пустым

### `SelectorPart`

Часть селектора — простой селектор плюс предшествующий комбинатор.

```go
type SelectorPart struct {
    Tag        string   // пустая строка = любой тег, "*" = универсальный
    ID         string   // идентификатор элемента
    Classes    []string // классы элемента
    Attributes []AttrSelector // атрибутные селекторы
    Pseudos    []PseudoSelector // псевдоклассы
    Combinator string   // "", " ", ">", "+", "~"
}
```

#### Поля

- `Tag`: Имя тега элемента. Пустая строка означает любой тег. Звёздочка (`*`) означает универсальный селектор.
- `ID`: Идентификатор элемента (префикс `#`).
- `Classes`: Срез имен классов элемента (префикс `.`).
- `Attributes`: Срез атрибутных селекторов `[...]`.
- `Pseudos`: Срез псевдоклассов `:...`.
- `Combinator`: Комбинатор, предшествующий этой части:
  - `""` — нет комбинатора (начало селектора)
  - `" "` — потомок (descendant combinator)
  - `">"` — прямой дочерний (child combinator)
  - `"+"` — непосредственный правый сосед (adjacent sibling)
  - `"~"` — любой правый сосед (general sibling)

### `AttrSelector`

Атрибутный селектор для проверки атрибутов.

```go
type AttrSelector struct {
    Name  string // имя атрибута
    Op    string // оператор сравнения: "", "=", "~=", "|=", "^=", "$=", "*="
    Value string // значение для сравнения
}
```

#### Операторы сравнения

- `""` — наличие атрибута (без проверки значения)
- `=` — точное совпадение
- `~=` — содержит одно из значений (пробел-разделитель)
- `|=` — начинается с имени или имён пространства имён
- `^=` — начинается с префикса
- `$=` — заканчивается на префикс
- `*=` — содержит подстроку

### `PseudoSelector`

Псевдокласс (псевдоэлемент).

```go
type PseudoSelector struct {
    Name string // имя псевдокласса
    Arg  string // аргумент в скобках, если есть
}
```

#### Структура аргумента

Аргумент может содержать любые вложенные структуры в формате: `(arg)`.

## Публичный API

### `ParseSelectorGroup(s string) (*SelectorGroup, error)`

Парсит строку селектора в объект `SelectorGroup`.

#### Параметры

- `s` (string): Строка селектора (или цепочка селекторов через запятую)

#### Возвращаемые значения

- `*SelectorGroup`: Парсированная группа селекторов
- `error`: Ошибка, если парсинг не удался

#### Поведение

- Обрезает ведущие/заключительные пробельные символы
- Возвращает пустую группу при пустой строке
- Парсит цепочки селекторов, разделённые запятыми
- Возвращает ошибку при ошибке парсинга любого из селекторов

### `MatchesSelector(n *Node, selector string) bool`

Проверяет, соответствует ли элемент узлу `selector`.

#### Параметры

- `n *Node`: Узел для проверки
- `selector` (string): Строка селектора

#### Возвращаемые значения

- `bool`: `true` если элемент соответствует селектору

#### Поведение

- Возвращает `false` для `nil` узлов или узлов типа `ElementNode`, кроме элементов
- Парсит селектор и проверяет соответствие каждому из них
- Возвращает `true` при первом совпадении

### `QueryAllSelector(root *Node, selector string) []*Node`

Возвращает все элементы, являющиеся потомками `root` и соответствующие `selector`.

#### Параметры

- `root *Node`: Корневой узел для поиска
- `selector` (string): Строка селектора

#### Возвращаемые значения

- `[]*Node`: Срез узлов, соответствующих селектору

#### Поведение

- Возвращает `nil` при ошибке парсинга селектора
- Рекурсивно проверяет всех потомков
- Возвращает срез всех совпадений

### `QuerySelectorSelector(root *Node, selector string) *Node`

Возвращает первый элемент, являющийся потомком `root` и соответствующий `selector`.

#### Параметры

- `root *Node`: Корневой узел для поиска
- `selector` (string): Строка селектора

#### Возвращаемые значения

- `*Node`: Первый совпадающий узел или `nil`

#### Поведение

- Вызывает `QueryAllSelector` и возвращает первый элемент
- Возвращает `nil` если селектор не найдён

## Частично публичный API (private functions)

### `queryAllSelectorRecursive`

Внутренняя рекурсивная функция для поиска всех совпадений.

```go
func queryAllSelectorRecursive(n *Node, group *SelectorGroup, results *[]*Node)
```

#### Поведение

- Проходит по всем дочерним узлам
- Проверяет соответствие каждому селектору
- Рекурсивно проверяет потомков
- Добавляет совпадения в срез `results`
- Пропускает узлы, не являющиеся `ElementNode`

### `splitByComma(s string) []string`

Разбивает строку на части по запятым, учитывая контекст (квадратные скобки, скобки, кавычки).

#### Параметры

- `s` (string): Строка для разбивки

#### Возвращаемые значения

- `[]string`: Срез подстрок, разделённых запятыми

#### Поведение

- Игнорирует запятые внутри квадратных скобок `[]`
- Игнорирует запятые внутри круглых скобок `()`
- Игнорирует запятые внутри кавычек
- Возвращает срез подстрок

### `parseComplexSelector(s string) (ComplexSelector, error)`

Парсит строку в сложный селектор.

#### Параметры

- `s` (string): Строка сложного селектора

#### Возвращаемые значения

- `ComplexSelector`: Парсированный селектор
- `error`: Ошибка при неудачном парсинге

#### Поведение

- Пропускает ведущие пробельные символы
- Парсит последовательность простых селекторов
- Определяет комбинаторы (`>`, `+`, `~`, ` `)
- Обрабатывает последовательные части селектора

### `parseSimpleSelectorSequence(s string) (SelectorPart, int, error)`

Парсит простую последовательность селектора.

#### Параметры

- `s` (string): Строка для парсинга

#### Возвращаемые значения

- `SelectorPart`: Парсированный простой селектор
- `int`: Потреблённые символы
- `error`: Ошибка при парсинге

#### Поведение

- Пропускает ведущие пробельные символы
- Парсит универсальный селектор `*`
- Парсит идентификаторы `#`
- Парсит классы `.`
- Парсит атрибутные селекторы `[...]`
- Парсит псевдоклассы `:...`
- Возвращает текущее состояние при встрече комбинатора

### `parseHash(s string) (string, int)`

Извлекает идентификатор из префикса `#`.

#### Параметры

- `s` (string): Строка для извлечения идентификатора

#### Возвращаемые значения

- `string`: Идентификатор (без префикса `#`)
- `int`: Потреблённые символы

### `parseClass(s string) (string, int)`

Извлекает класс из префикса `.`.

#### Параметры

- `s` (string): Строка для извлечения класса

#### Возвращаемые значения

- `string`: Имя класса (без префикса `.`)
- `int`: Потреблённые символы

### `parseIdent(s string) (string, int)`

Извлекает идентификатор (имя тега, идентификатор, класс).

#### Параметры

- `s` (string): Строка для парсинга

#### Возвращаемые значения

- `string`: Извлечённый идентификатор
- `int`: Потреблённые символы

#### Разрешённые символы

- Буквы (латинские)
- Цифры
- Тире `-`
- Удвоение подчеркивания `_`

### `parseAttribute(s string) (AttrSelector, int, error)`

Парсит атрибутный селектор внутри квадратных скобок.

#### Параметры

- `s` (string): Строка для парсинга (должна начинаться с `[`)

#### Возвращаемые значения

- `AttrSelector`: Парсированный атрибутный селектор
- `int`: Потреблённые символы
- `error`: Ошибка при парсинге

#### Поведение

- Пропускает ведущие пробельные символы
- Парсит имя атрибута
- Парсит оператор сравнения
- Парсит значение (в кавычках или без)
- Пропускает заключительные пробельные символы
- Ожидает закрывающей квадратной скобки `]`

### `parsePseudo(s string) (PseudoSelector, int, error)`

Парсит псевдокласс.

#### Параметры

- `s` (string): Строка для парсинга (должна начинаться с `:`)

#### Возвращаемые значения

- `PseudoSelector`: Парсированный псевдокласс
- `int`: Потреблённые символы
- `error`: Ошибка при парсинге

#### Поведение

- Обрабатывает одно- и двойные двоеточия для псевдоэлементов
- Парсит имя псевдокласса
- Опционально парсит аргументы в скобках
- Поддерживает вложенные скобки

## Примечания по реализации

### Парсинг

- Используется ручная реализация парсера без внешних зависимостей
- Парсинг происходит слева направо
- Потреблённые символы используются для отслеживания прогресса

### Комбинаторы

- Простой пробел соответствует комбинатору потомка
- Явные комбинаторы `>`, `+`, `~` должны следовать за простыми селекторами
- Комбинаторы могут иметь пробелы вокруг себя

### Атрибутные селекторы

- Имена атрибутов приводятся к нижнему регистру
- Операторы чувствительны к регистру
- Значения в кавычках обрабатываются с учётом типа кавычки

### Псевдоклассы

- Поддерживает синтаксис `::` для псевдоэлементов (приводится к `:`)
- Аргументы в скобках поддерживают вложенность

### Ошибки

- Возвращаются при невозможности завершить парсинг
- Не возвращается при пустой строке (возвращается пустой объект)

### Безопасность

- Имена тегов, идентификаторов, классов ограничены алфавитно-цифровыми символами и `-`, `_`
- Атрибутные имена также ограничены теми же символами
- Ограничения предотвращают потенциальные уязвимости инъекций

## Примеры использования

```go
// Парсинг простого селектора
group, err := ParseSelectorGroup("div")

// Парсинг селектора с идентификатором
group, err := ParseSelectorGroup("#main")

// Парсинг цепочки селекторов
group, err := ParseSelectorGroup("div, .class, p")

// Проверка соответствия
matches := MatchesSelector(node, "div")

// Запрос всех элементов
elements := QueryAllSelector(root, "div > p")

// Запрос первого элемента
element := QuerySelectorSelector(root, "#header")
```
