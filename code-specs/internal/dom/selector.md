# Спецификация пакета `internal/dom/selector`

## Обзор

Пакет `internal/dom` реализует разбор CSS-подобных селекторов в структуры данных и поиск DOM-элементов по этим структурам. Файл `selector.go` предоставляет парсер и API поиска; проверка фактического соответствия делегируется функциям `matchesComplex` и другим функциям пакета.

## Типы данных

`SelectorGroup` содержит `Selectors []ComplexSelector`. Группа может быть пустой.

`ComplexSelector` содержит последовательность `Parts []SelectorPart`, которая также может быть пустой.

`SelectorPart` содержит `Tag`, `ID`, `Classes`, `Attributes`, `Pseudos` и предшествующий `Combinator`. Пустой `Tag` означает отсутствие явно заданного тега, `*` — универсальный селектор. Комбинатор — одна из строк `""`, `" "`, `">"`, `"+"`, `"~"`.

`AttrSelector` содержит имя `Name`, оператор `Op` и значение `Value`. Поддерживаемые операторные строки: `""`, `"="`, `"~="`, `"|="`, `"^="`, `"$="`, `"*="`.

`PseudoSelector` содержит имя `Name` и строковый аргумент `Arg`.

## Публичный API

### `ParseSelectorGroup(s string) (*SelectorGroup, error)`

Обрезает пробелы по краям. Для пустой строки возвращает пустую группу без ошибки. Иначе разбивает строку по запятым вне кавычек, квадратных и круглых скобок, обрезает пробелы у каждой части и пропускает пустые части. Возвращает ошибку, если разбор непустой части завершился ошибкой.

### `MatchesSelector(n *Node, selector string) bool`

Возвращает `false`, если узел nil или не является `ElementNode`, либо если строка селектора не разбирается. Иначе проверяет селекторы группы через `matchesComplex` и возвращает `true` при первом совпадении.

### `QueryAllSelector(root *Node, selector string) []*Node`

При ошибке разбора возвращает nil. Иначе рекурсивно обходит потомков `root` (сам `root` не проверяется), пропускает не-элементные узлы вместе с их поддеревьями, добавляет каждый совпавший элемент один раз и сохраняет порядок обхода в глубину. Для пустой группы совпадений нет.

### `QuerySelectorSelector(root *Node, selector string) *Node`

Вызывает `QueryAllSelector`; возвращает первый результат или nil, если результатов нет.

## Внутреннее устройство парсера

`splitByComma` отслеживает глубину квадратных и круглых скобок и состояние кавычек; разделяет только при нулевой глубине вне кавычек. Экранирование кавычек отдельно не обрабатывается.

`parseComplexSelector` пропускает начальные пробелы и разбирает последовательность простых частей, разделённых пробельным потомком или явным комбинатором `>`, `+`, `~`, с возможными пробелами вокруг явных комбинаторов. Ошибка возникает при некорректном разделителе, отсутствии части после комбинатора или ошибке разбора части. Пустая входная строка даёт пустой `ComplexSelector`.

`parseSimpleSelectorSequence` последовательно разбирает атомы до пробела или неподходящего для текущей части символа. Атомами служат `*`, `#` с идентификатором, `.` с именем класса, атрибутный селектор, псевдоселектор или имя тега. Атомы комбинируются в одном `SelectorPart`; повторные ID допустимы и перезаписывают поле `ID`. Незавершённые `#` и `.` могут дать пустое имя без самостоятельной ошибки.

`parseIdent` принимает последовательности байтов, распознаваемых как Unicode-буквы/цифры, а также `-` и `_`; разбор идёт по байтам строки.

`parseAttribute` пропускает пробелы вокруг имени, оператора и значения; приводит имя атрибута к нижнему регистру. Значение может быть в одинарных/двойных кавычках либо не заключённым в кавычки идентификатором. Ожидает закрывающую `]`, иначе возвращает ошибку. В частности, отсутствие оператора допустимо только перед `]`.

`parsePseudo` принимает `:` и `::`, считывает имя, а при наличии `(` — аргумент с учётом вложенных круглых скобок. Экранирование и кавычки при подсчёте вложенности не учитываются; отсутствие закрывающей скобки не приводит к отдельной ошибке.

## Поиск

`queryAllSelectorRecursive` обходит `Children` в порядке среза. Для каждого дочернего элемента проверяет селекторы группы, добавляет узел при первом совпадении, затем рекурсивно обходит его детей. Для не-элементного ребёнка продолжение обхода в его поддерево не выполняется.

Реализация использует ручной парсер без внешних зависимостей. Поддержка и семантика соответствия селекторов определяются реализацией `matchesComplex` и связанными функциями пакета, а не самим парсером.
