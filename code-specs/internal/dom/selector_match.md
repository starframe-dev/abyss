# Specification: `internal/dom/selector_match.go`

## Обзор

Этот файл реализует логику проверки соответствия DOM-узла CSS-селектору. Он содержит функции для:
- Проверки простых и сложных селекторов
- Обработки комбинаторов (потомок, родитель, сосед)
- Поддержки псевдоклассов (first-child, nth-child, и т.д.)
- Проверки атрибутов узлов

## Публичный API

### Функции

#### `MatchesSelector(n *Node, selector string) bool`

Проверяет, соответствует ли узел `n` строке селектора.

**Параметры:**
- `n` — DOM-узел для проверки
- `selector` — строка CSS-селектора

**Возвращаемое значение:** `true`, если узел соответствует селектору (или если селектор пуст)

**Особенности:**
- Возвращает `false` для `nil` узлов или узлов типа `TextNode`
- Парсит селектор через `ParseSelectorGroup`
- Проверяет все селекторы в группе (через запятые)

#### `QueryAllSelector(root *Node, selector string) []*Node`

Возвращает все потомки узла `root`, соответствующие селектору.

#### `QuerySelectorSelector(root *Node, selector string) *Node`

Возвращает первого потомка узла `root`, соответствующего селектору, или `nil`.

## Внутренний API

### `matchesComplex(n *Node, sel ComplexSelector) bool`

Проверяет, соответствует ли узел `n` сложному селектору.

**Параметры:**
- `n` — DOM-узел
- `sel` — сложный селектор с последовательностью частей

**Возвращаемое значение:** `true`, если узел соответствует

**Поведение:**
- Возвращает `false`, если сложное селектор не имеет частей
- Рекурсивно проверяет последнюю часть селектора

### `matchPart(n *Node, parts []SelectorPart, idx int) bool`

Проверяет соответствие узла части селектора и предшествующей ему цепочки комбинаторов.

**Параметры:**
- `n` — DOM-узел
- `parts` — массив частей селектора
- `idx` — индекс текущей части

**Поведение по комбинаторам:**
- `""` или `" "` — поиск предка (потомок)
- `">"` — проверка родителя
- `"+"` — проверка предыдущего соседнего элемента
- `"~"` — проверка всех предыдущих соседних элементов

### `previousElementSibling(n *Node) *Node`

Возвращает предыдущего элемент-брата узла `n`.

**Поведение:**
- Ищет в сестрах-предках узла
- Возвращает `nil`, если узел `nil` или у него нет родителя

### `matchesSimple(n *Node, part SelectorPart) bool`

Проверяет, соответствует ли узел простой части селектора.

**Проверяет:**
- Проверку тега (`tag` или `*` для универсального)
- Проверку ID (`#id`)
- Проверку классов (`.class`)
- Проверку атрибутов (`[attr=...]`)
- Проверку псевдоклассов (`:pseudo`)

### `matchesAttr(n *Node, attr AttrSelector) bool`

Проверяет соответствие узла атрибутному селектору.

**Поддерживаемые операторы:**
- `""` (пустой) — наличие атрибута
- `=` — точное совпадение
- `~=` — совпадение с любым из значений (разделенных пробелами)
- `|=` — совпадение или префикс с дефисом
- `^=` — совпадение префикса
- `$=` — совпадение суффикса
- `*=` — содержит подстроку

### `matchesPseudo(n *Node, pseudo PseudoSelector) bool`

Проверяет псевдокласс узла.

**Поддерживаемые псевдоклассы:**
- `first-child`
- `last-child`
- `only-child`
- `first-of-type`
- `last-of-type`
- `only-of-type`
- `nth-child`
- `nth-of-type`
- `nth-last-child`
- `nth-last-of-type`
- `not`
- `is`
- `where`
- `empty`
- `checked`
- `disabled`
- `enabled`
- `selected`
- `focus` (всегда возвращает `false`)
- `root` (для документа)

Использует ленивую загрузку таблиц псевдоклассов через `sync.Once`.

### `isEmptyNode(n *Node) bool`

Проверяет, является ли узел пустым (нет элементов и нет текстовых узлов с содержимым).

## Типы

### `ComplexSelector`

Сложный селектор, состоящий из последовательности простых частей.

**Поля:**
- `Parts []SelectorPart` — массив простых частей селектора

### `SelectorPart`

Простая часть селектора с предшествующим комбинатором.

**Поля:**
- `Tag string` — имя тега (пусто для любого, `*` для универсального)
- `ID string` — ID элемента
- `Classes []string` — список классов
- `Attributes []AttrSelector` — атрибутные селекторы
- `Pseudos []PseudoSelector` — псевдоклассы
- `Combinator string` — комбинатор: `""`, `" "`, `">"`, `"+"`, `"~"`

### `AttrSelector`

Атрибутный селектор.

**Поля:**
- `Name string` — имя атрибута
- `Op string` — оператор сравнения
- `Value string` — значение для сравнения

### `PseudoSelector`

Псевдокласс селектор.

**Поля:**
- `Name string` — имя псевдокласса
- `Arg string` — аргумент псевдокласса (для `nth-*`, `not`, `is`, `where`)

## Вспомогательные функции

### `childIndex(n *Node, ofType bool) int`

Возвращает 1-based индекс узла среди его элементных детей. Если `ofType=true`, учитывает только детей с тем же тегом.

### `lastChildIndex(n *Node, ofType bool) int`

Возвращает 1-based индекс узла, считая с последнего элемента.

### `matchNth(arg string, idx int) bool`

Проверяет соответствие индекса аргументу `nth-child`/`nth-of-type`.

**Формат аргумента:** `an+b`, например:
- `2n+1` — второй, пятый, восьмой...
- `odd` — нечётные
- `even` — чётные
- `3` — третий

### `parseNth(s string) (a, b int, ok bool)`

Парсит аргумент `nth-child` в формулу `an+b`.

## Конструкции данных

### `SelectorGroup`

Группа селекторов (через запятые).

**Поля:**
- `Selectors []ComplexSelector` — массив сложных селекторов

## Взаимодействие с другими файлами

### `selector.go`
- `ParseSelectorGroup` — парсит строку селектора в `SelectorGroup`
- `MatchesSelector` — публичный API проверки селектора
- `QueryAllSelector` / `QuerySelectorSelector` — публичные методы поиска
- `parseComplexSelector` / `parseSimpleSelectorSequence` — парсинг
- `parseHash` / `parseClass` / `parseIdent` / `parseAttribute` / `parsePseudo` — парсеры

### `selector_nth.go`
- `childIndex` / `lastChildIndex` — индексы детей
- `matchNth` / `parseNth` — логика `nth-*` псевдоклассов

### `dom.go`
- `Node` — тип узла
- `Parse` — парсинг HTML
- `hasClass` — проверка класса (используется в `matchesSimple`)

## Примечания

- Псевдоклассы кэшируются в глобальной мапе с ленивой инициализацией через `sync.Once`
- Комбинаторы обрабатываются в порядке: потомок (`" "`), родитель (`">"`), сосед плюс (`"+"`), сосед тильда (`"~"`)
- Для `focus` псевдокласса всегда возвращается `false` (реализация браузера-зависимая)
- Псевдоклассы `root` и `empty` специфичны для дерева DOM
