# Спецификация: `internal/dom/selector_match.go`

## Обзор

Файл реализует внутреннюю логику сопоставления DOM-узлов с частями CSS-селекторов, включая комбинаторы, атрибуты и псевдоклассы. Публичные функции разбора и поиска селекторов описаны в `selector.go`, а вспомогательные функции `childIndex`, `lastChildIndex`, `matchNth` и `parseNth` — в `selector_nth.go`.

## Функции

### `matchesComplex(n *Node, sel ComplexSelector) bool`

Возвращает `false` для селектора без частей; иначе запускает рекурсивную проверку с последней частью.

### `matchPart(n *Node, parts []SelectorPart, idx int) bool`

Сначала проверяет текущую часть через `matchesSimple`. Если индекс равен нулю, возвращает `true`. Иначе применяет комбинатор, заданный в текущей части:
- `" "` или `""`: ищет подходящего предка;
- `">"`: проверяет родителя;
- `"+"`: проверяет предыдущего элементного соседа;
- `"~"`: проверяет всех предыдущих элементных соседей.

Неизвестный комбинатор не совпадает.

### `previousElementSibling(n *Node) *Node`

Возвращает ближайший предыдущий узел-брат типа `ElementNode`, найденный в `n.Parent.Children`. Для `nil`, узла без родителя или отсутствующего в списке детей узла возвращает `nil`.

### `matchesSimple(n *Node, part SelectorPart) bool`

Возвращает `false`, если узел `nil` или не является `ElementNode`. Проверяет заданный тег (без учета регистра, кроме пустого и `*`), точное значение атрибута `id`, каждый класс, каждый атрибутный селектор и каждый псевдокласс. Возвращает `true`, если все проверки прошли.

### `matchesAttr(n *Node, attr AttrSelector) bool`

Сопоставляет атрибут по операторам:
- пустой оператор: атрибут существует;
- `=`: точное равенство;
- `~=`: значение является одним из разделенных пробелами токенов;
- `|=`: равенство или префикс, за которым следует дефис;
- `^=`: префикс;
- `$=`: суффикс;
- `*=`: подстрока.

Неизвестный оператор возвращает `false`.

### `matchesPseudo(n *Node, pseudo PseudoSelector) bool`

Ленивая инициализация таблицы обработчиков выполняется один раз через `sync.Once`; имя псевдокласса приводится к нижнему регистру. Поддерживаются:
- `first-child`, `last-child`, `only-child`;
- `first-of-type`, `last-of-type`, `only-of-type`;
- `nth-child`, `nth-of-type`, `nth-last-child`, `nth-last-of-type` (через `matchNth` и соответствующий индекс);
- `not`, `is`, `where` (через `MatchesSelector` с аргументом псевдокласса);
- `empty` (через `isEmptyNode`);
- `checked`, `disabled`, `enabled`, `selected` (проверки `GetAttr` на пустую строку);
- `focus` (всегда `false`);
- `root` (узел типа `DocumentNode`).

Неизвестный псевдокласс возвращает `false`.

### `isEmptyNode(n *Node) bool`

Возвращает `false`, если среди детей есть элемент либо текстовый узел с непустым после `strings.TrimSpace` текстом; иначе возвращает `true`.

## Зависимости

Используются типы селекторов, `Node`, `ElementNode`, `TextNode`, `DocumentNode`, `hasClass`, `MatchesSelector`, `childIndex`, `lastChildIndex` и `matchNth`, определенные или реализованные в других файлах пакета `dom`.
