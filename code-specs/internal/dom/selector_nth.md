# Спецификация Selector Nth

## Назначение

Файл реализует вспомогательные функции для вычисления позиции DOM-узла среди элементов-соседей и сопоставления индекса с формулой `an+b`.

## Функции

### `childIndex(n *Node, ofType bool) int`

Возвращает позицию `n`, начиная с 1, в прямом порядке среди элементов в `n.Parent.Children`. Возвращает 0, если `n` или родитель равен `nil`, либо если сам узел `n` не обнаружен в слайсе среди учитываемых элементов.

Неэлементные узлы пропускаются. При `ofType == true` учитываются только элементы, чьи `TagName` равны `n.TagName` без учёта регистра; иначе учитываются все элементы. Узел сравнивается по указателю.

### `lastChildIndex(n *Node, ofType bool) int`

Аналогично `childIndex`, но перебирает детей от последнего к первому и возвращает позицию с конца (последний учитываемый элемент имеет индекс 1). Возвращает 0 при nil-значениях либо если узел не найден среди учитываемых элементов.

### `matchNth(arg string, idx int) bool`

Нормализует аргумент удалением пробелов по краям и переводом в нижний регистр. Пустой аргумент даёт `false`.

Поддерживаются `even` (остаток от деления индекса на 2 равен 0), `odd` (остаток равен 1), целые числа и формулы `an+b`, принимаемые `parseNth`. Особый аргумент `0` эквивалентен условию `idx == 0`. Числовой аргумент сравнивается с `idx` напрямую.

Для формулы, если `a == 0`, результатом является `idx == b`. Для `a > 0` функция сразу отвергает `idx < b`; для `a < 0` сразу отвергает `idx > b`. Затем проверяется `(idx-b) % a == 0`. Отрицательные индексы специально не запрещаются. Если формула не распознана, функция пробует разобрать весь аргумент через `strconv.Atoi`; ошибка разбора даёт `false`.

### `parseNth(s string) (a, b int, ok bool)`

Удаляет из строки все ASCII-пробелы (`strings.ReplaceAll(s, " ", "")`). Пустая строка даёт `ok == false`. Строка `0` отдельно разбирается как `a=0, b=0, ok=true`. Иначе требуется наличие символа `n`; часть до него задаёт `a` (`n` означает 1, `-n` означает -1), а часть после него — целое `b`, либо пустую строку для нуля. Некорректные целые значения дают `ok == false`.

Парсер использует первое вхождение `n` и `strconv.Atoi`, поэтому поддержка ограничена именно этой формой записи и диапазоном `int`; дополнительные знаки `+`/`-` в суффиксе принимаются `Atoi`, если валидны как целое число.

## Детали

Функции работают с `Node`, `ElementNode` и полями `Parent`, `Children`, `Type`, `TagName`, объявленными в пакете `dom`. Индексы вычисления соседей начинаются с 1, тогда как `matchNth` самостоятельно принимает любой `int` и не проверяет, соответствует ли он позиции реального элемента. Ошибки парсинга представляются через `false`/`ok == false`; ошибки не возвращаются.
