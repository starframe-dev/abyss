# Спецификация пакета `dom`

## Обзор

Пакет `dom` предоставляет простое DOM-дерево, построенное из HTML. Для токенизации используется `golang.org/x/net/html`. Пакет предоставляет парсинг документа и фрагмента, поиск по селекторам, операции над узлами, сериализацию и извлечение текста.

## Публичный API

### Типы

`NodeType` — целочисленный тип. Константы: `ElementNode` (1), `TextNode` (3), `CommentNode` (8), `DocumentNode` (9), `DocumentFragmentNode` (11).

`Node` содержит экспортированные поля `Type NodeType`, `TagName string`, `Attributes map[string]string`, `Children []*Node`, `Text string` и `Parent *Node`.

### Парсинг

`Parse(htmlStr string) *Node` возвращает корень типа `DocumentNode`; `ParseFragment(htmlStr string) *Node` возвращает корень типа `DocumentFragmentNode`. Оба создают пустые map атрибутов и срез детей, токенизируют вход посредством `x/net/html` и используют общие ограничения: максимум 100000 узлов (включая корень), глубина стека максимум 512 и максимальный размер буфера токена 1 MiB. При достижении лимита парсинг прекращается и возвращается безопасно построенный префикс; при ошибке токенизации также возвращается построенное дерево.

Void-элементы не добавляются в стек: `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `keygen`, `link`, `meta`, `param`, `source`, `track`, `wbr`. В стек добавляются только обычные стартовые теги, а не self-closing токены. Перед добавлением нового элемента выполняется ограниченное восстановление открытых элементов: закрывается `p` перед `p` и указанными блочными тегами; повторные `li`, `dt`/`dd`, `option`, `optgroup`, строки/ячейки таблиц и заголовки закрывают соответствующий открытый элемент. Это не полноценный HTML5 tree builder.

Текстовые токены создают текстовые узлы, кроме whitespace-only токенов: они пропускаются, если родитель не `pre` и последний ребёнок родителя не элемент. Поэтому пробел после элемента сохраняется, но это правило не эквивалентно общему сохранению разделителей inline-содержимого. Атрибуты сохраняются с именами в нижнем регистре. Ошибка токенизатора завершает обработку без отдельного сообщения об ошибке.

### Методы `Node`

- `QueryAll(selector string) []*Node`, `QuerySelector(selector string) *Node` и `Matches(selector string) bool` делегируют реализацию функциям `QueryAllSelector`, `QuerySelectorSelector` и `MatchesSelector` пакета.
- `Closest(selector string) *Node` возвращает первый совпавший узел при обходе от самого узла вверх по `Parent`; для nil-получателя возвращает nil.
- `GetAttr(name string) string` ищет имя в нижнем регистре; при nil-карте или отсутствующем атрибуте возвращает пустую строку.
- `RemoveChild(child *Node) *Node` удаляет первое совпадение по указателю, обнуляет `Parent` удалённого узла и возвращает его; если совпадения нет, возвращает nil.
- `AppendChild(child *Node) *Node` добавляет ребёнка, назначает ему текущий узел родителем и возвращает его.
- `Clone(deep bool) *Node` копирует тип, имя тега, текст и карту атрибутов. Родитель не копируется. При deep=true рекурсивно копирует детей и назначает им клонированного родителя; при false список детей остаётся пустым.
- `OuterHTML() string` для nil возвращает пустую строку; для document и fragment сериализует только детей; для текстового и comment узлов сериализует `Text` через `escapeHTML`. Для остальных узлов формирует открывающий тег, атрибуты (порядок map не определён) и содержимое. Пустой узел с именем void-элемента сериализуется как `<tag />`; иначе выводится закрывающий тег. Экранируются `&`, `<`, `>`, `"` и в тексте, и в значениях атрибутов.
- `FindStyleTags() []*Node` эквивалентен поиску `style`.
- `FindLinkStylesheets() []*Node` ищет `link[rel=stylesheet]`.
- `TextContent() string` возвращает `Text` для TextNode, иначе конкатенирует результаты для всех детей без разделителей.

### Вспомогательные функции

`hasClass(classAttr, className string) bool` разделяет строку через `strings.Fields` и проверяет точное совпадение с учётом регистра.

`escapeHTML(s string) string` заменяет `&`, `<`, `>`, `"` соответственно на `&amp;`, `&lt;`, `&gt;`, `&quot;`.

`isVoidElement(tag string) bool` сравнивает имя без учёта регистра с набором `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `link`, `meta`, `param`, `source`, `track`, `wbr`. В отличие от набора парсера, `keygen` здесь отсутствует.

## Примечания реализации

`CommentNode` объявлен, но данный парсер не обрабатывает comment-токены и не создаёт узлы комментариев. Селекторы реализованы в другом коде пакета, а не самим `x/net/html`. Методы манипуляции узлами не проверяют циклы, nil-значения или согласованность прежнего родителя. `OuterHTML` для комментария выводит экранированный текст без синтаксиса `<!-- -->`.
