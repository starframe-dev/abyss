# Спецификация пакета `dom`

## Обзор

Пакет `dom` предоставляет простую DOM-дерево, построенное из HTML-строки. Он реализует базовый парсинг HTML и предоставляет методы для навигации по дереву, манипуляции узлами и генерации HTML-серииализации.

Реализация использует библиотеку `golang.org/x/net/html` для токенизации HTML и поддерживает стандартный набор методов для работы с DOM-деревом.

---

## Публичный API

### Типы

#### `NodeType`

Константный тип, определяющий тип узла DOM.

**Константы:**

| Константа | Значение | Описание |
|-----------|----------|----------|
| `ElementNode` | 1 | Элементный узел (`<div>`, `<span>` и т.д.) |
| `TextNode` | 3 | Текстовый узел (текстовый контент внутри элемента) |
| `CommentNode` | 8 | Узел комментария (`<!-- comment -->`) |
| `DocumentNode` | 9 | Корневой узел документа |
| `DocumentFragmentNode` | 11 | Фрагмент документа (не отображается в HTML) |

#### `Node`

Структура, представляющая узел DOM:

```go
type Node struct {
    Type       NodeType
    TagName    string
    Attributes map[string]string
    Children   []*Node
    Text       string
    Parent     *Node
}
```

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `Type` | `NodeType` | Тип узла |
| `TagName` | `string` | Имя тега элемента |
| `Attributes` | `map[string]string` | Атрибуты элемента (ключи в нижнем регистре) |
| `Children` | `[]*Node` | Ссылки на дочерние узлы |
| `Text` | `string` | Текстовый контент (для текстовых узлов) |
| `Parent` | `*Node` | Ссылка на родительский узел |

## Функции

### `Parse(htmlStr string) *Node`

Парсит строку HTML и возвращает корневой узел документа.

**Параметры:**

- `htmlStr` — строка HTML для парсинга

**Возвращаемое значение:**

- Указатель на корневой узел `*Node` типа `DocumentNode`

**Поведение:**

- Создает новый корневой узел документа
- Использует токенизатор из `golang.org/x/net/html`
- Обрабатывает пустые элементы (void elements) как самозакрывающиеся
- Пропускает пробельные текстовые узлы, за исключением элементов типа `<pre>`
- Возвращает корневой узел даже при ошибках токенизации

---

### Методы узла `Node`

#### `QueryAll(selector string) []*Node`

Возвращает все потомки узла, соответствующие CSS-селектору.

**Параметры:**

- `selector` — CSS-селектор

**Возвращаемое значение:**

- Срезу на все соответствующие узлы `[]*Node`

**Пример:**

```go
nodes := doc.QueryAll("div") // все div элементы
```

#### `QuerySelector(selector string) *Node`

Возвращает первого потомка узла, соответствующего CSS-селектору, или `nil`.

**Параметры:**

- `selector` — CSS-селектор

**Возвращаемое значение:**

- Указатель на первый соответствующий узел или `nil`

**Пример:**

```go
div := doc.QuerySelector("div.container")
```

#### `Matches(selector string) bool`

Проверяет, соответствует ли узел заданному CSS-селектору.

**Параметры:**

- `selector` — CSS-селектор

**Возвращаемое значение:**

- `true`, если узел соответствует селектору, `false` иначе

**Пример:**

```go
if el.Matches("div.active") {
    // обработка активного div
}
```

#### `Closest(selector string) *Node`

Возвращает ближайшего предка (включая сам узел), соответствующего селектору, или `nil`.

**Параметры:**

- `selector` — CSS-селектор

**Возвращаемое значение:**

- Указатель на ближайший соответствующий предок или `nil`

**Пример:**

```go
btn := anchor.Closest("button")
```

#### `GetAttr(name string) string`

Возвращает значение атрибута.

**Параметры:**

- `name` — имя атрибута

**Возвращаемое значение:**

- Значение атрибута или пустая строка, если атрибут отсутствует

**Пример:**

```go
href := link.GetAttr("href")
```

**Примечание:** Имя атрибута приводится к нижнему регистру.

#### `RemoveChild(child *Node) *Node`

Удаляет дочерний узел из списка детей этого узла.

**Параметры:**

- `child` — узел для удаления

**Поведение:**

- Удаляет узел из слайса `Children`
- Устанавливает `Parent` удалённого узла в `nil`

**Пример:**

```go
parent.RemoveChild(childToRemove)
```

#### `AppendChild(child *Node) *Node`

Добавляет дочерний узел в конец списка детей.

**Параметры:**

- `child` — узел для добавления

**Поведение:**

- Добавляет узел в конец слайса `Children`
- Устанавливает `Parent` добавленного узла на текущий узел

**Пример:**

```go
parent.AppendChild(newChild)
```

#### `Clone(deep bool) *Node`

Создает копию узла.

**Параметры:**

- `deep` — если `true`, создаётся глубокое копирование (включая детей); если `false`, поверхностное копирование только текущих данных

**Возвращаемое значение:**

- Указатель на копию узла

**Пример:**

```go
clone := node.Clone(true) // глубокая копия
```

#### `OuterHTML() string`

Возвращает HTML-серииализацию узла и его потомков.

**Возвращаемое значение:**

- Строка HTML

**Примечание:**

- Для текстовых и комментариев возвращает экранированный текст
- Для элементов возвращает тег с атрибутами и содержимым
- Пустые элементы могут выводиться как самозакрывающиеся (`<br />`)
- HTML-специальные символы экранируются

**Пример:**

```go
html := div.OuterHTML() // "<div class='container'>Hello</div>"
```

#### `FindStyleTags() []*Node`

Возвращает все узлы `<style>` в документе.

**Возвращаемое значение:**

- Срезу на узлы `<style>`

**Пример:**

```go
styles := doc.FindStyleTags()
```

#### `FindLinkStylesheets() []*Node`

Возвращает все узлы `<link rel="stylesheet">` в документе.

**Возвращаемое значение:**

- Срезу на узлы `<link>` со стилевыми листами

**Пример:**

```go
cssLinks := doc.FindLinkStylesheets()
```

#### `TextContent() string`

Возвращает concatenated текстовый контент всех текстовых узлов-потомков.

**Возвращаемое значение:**

- Строка с текстовым контентом

**Пример:**

```go
text := paragraph.TextContent() // "Hello World"
```

## Вспомогательные функции

### `hasClass(classAttr, className string) bool`

Проверяет, содержится ли класс в атрибуте `class`.

**Параметры:**

- `classAttr` — значение атрибута `class`
- `className` — имя класса для поиска

**Возвращаемое значение:**

- `true`, если класс найден, `false` иначе

**Примечание:** Классы разделяются пробелами, имена чувствительны к регистру.

### `escapeHTML(s string) string`

Экранирует HTML-специальные символы в строке.

**Параметры:**

- `s` — строка для экранирования

**Возвращаемое значение:**

- Экранированная строка

**Замещения:**

- `&` → `&amp;`
- `<` → `&lt;`
- `>` → `&gt;`
- `"` → `&quot;`

### `isVoidElement(tag string) bool`

Проверяет, является ли элемент HTML void element (элемент без завершающего тега).

**Параметры:**

- `tag` — имя тега

**Возвращаемое значение:**

- `true`, если элемент является void element

**Void элементы:**

- `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `link`, `meta`, `param`, `source`, `track`, `wbr`

### `Parse(htmlStr string) *Node`

Публичная функция парсинга HTML-строки.

## Внутренние функции

### `handleTextToken(stack []*Node, tokenizer *html.Tokenizer)`

Обработчик текстовых токенов.

**Поведение:**

- Проверяет, не пуст ли стек узлов
- Берёт родительский узел
- Пропускает пробельные узлы, если родитель не является `<pre>`
- Создаёт текстовый узел с текстом

### `handleStartTag(stack []*Node, tokenizer *html.Tokenizer, tt html.TokenType) []*Node`

Обработчик стартовых тегов.

**Поведение:**

- Создаёт элементный узел из токена
- Парсит атрибуты тега
- Добавляет узел в детей родителя
- Добавляет узел в стек только если это не void element

## Особенности реализации

### Парсинг HTML

- Использует `golang.org/x/net/html` для токенизации
- Обрабатывает ошибки токенизации (возвращает существующий документ)
- Поддерживает HTML5 void elements (без завершающих тегов)
- Игнорирует пробелы в текстовых узлах, кроме внутри `<pre>`

### Работа с атрибутами

- Все имена атрибутов приводятся к нижнему регистру
- Пустой `Attributes` маппинг возвращается пустая строка

### Структура дерева

- Каждый узел хранит ссылку на родителя
- Пустой стек означает корневой документ
- Документ-фрагменты не отображаются в HTML

### Экранирование

- Все HTML-специальные символы экранируются при серииализации
- Атрибуты значений также экранируются

---

## Ограничения

- CSS-селекторы поддерживаются через встроенный парсер из `golang.org/x/net/html`
- Нет поддержки сложных селекторов (атрибуты с операторами, псевдоклассы)
- Невозможно изменить структуру документа после парсинга (только добавить/удалить узлы через методы)
- Глубокое копирование не включает новые атрибуты, созданные после парсинга

## Примеры использования

```go
package main

import (
    "fmt"
    "github.com/yourproject/abyss/internal/dom"
)

func main() {
    html := `<div class="container">
        <h1>Hello</h1>
        <p>World</p>
    </div>`

    doc := dom.Parse(html)

    // Найти все h1 элементы
    headers := doc.QueryAll("h1")
    fmt.Println(len(headers))

    // Получить текстовый контент
    content := doc.TextContent()
    fmt.Println(content)

    // Клонировать узел
    clone := doc.Clone(false)
    clone.AppendChild(doc.QueryAll("p")[0])
}
```
