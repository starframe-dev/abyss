# dom_serialize — спецификация

## Обзор

Пакет `internal/js/dom_serialize.go` предоставляет функции для работы с DOM-деревами: сериализации узлов в HTML, получения содержимого узлов и замены узлов через outerHTML.

Файл работает с глобальным хранилищем узлов (`nodes` map) через мутек `nodeMu` для синхронизации доступа.

---

## Публичный API

### `getInnerHTML(id NodeID) string`

Возвращает HTML-внутреннее содержимое узла (без самого тега).

**Параметры:**
- `id NodeID` — идентификатор узла

**Возвращает:**
- `string` — HTML-строка содержимого всех дочерних узлов, или `""` если узла не существует

**Поведение:**
1. Захватывает `nodeMu` для эксклюзивного доступа
2. Проверка существования узла — возвращает `""` если узла нет
3. Сериализует всех дочерних узлов через `serializeNode`
4. Освобождает мутек

**Пример:**
```go
id := GetNodeID("div")
innerHTML := getInnerHTML(id)
// "<span>text</span><span>more text</span>"
```

---

### `getTextContent(id NodeID) string`

Возвращает текстовое содержимое узла и всех его дочерних узлов.

**Параметры:**
- `id NodeID` — идентификатор узла

**Возвращает:**
- `string` — текстовое содержимое, или `""` если узла не существует

**Поведение:**
1. Захватывает `nodeMu`
2. Проверка существования узла
3. Вызывает `collectText` для рекурсивного сбора текста
4. Освобождает мутек

**Пример:**
```go
id := GetNodeID("div")
text := getTextContent(id)
// "text more text"
```

---

### `collectText(n *dom.Node) string`

Внутренняя функция, рекурсивно собирающая текст из узла и его детей.

**Параметры:**
- `n *dom.Node` — указатель на DOM-узел

**Возвращает:**
- `string` — собранный текст

**Поведение:**
1. Если тип узла `dom.TextNode` — возвращает `n.Text`
2. Иначе итерируется по дочерним узлам
3. Для каждого дочернего узла рекурсивно вызывает `collectText`
4. Использует `strings.Builder` для эффективного соединения строк

---

### `serializeNode(b *strings.Builder, n *dom.Node)`

Внутренняя функция сериализации узла в HTML.

**Параметры:**
- `b *strings.Builder` — буильдер для записи HTML
- `n *dom.Node` — указатель на узел

**Поведение:**
1. Для `TextNode`:
   - Вызывает `escapeHTML(n.Text)` и записывает в буильдер
   
2. Для `ElementNode`:
   - Записывает открывающий тег `<TagName`
   - Сортирует атрибуты по именам для детерминированного вывода
   - Для каждого атрибута:
     - Записывает имя атрибута
     - Если значение не пусто — записывает `="value"`
   - Если элемент void-элемент (не требует закрывающего тега):
     - Записывает ` />`
   - Иначе записывает `>`
   - Рекурсивно сериализует всех дочерних узлов
   - Записывает закрывающий тег `</TagName>`

---

### `escapeHTML(s string) string`

Внутренняя функция экранирования HTML-специальных символов.

**Параметры:**
- `s string` — строка для экранирования

**Возвращает:**
- `string` — экранированная строка

**Поведение:**
1. Заменяет `&` → `&amp;`
2. Заменяет `<` → `&lt;`
3. Заменяет `>` → `&gt;`
4. Заменяет `"` → `&quot;`

---

### `voidElements`

Глобальная переменная — map с перечислением void-элементов HTML.

**Содержит:**
```go
var voidElements = map[string]bool{
    "area": true, "base": true, "br": true, "col": true, "embed": true,
    "hr": true, "img": true, "input": true, "link": true, "meta": true,
    "param": true, "source": true, "track": true, "wbr": true,
}
```

---

### `outerHTMLString(nodeID NodeID) string`

Возвращает полный HTML узла (включая открывающий и закрывающий теги).

**Параметры:**
- `nodeID NodeID` — идентификатор узла

**Возвращает:**
- `string` — outerHTML узла, или `""` если узла не существует

**Поведение:**
1. Захватывает и освобождает `nodeMu`
2. Проверка существования и непустоты узла
3. Вызывает `n.OuterHTML()`

---

### `setOuterHTML(nodeID NodeID, html string)`

Заменяет узел на новый, созданный из предоставленного HTML-строки.

**Параметры:**
- `nodeID NodeID` — идентификатор узла для замены
- `html string` — HTML-строка для замены

**Возвращает:**
- `nil` — не возвращает (void function)

**Поведение:**
1. Захватывает и освобождает `nodeMu`
2. Проверка: узел должен существовать, быть непустым и иметь родителя
3. Вызывает `dom.Parse` для парсинга HTML внутри `"<fragment>...</fragment>"`
4. Если парсинг вернул nil — возвращает
5. Фильтрует только элементы из fragment (пропускает текст)
6. Если нет элементов — возвращает
7. Захватывает `nodeMu` для модификации
8. Находит индекс узла в родителя
9. Если индекс не найден — возвращает
10. Удаляет старый узел из родителя:
    - Устанавливает `n.Parent = nil`
    - Удаляет из `parent.Children`
11. Соединяет слайсы родителей вокруг места удаления
12. Устанавливает `Parent` для новых узлов на родителя
13. Обновляет слайс `parent.Children`
14. Вызывает `css.InvalidateCache()` для инвалидации CSS-кэша

## Архитектурные особенности

### Синхронизация

Все публичные функции используют `nodeMu` (предположительно `sync.Mutex`) для защиты общего хранилища `nodes`:

- `getInnerHTML` и `getTextContent` захватывают-освобождают мутек
- `setOuterHTML` захватывает мутек дважды — один раз для чтения, один раз для записи

### Ошибки

Ошибки обрабатываются явно через проверки `ok` при доступе к узлу. Нет использования `panic` или `defer` для рекуперации.

### Парсинг HTML

`setOuterHTML` использует `dom.Parse` для интерпретации строки как HTML. Фрагментный подход позволяет безопасно парсить HTML без создания root-элемента.

### CSS Кэш

После замены узла вызывается `css.InvalidateCache()` — инвалидирует CSS-кэш, так как DOM изменился.

## Тестирование

Рекомендуемые тест-кейсы:

1. `getInnerHTML` на непараметризованном узле
2. `getInnerHTML` на узле без детей
3. `getTextContent` на узле-тексте
4. `serializeNode` на void-элементах
5. `escapeHTML` на строках с спецсимволами
6. `setOuterHTML` на узле с родителем
7. `setOuterHTML` на корневого узла (без родителя)
8. `setOuterHTML` с валидным HTML
9. `setOuterHTML` с невалидным HTML
10. `setOuterHTML` на несуществующем узле

---

## Примечания

- Функции работают с глобальным состоянием — требуется синхронизация
- `setOuterHTML` не возвращает результат, но модифицирует DOM и вызывает CSS-инвалидацию
- Атрибуты сортируются для детерминированного вывода HTML
- Void-элементы обрабатываются как самозакрывающиеся без закрывающего тега
