# dom_serialize — спецификация

## Обзор

`internal/js/dom_serialize.go` содержит функции сериализации DOM-узлов, получения HTML- и текстового содержимого, а также замены узла через `outerHTML`. Для доступа к глобальным `nodes` и `nodeMu` используется синхронизация, как описано ниже.

## Функции

### `getInnerHTML(id NodeID) string`
Блокирует `nodeMu`, ищет узел в `nodes` и возвращает пустую строку, если он отсутствует. Иначе сериализует каждый дочерний узел через `serializeNode` и возвращает результат. Мьютекс удерживается во время сериализации.

### `getTextContent(id NodeID) string`
Блокирует `nodeMu`, ищет узел и возвращает пустую строку при отсутствии. Иначе возвращает `collectText` для найденного узла; мьютекс удерживается во время обхода.

### `collectText(n *dom.Node) string`
Для текстового узла возвращает `n.Text`. Для любого другого типа рекурсивно собирает текст детей в исходном порядке с помощью `strings.Builder`.

### `serializeNode(b *strings.Builder, n *dom.Node)`
Для `TextNode` записывает экранированный текст. Для `ElementNode`:
- записывает `<` и имя тега;
- сортирует имена атрибутов лексикографически;
- записывает каждый атрибут как ` name`, а `="значение"` добавляет только при непустом значении; значение экранируется через `escapeHTML`;
- если у элемента нет детей и его имя содержится в `voidElements`, записывает ` />` и завершает сериализацию этого узла;
- в остальных случаях записывает `>`, рекурсивно сериализует детей и записывает закрывающий тег.

Другие типы узлов не добавляют содержимого.

### `escapeHTML(s string) string`
Последовательно заменяет `&` на `&amp;`, `<` на `&lt;`, `>` на `&gt;`, `"` на `&quot;`.

### `voidElements`
Глобальная карта содержит следующие имена: `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `link`, `meta`, `param`, `source`, `track`, `wbr` (для каждого значение `true`). Void-форма применяется только при отсутствии детей.

### `outerHTMLString(nodeID NodeID) string`
Кратковременно блокирует `nodeMu` для чтения `nodes[nodeID]`, затем освобождает его. Возвращает пустую строку, если узел отсутствует или равен `nil`; иначе возвращает результат `n.OuterHTML()`.

### `setOuterHTML(nodeID NodeID, html string)`
Если узел отсутствует, равен `nil` или не имеет родителя, функция ничего не делает. Поиск выполняется под `nodeMu`, но мьютекс снимается до разбора и до получения указателя на родителя.

Разбирает HTML через `dom.ParseFragment`. Если результат `nil`, ничего не делает. Использует все элементы `fragment.Children` (включая текстовые и прочие типы узлов); пустой список детей сам по себе не отменяет замену.

Затем блокирует `nodeMu`, ищет исходный узел среди `parent.Children` и ничего не делает, если он не найден. Удаляет исходный узел и сбрасывает его `Parent`, назначает каждому новому узлу `Parent = parent` и вызывает `assignIDsToNew` для каждого. Вставляет новые узлы на место удалённого, сохраняя порядок. После успешной замены вызывает `css.InvalidateCache()`.

## Импорты и зависимости

Файл использует `sort`, `strings`, `internal/css` для инвалидации кэша и `internal/dom` для DOM-узлов и `dom.ParseFragment`.
