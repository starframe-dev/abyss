# Спецификация bridge_dom.go

## Назначение

`internal/js/bridge_dom.go` содержит обработчики вызовов DOM из JavaScriptCore. Каждый обработчик принимает `*Context` и `[]C.JSValueRef`, преобразует значения с помощью вспомогательных функций соседнего пакета и вызывает соответствующую DOM-операцию. Отрицательный ID считается невалидным там, где выполняется проверка. Преобразования строк через `getArgString` игнорируют ошибку.

Файл включает JavaScriptCore и объявляет C-функции, перечисленные в его cgo-прологе; в этом файле непосредственно используются `C.JSValueToBoolean`, `C.CString`, `C.free` и `_makeString`. Импортируются `unsafe` и `internal/css`.

## Обработчики

- `createElementJS`: при отсутствии аргументов возвращает `JSValueMakeUndefined`; иначе получает строку тега, заменяет пустую строку на `div`, создаёт элемент и возвращает `nodeToJS`.
- `createTextNodeJS`: без аргумента возвращает undefined; иначе создаёт текстовый узел из строки и возвращает его обёртку.
- `createDocumentFragmentJS`: игнорирует аргументы, создаёт фрагмент и возвращает его обёртку.
- `appendChildJS`: требует два аргумента и неотрицательные ID родителя и ребёнка; вызывает `appendChild`, инвалидирует CSS-кэш, вызывает `SetDirty` и возвращает исходное значение второго аргумента. При отказе возвращает undefined.
- `removeChildJS`: та же проверка двух ID; вызывает `removeChild`, инвалидирует кэш, помечает состояние грязным и возвращает исходное значение ребёнка; при отказе — undefined.
- `insertBeforeJS`: требует три аргумента, преобразует все ID, но проверяет только родителя и новый узел (ID ссылки может быть отрицательным); вызывает `insertBefore`, помечает состояние грязным и возвращает исходный второй аргумент. При недостатке аргументов или невалидных проверяемых ID возвращает undefined.
- `replaceChildJS`: требует три аргумента и проверяет все три ID; вызывает `replaceChild`, помечает состояние грязным и возвращает исходное третье значение. При отказе — undefined.
- `setInnerHTMLJS`: требует два аргумента и неотрицательный ID; устанавливает строковое HTML-содержимое, инвалидирует CSS-кэш, помечает состояние грязным и возвращает undefined.
- `setOuterHTMLJS`: требует два аргумента и неотрицательный ID; устанавливает строковое outerHTML, помечает состояние грязным и возвращает undefined.
- `setAttributeJS`: требует три аргумента и неотрицательный ID; преобразует имя и значение в строки, устанавливает атрибут, инвалидирует CSS-кэш, помечает состояние грязным и возвращает undefined.
- `setTextContentJS`: требует два аргумента и неотрицательный ID; устанавливает текст, вызывает `SetDirty` (без инвалидации CSS-кэша) и возвращает undefined.
- `getInnerHTMLJS` и `getTextContentJS`: при отсутствии аргумента или отрицательном ID возвращают пустую JS-строку; иначе получают значение и возвращают его через `ctx.MakeString`.
- `outerHTMLJS`: при отсутствии аргумента или отрицательном ID возвращает пустую JS-строку. Иначе получает `outerHTMLString`, создаёт C-строку, освобождает её через `defer C.free` и возвращает результат `C._makeString`.
- `cloneNodeJS`: при отсутствии аргумента или отрицательном ID возвращает null. Глубина по умолчанию false; при наличии второго аргумента используется `C.JSValueToBoolean`. Если `cloneNode` возвращает nil, результат null, иначе возвращается `nodeToJS`.
- `containsJS`: при недостатке аргументов или отрицательном ID возвращает false; иначе возвращает результат `contains` как JS boolean.
- `insertAdjacentHTMLJS` и `insertAdjacentTextJS`: требуют три аргумента и неотрицательный ID цели; считывают позицию и HTML/текст, вызывают соответственно `InsertAdjacentHTML` и `insertAdjacentText`, помечают состояние грязным и возвращают undefined.
- `insertAdjacentElementJS`: требует три аргумента и неотрицательные ID цели и вставляемого элемента; позицию берёт из третьего аргумента, вызывает `insertAdjacentElement`, помечает состояние грязным и возвращает исходное второе значение. При отказе возвращает null.

## Изменение состояния

Инвалидация `css.InvalidateCache()` выполняется только в `appendChildJS`, `removeChildJS`, `setInnerHTMLJS` и `setAttributeJS`. `SetDirty()` вызывается во всех перечисленных модифицирующих обработчиках, кроме создающих, читающих, `cloneNodeJS` и `containsJS`. Файл не реализует явной передачи исключений JavaScript и игнорирует ошибки преобразования строк.

## Зависимости

DOM-операции (`createElement`, `appendChild`, `setInnerHTML` и остальные) и преобразователи `jsToNodeID`, `getArgString`, `nodeToJS` определены вне этого файла. Методы `Context` также определены в соседнем коде. Функции поиска и обработки событий в этом файле отсутствуют.
