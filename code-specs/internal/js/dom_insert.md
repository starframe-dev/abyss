# Спецификация: `internal/js/dom_insert.go`

## Обзор

Файл реализует вставку, замену и смежную вставку DOM-узлов. Функции, работающие с `nodes` и деревом, используют `nodeMu`; `insertAdjacentHTML` и `insertAdjacentText` сначала кратковременно блокируют мьютекс для чтения узла, затем выполняют подготовку и повторно блокируют его для изменения дерева.

## Импорты и типы

Пакет `js` импортирует `internal/css` и `internal/dom`. `NodeID` используется как идентификатор узла в карте `nodes`.

## Функции

### `insertBefore(parentID, newNodeID, refNodeID NodeID)`

Под `nodeMu` проверяет родителя и новый узел; отсутствующие или nil-узлы игнорируются. Также игнорирует попытку вставить узел перед самим собой. Отрицательный `refNodeID` означает вставку в конец; иначе ссылка берётся из `nodes`, а отсутствующая ссылка приводит к добавлению в конец. Перед обычной вставкой проверяется цикл через `wouldCreateCycle`; узел удаляется из прежнего родителя, затем вставляется перед ссылкой, если она есть среди детей родителя, иначе добавляется в конец. Для `DocumentFragmentNode` проверяет, что ни один ребёнок не создаёт цикл, распаковывает детей через `insertFragmentChildrenLocked` и очищает фрагмент. После успешной операции инвалидирует CSS-кэш. При цикле или недопустимых входных данных возвращает без изменений.

### `insertFragmentChildrenLocked(parent, fragment, refNode *dom.Node)`

Предполагает, что вызывающий держит `nodeMu`. Копирует список детей фрагмента. Если `refNode` найден среди детей родителя, вставляет скопированных детей непосредственно перед ним; иначе добавляет их в конец. Устанавливает каждому перенесённому ребёнку `Parent = parent` и очищает `fragment.Children`.

### `replaceChild(parentID, newNodeID, oldNodeID NodeID)`

Под мьютексом проверяет наличие и непустоту узлов; игнорирует `parent == newNode`, `oldNode == newNode`. Для фрагмента предварительно проверяет циклы для всех его детей и наличие `oldNode` в детях родителя. Если проверка пройдена, отсоединяет старый узел, вставляет копию детей фрагмента на его место, обновляет родительские ссылки, очищает фрагмент и инвалидирует CSS-кэш. Для обычного узла проверяет цикл, удаляет новый узел из прежнего родителя, затем заменяет старый узел, если он найден, и инвалидирует CSS-кэш. Если старый узел не является ребёнком родителя, замена не происходит.

### `InsertAdjacentHTML(nodeID NodeID, position, html string)`

Проверяет наличие целевого узла под кратковременной блокировкой, разбирает HTML с помощью `dom.ParseFragment`, сохраняя верхнеуровневые текстовые узлы без синтетического узла-фрагмента. Пустой или nil-фрагмент игнорируется. Под мьютексом принимает только позиции `beforebegin`, `afterbegin`, `beforeend`, `afterend`; для внешних позиций требует наличие родителя. Вставляет все узлы фрагмента внутрь цели или рядом с ней, назначает новым узлам ID через `assignIDsToNew` и инвалидирует CSS-кэш.

### `insertAdjacentText(nodeID NodeID, position, text string)`

Проверяет целевой узел, создаёт `dom.TextNode` и вставляет его в одну из четырёх позиций. Для внешних позиций используется вставка рядом с узлом, которая ничего не делает без родителя или если узел отсутствует среди детей родителя. Неизвестная позиция не приводит к вставке. CSS-кэш не инвалидируется.

### `insertAdjacentElement(nodeID, elemID NodeID, position string)`

Под мьютексом проверяет наличие обоих узлов. Для `beforebegin` и `afterend` целевым родителем является родитель узла-ориентира; для `afterbegin` и `beforeend` — сам ориентир. Неизвестная позиция и отсутствие требуемого внешнего родителя приводят к возврату. Проверяет, не создаст ли перенос цикл, удаляет элемент из прежнего родителя и вставляет его в указанную позицию. Инвалидирует CSS-кэш.

### `insertSiblingNodes(n *dom.Node, newNodes []*dom.Node, after bool)`

Вспомогательная функция для вставки списка узлов перед или после `n`. Если у `n` нет родителя или он не найден среди детей родителя, ничего не делает. Назначает новым узлам родителя, при `after` вставляет их непосредственно после `n`, иначе непосредственно перед ним.

## Замечания

Операции не возвращают ошибки; недопустимые входные данные и невозможность вставки обрабатываются ранним возвратом. `css.InvalidateCache()` вызывается при операциях вставки/замены, кроме вставки текста. Фрагменты очищаются после распаковки. `insertAdjacentHTML` и `insertAdjacentText` не требуют, чтобы цель была зарегистрирована в `nodes` во время самого изменения после первоначальной проверки.
