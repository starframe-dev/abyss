# Спецификация: `internal/js/dom_insert.go`

## Обзор

Файл содержит реализацию функций для работы с DOM-деревом — вставка узлов перед, после или внутрь существующих элементов. Все операции выполняются с защитой от гонок данных через мьютекс `nodeMu`.

## Пакет

```go
package js
```

## Импорт

```go
import (
    "github.com/starframe-dev/abyss/internal/css"
    "github.com/starframe-dev/abyss/internal/dom"
)
```

## Типы

### NodeID

Тип `NodeID` — идентификатор узла DOM (индекс в карте `nodes`). Используется во всех функциях пакета как параметр для указания узлов.

## Общепринятые паттерны

- **Защита от гонок**: Все публичные функции блокируют `nodeMu` на начало и разблокируют после завершения.
- **Обработка фрагментов**: Узлы типа `DocumentFragmentNode` автоматически распаковываются при вставке.
- **Неинвалидация CSS-кэша при read**: `css.InvalidateCache()` вызывается только при вставке, не при чтении.
- **Управление состоянием**: `parent.Children` — слайс `*dom.Node`, хранит прямых детей узла.
- **Fragment очистка**: После распаковки `fragment.Children` устанавливается в `nil`.

## Публичный API

### `insertBefore(parentID, newNodeID, refNodeID NodeID)`

Вставляет новый узел перед указанным опорным узлом в родительском контейнере.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `parentID` | `NodeID` | Идентификатор родительского узла |
| `newNodeID` | `NodeID` | Идентификатор узла, который нужно вставить |
| `refNodeID` | `NodeID` | Идентификатор опорного узла (отрицательное значение — конец списка) |

#### Поведение

1. Проверка существования и непустоты родителя и нового узла.
2. Если `refNodeID >= 0` — ищется опорный узел; отрицательное значение означает вставку в конец.
3. Если новый узел — фрагмент, вызывается `insertFragmentChildrenLocked`, иначе:
   - Если у нового узла есть родитель, он удаляется через `RemoveChild`.
   - Новый узел добавляется в `parent.Children` перед `refNode` или в конец.
4. `css.InvalidateCache()` вызывается после вставки.

#### Возвращаемое значение

Ничего. Ошибки обрабатываются молча (типа `ok`).

---

### `insertFragmentChildrenLocked(parent, fragment, refNode *dom.Node)`

Вставляет всех детей фрагмента перед `refNode`.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `parent` | `*dom.Node` | Родительский узел |
| `fragment` | `*dom.Node` | Фрагмент для распаковки |
| `refNode` | `*dom.Node` | Опорный узел (или `nil`) |

#### Требования

- Вызыватель должен держать `nodeMu`.

#### Поведение

1. Копирует детей фрагмента в новый слайс.
2. Ищет индекс `refNode` в родителях.
3. Если `refNode` найден:
   - Разбивает `parent.Children` на две части перед и после `refNode`.
   - Вставляет детей фрагмента между ними.
4. Если `refNode` не найден или `nil` — вставляет всех детей в конец.
5. Устанавливает `Parent = parent` для всех детей фрагмента.
6. Очищает `fragment.Children = nil`.

---

### `replaceChild(parentID, newNodeID, oldNodeID NodeID)`

Заменяет существующий узел новым в родительском контейнере.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `parentID` | `NodeID` | Идентификатор родителя |
| `newNodeID` | `NodeID` | Идентификатор нового узла |
| `oldNodeID` | `NodeID` | Идентификатор узла для замены |

#### Поведение

1. Проверка существования всех трёх узлов.
2. Если `newNode` — фрагмент:
   - Ищет `oldNode` в `parent.Children`.
   - Если не найден — возвращает.
   - Удаляет `oldNode.Parent`.
   - Распаковывает `newNode` и вставляет детей вместо позиции `oldNode`.
   - `css.InvalidateCache()` вызывается.
3. Если `newNode` — обычный узел:
   - Удаляет `newNode` из текущего родителя.
   - Находит `oldNode` в `parent.Children` и заменяет на `newNode`.
4. `css.InvalidateCache()` вызывается.

---

### `insertAdjacentHTML(nodeID NodeID, position, html string)`

Вставляет парсинг HTML в узел по позиции.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `nodeID` | `NodeID` | Идентификатор целевого узла |
| `position` | `string` | Одно из: `beforebegin`, `afterbegin`, `beforeend`, `afterend` |
| `html` | `string` | HTML-строка для парсинга |

#### Позиции

| Позиция | Описание |
|---------|----------|
| `beforebegin` | Перед узлом (внутри родителя) |
| `afterbegin` | Сразу после открытия тега узла |
| `beforeend` | Сразу перед закрытием тега узла |
| `afterend` | После узла (внутри родителя) |

#### Поведение

1. Блокирует `nodeMu`, проверяет существование узла, разблокирует.
2. Парсит HTML через `dom.Parse("<fragment>" + html + "</fragment>")`.
3. Фильтрует только `ElementNode` из фрагмента.
4. Если детей нет — возвращает.
5. Выполняет соответствующую операцию в зависимости от `position`.
6. Вызывает `css.InvalidateCache()`.

---

### `insertAdjacentText(nodeID NodeID, position, text string)`

Вставляет текстовый узел в позицию.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `nodeID` | `NodeID` | Идентификатор целевого узла |
| `position` | `string` | Одно из: `beforebegin`, `afterbegin`, `beforeend`, `afterend` |
| `text` | `string` | Текстовое содержимое |

#### Поведение

1. Создаёт текстовый узел `&dom.Node{Type: dom.TextNode, Text: text}`.
2. Выполняет соответствующую операцию в зависимости от `position`.
3. Не вызывает `css.InvalidateCache()` (текст не влияет на CSS).

---

### `insertAdjacentElement(nodeID, elemID NodeID, position string)`

Вставляет существующий элемент в позицию.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `nodeID` | `NodeID` | Идентификатор целевого узла |
| `elemID` | `NodeID` | Идентификатор элемента для вставки |
| `position` | `string` | Одно из: `beforebegin`, `afterbegin`, `beforeend`, `afterend` |

#### Поведение

1. Проверка существования обоих узлов.
2. Удаляет элемент из текущего родителя.
3. Выполняет соответствующую операцию в зависимости от `position`.
4. Вызывает `css.InvalidateCache()`.

---

### `insertSiblingNodes(n *dom.Node, newNodes []*dom.Node, after bool)`

Всесторонняя функция для вставки списка узлов относительно существующего узла `n`.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `n` | `*dom.Node` | Узел-ориентир |
| `newNodes` | `[]*dom.Node` | Список узлов для вставки |
| `after` | `bool` | `true` — вставить после `n`, `false` — перед |

#### Поведение

1. Если у `n` нет родителя — возвращает.
2. Ищет индекс `n` в `parent.Children`.
3. Если не найден — возвращает.
4. Для каждого узла в `newNodes` устанавливает `Parent = parent`.
5. Если `after` — инкрементирует индекс.
6. Перестраивает `parent.Children` с новой вставкой.

## Внутренние детали

### Мьютекс `nodeMu`

- Используется для защиты от гонок при чтении/писании в `nodes` и `parent.Children`.
- В публичных функциях используется паттерн `Lock() ... Unlock()` с `defer`.

### Карта узлов `nodes`

- Тип: `map[NodeID]*dom.Node`
- Хранит все узлы по их ID.
- Пустые значения означают отсутствие узла.

### `css.InvalidateCache()`

- Вызывается после любых операций, изменяющих DOM (кроме текстовых вставок).
- Пересчитывает CSS-кэш для соответствующих элементов.

### `dom.Parse()`

- Используется для парсинга HTML-строки в `insertAdjacentHTML`.
- Обернут в фрагмент-обертку для упрощения обработки.

### `RemoveChild()`

- Метод `*dom.Node` для удаления дочернего узла из родителя.

### `Parent` и `Children`

- `Parent` — ссылочная связь узла с родителем.
- `Children` — слайс дочерних узлов (`*dom.Node`), хранится в родителе.

## Ошибки и границы

- Функции не возвращают ошибки — ошибки обрабатываются через возврат `nil` и молчаливое игнорирование.
- Проверки `ok` от слайса `nodes` гарантируют существование узла.
- Если узел не найден — функция возвращает без изменений.
- Если опорный узел не найден — вставка происходит в конец списка.
- Если фрагмент пуст — ничего не вставляется.

## Важные замечания

- Все операции вставки/замены требуют, чтобы узлы существовали в `nodes` и были непустыми.
- `css.InvalidateCache()` не вызывается при вставке текста (текст не влияет на стилизацию).
- Фрагменты автоматически распадаются на детей при вставке.
- `insertSiblingNodes` используется как вспомогательная для `insertAdjacentHTML` и `insertAdjacentText`.
- После операции вставки дети фрагмента теряют связь с фрагментом (`fragment.Children = nil`).
