# bridge_events

## Обзор

`bridge_events.go` — пакет Go для реализации обработчиков событий JavaScript через мост (bridge) между Go и JavaScriptCore. Файл содержит имплементацию функций, имитирующих API событий из JavaScript (setTimeout, setInterval, addEventListener, removeEventListener, dispatchEvent).

## Публичный API

### Функции

#### `setTimeoutJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Запускает отложенный вызов callback-функции.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — callback-функция
  - `args[1]` — задержка в миллисекундах

**Возвращаемое значение:**
- ID таймера (число)
- При ошибке или недостаточном количестве аргументов возвращает `0`

**Поведение:**
1. Проверяет количество аргументов (нужно минимум 2)
2. Преобразует callback к объекту
3. Преобразует задержку к числу
4. Вызывает внутреннюю функцию `setTimeout`
5. Возвращает ID таймера

#### `setIntervalJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Запускает периодический вызов callback-функции.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — callback-функция
  - `args[1]` — интервал в миллисекундах

**Возвращаемое значение:**
- ID интервала (число)
- При ошибке или недостаточном количестве аргументов возвращает `0`

**Поведение:**
1. Проверяет количество аргументов (нужно минимум 2)
2. Преобразует callback к объекту
3. Преобразует интервал к числу
4. Вызывает внутреннюю функцию `setInterval`
5. Возвращает ID интервала

#### `clearTimeoutJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Отменяет таймер, установленный через `setTimeoutJS`.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — ID таймера

**Возвращаемое значение:**
- `undefined` при успешном завершении или недостаточном количестве аргументов

**Поведение:**
1. Проверяет количество аргументов (нужен минимум 1)
2. Преобразует ID к числу
3. Вызывает внутреннюю функцию `clearTimer`
4. Возвращает `undefined`

#### `clearIntervalJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Отменяет интервал, установленный через `setIntervalJS`.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — ID интервала

**Возвращаемое значение:**
- `undefined` при успешном завершении или недостаточном количестве аргументов

**Поведение:**
1. Проверяет количество аргументов (нужен минимум 1)
2. Преобразует ID к числу
3. Вызывает внутреннюю функцию `clearTimer`
4. Возвращает `undefined`

#### `addEventListenerJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Добавляет обработчик события к элементу.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — DOM-элемент
  - `args[1]` — тип события
  - `args[2]` — callback-функция

**Возвращаемое значение:**
- `undefined` при успешном завершении или недостаточном количестве аргументов

**Поведение:**
1. Проверяет количество аргументов (нужно минимум 3)
2. Преобразует элемент к Node ID через `jsToNodeID`
3. Если ID < 0, возвращает `undefined`
4. Преобразует тип события к строке через `getArgString`
5. Преобразует callback к объекту
6. Вызывает внутреннюю функцию `addEventListener`
7. Возвращает `undefined`

#### `removeEventListenerJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Удаляет обработчик события из элемента.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — DOM-элемент
  - `args[1]` — тип события
  - `args[2]` — callback-функция

**Возвращаемое значение:**
- `undefined` при успешном завершении или недостаточном количестве аргументов

**Поведение:**
1. Проверяет количество аргументов (нужно минимум 3)
2. Преобразует элемент к Node ID через `jsToNodeID`
3. Если ID < 0, возвращает `undefined`
4. Преобразует тип события к строке через `getArgString`
5. Преобразует callback к объекту
6. Вызывает внутреннюю функцию `removeEventListener`
7. Возвращает `undefined`

#### `dispatchEventJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Вызывает событие на элементе.

**Параметры:**
- `ctx` — контекст JavaScriptCore
- `args` — массив JSValueRef, где:
  - `args[0]` — DOM-элемент
  - `args[1]` — тип события

**Возвращаемое значение:**
- `undefined` при успешном завершении или недостаточном количестве аргументов

**Поведение:**
1. Проверяет количество аргументов (нужно минимум 2)
2. Преобразует элемент к Node ID через `jsToNodeID`
3. Если ID < 0, возвращает `undefined`
4. Преобразует тип события к строке через `getArgString`
5. Вызывает внутреннюю функцию `dispatchEvent`
6. Возвращает `undefined`

## Внутренние функции (C)

Функции объявлены в заголовочных файлах C и импортируются через `import "C"`:

### `makeGoFunction(ctx, funcName)`
Создаёт Go-функцию в контекте JS.

### `_getType(ctx, value)`
Получает тип значения в JS.

### `_valueToString(ctx, value, exception)`
Конвертирует значение в строку.

### `_makeArray(ctx, values, count, exception)`
Создаёт массив из значений.

### `_fprintf_stderr(msg)`
Выводит сообщение на stderr.

### `_protectValue(ctx, value)`
Защищает значение от автоматического освобождения.

### `_unprotectValue(ctx, value)`
Снимает защиту с значения.

### `_callAsFunction(ctx, func, thisObj, argCount, args, exception)`
Вызывает функцию как конструктор.

### `_makeString(ctx, value)`
Создаёт строковое значение.

### `_makeBoolean(ctx, value)`
Создаёт булево значение.

## Внутренние функции (Go)

### `jsToNodeID(ctx, value) int`
Преобразует JS-значение к Node ID. Возвращает отрицательное число, если преобразование не удалось.

### `getArgString(ctx, value) (string, error)`
Преобразует аргумент к строке.

### `clearTimer(id int)`
Внутренняя функция для очистки таймера/интервала.

### `addEventListener(id, eventType, callback)`
Внутренняя функция для добавления обработчика события.

### `removeEventListener(id, eventType, callback)`
Внутренняя функция для удаления обработчика события.

### `dispatchEvent(id, eventType)`
Внутренняя функция для вызова события.

## Обработка ошибок

### Стратегия
- Ошибки обрабатываются явно при конвертации типов (`ctx.ToNumber`, `ctx.jsValueToObject`)
- При ошибках конвертации возвращается `undefined` или `0` в зависимости от функции
- Проверка количества аргументов выполняется перед обработкой

### Типы возвращаемых значений
- Успех: конкретное значение (ID таймера/интервала) или `undefined`
- Ошибка: `0` для числовых функций, `undefined` для функций событий

## Типы данных

### Входящие данные
- `*Context` — указатель на контекст JavaScriptCore
- `[]C.JSValueRef` — массив ссылок на значения JavaScript

### Выходные данные
- `C.JSValueRef` — ссылка на JS-значение
- `undefined` — для функций, возвращающих void

## Границы модуля

### Зависимости
- `#include <JavaScriptCore/JavaScriptCore.h>` — заголовочный файл JavaScriptCore
- `#include <stdlib.h>` — стандартная библиотека C
- `import "C"` — CGo импорт для доступа к C-функциям

### Экспорт
Все функции имеют префикс `JS` и доступны через мост для вызова из JavaScript.

## Архитектурные принципы

### Явное управление состоянием
- Каждая функция принимает контекст `ctx` явно
- Нет глобального состояния

### Проверка аргументов
- Все функции проверяют количество аргументов
- Ошибки преобразования типов обрабатываются явно

### Безопасность
- Callbackы проверяются на nil перед использованием
- Node ID проверяется на валидность (>= 0)

### Простота
- Каждая функция реализует одну задачу
- Нет сложных зависимостей между функциями

## Примеры использования

### Установка таймера
```go
ctx := &Context{...}
callback := C.JSValueToObject(ctx.ctx, args[0], nil)
id := setTimeoutJS(ctx, args)
```

### Добавление обработчика события
```go
id := jsToNodeID(ctx, args[0])
eventType, _ := getArgString(ctx, args[1])
callback := C.JSValueToObject(ctx.ctx, args[2], nil)
addEventListenerJS(ctx, args)
```

### Очистка таймера
```go
id, _ := ctx.ToNumber(args[0])
clearTimer(int(id))
clearTimeoutJS(ctx, args)
```

## Тестирование

Функции следует тестировать на:
- Нормальные случаи с корректными аргументами
- Нормальные случаи с `undefined` аргументами
- Неправильное количество аргументов
- Невалидные типы для числовых аргументов
- Невалидные DOM-элементы (Node ID < 0)
