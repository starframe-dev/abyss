# Спецификация: `internal/js/dom.go`

## Описание

Модуль `dom.go` реализует мост между Go-приложением и JavaScriptCore (JSC) для манипуляций DOM. Это низкоуровневый API, предоставляющий функции создания, удаления и модификации DOM-узлов, а также управления контекстом и перерисовкой.

## Архитектура

Модуль использует внешние C-функции для взаимодействия с JavaScriptCore:
- `_protectValue` / `_unprotectValue` — защита/снятие защиты JSValue
- `_callAsFunction` — вызов функции в JS
- `_makeString` / `_makeBoolean` — создание JS-значений
- `_evaluate` — оценка JavaScript-кода

## Глобальные переменные

## Типы

### `NodeID`

```go
type NodeID int
```

Уникальный идентификатор узла DOM. Интегрирован в карту `nodes`.

### `timer`

```go
type timer struct {
    ID       int
    Callback C.JSObjectRef
    Deadline time.Time
    Interval time.Duration
    Repeat   bool
}
```

Структура таймера для `setTimeout`/`setInterval`.

### `Context`

Внешний тип, представляющий контекст JavaScriptCore. Имеет метод `.Close()` для закрытия.

## Публичный API

### Управление контекстом JSC

#### `SetCurrentContext(ctx *Context, url string)`

**Описание:** Устанавливает активный контекст JavaScriptCore и URL документа для live-перерисовки.

**Параметры:**
- `ctx` — указатель на объект `Context`
- `url` — URL документа

**Побочные эффекты:**
- Если предыдущий контекст отличался от нового — закрывается
- `currentCtx` и `currentURL` обновляются

#### `GetCurrentContext() (*Context, string)`

**Описание:** Возвращает текущий активный контекст JSC и URL.

**Возвращает:**
- `*Context` — текущий контекст (может быть `nil`)
- `string` — URL документа

#### `CloseCurrentContext()`

**Описание:** Закрывает активный контекст JSC.

**Побочные эффекты:**
- Вызывается метод `.Close()` на `currentCtx`
- `currentCtx` обнуляется
- `currentURL` обнуляется

### Управление флагом перерисовки

#### `SetDirty()`

**Описание:** Помечает DOM как изменённый, инициируя перерисовку в браузере.

**Побочные эффекты:**
- Устанавливает `dirty = true`

#### `IsDirty() bool`

**Описание:** Проверяет, был ли DOM изменён с момента последней перерисовки.

**Возвращает:** `true` если изменения есть, `false` иначе

#### `MarkClean()`

**Описание:** Очищает флаг перерисовки после завершения отрисовки.

**Побочные эффекты:**
- Устанавливает `dirty = false`

### Инициализация DOM

#### `InitDOM(doc *dom.Node)`

**Описание:** Инициализирует состояние DOM с разобранного документа.

**Параметры:**
- `doc` — корневой узел документа

**Внутренние действия:**
1. Очистка карты `nodes`
2. Установка `rootDoc`
3. Вызов `assignIDs(doc)` для присвоения ID всем узлам

#### `assignIDs(n *dom.Node)`

**Описание:** Рекурсивно присваивает ID всем узлам в поддереве.

**Внутренние действия:**
1. Создание нового ID из `nodeNextID`
2. Сохранение узла в `nodes`
3. Рекурсия для всех дочерних узлов

### Создание узлов

#### `createElement(tagName string) *dom.Node`

**Описание:** Создаёт новый элемент узла.

**Параметры:**
- `tagName` — имя тега (преобразуется к нижнему регистру)

**Возвращает:** Созданный узел `*dom.Node`

**Побочные эффекты:**
- Создание новой структуры элемента
- Присвоение следующего доступного ID
- Сохранение в `nodes`

#### `createTextNode(text string) *dom.Node`

**Описание:** Создаёт новый текстовый узел.

**Параметры:**
- `text` — содержимое текста

**Возвращает:** Созданный текстовый узел `*dom.Node`

**Побочные эффекты:**
- Создание узла текстового типа
- Присвоение ID
- Сохранение в `nodes`

#### `createDocumentFragment() *dom.Node`

**Описание:** Создаёт новый фрагмент документа.

**Возвращает:** Созданный фрагмент `*dom.Node`

**Побочные эффекты:**
- Создание узла типа `DocumentFragmentNode` с именем `"#document-fragment"`
- Присвоение ID
- Сохранение в `nodes`

### Манипуляции с узлами

#### `appendChild(parentID, childID NodeID)`

**Описание:** Добавляет дочерний элемент к родителю. Фрагменты документов распаковываются.

**Параметры:**
- `parentID` — ID родительского узла
- `childID` — ID дочернего узла

**Поведение:**
1. Проверка существования обоих узлов
2. Если `child` — фрагмент документа:
   - Вызов `moveAllChildren(parent, child)`
3. Иначе:
   - Вызов `removeNodeFromParentLocked(child)`
   - Установка `child.Parent = parent`
   - Добавление в `parent.Children`

**Возвращает:** Ничего (void)

#### `removeChild(parentID, childID NodeID)`

**Описание:** Удаляет дочерний элемент из родителя.

**Параметры:**
- `parentID` — ID родительского узла
- `childID` — ID удаляемого узла

**Поведение:**
1. Поиск `child` в `parent.Children`
2. Удаление из слайса
3. Установка `child.Parent = nil`

**Возвращает:** Ничего (void)

#### `setInnerHTML(id NodeID, html string)`

**Описание:** Устанавливает внутренний HTML узла с парсингом.

**Параметры:**
- `id` — ID узла
- `html` — HTML-строка для парсинга

**Поведение:**
1. Поиск узла по ID
2. Парсинг HTML через `dom.Parse(html)`
3. Очистка существующих дочерних узлов
4. Установка `child.Parent = node`
5. Добавление всех новых дочерних узлов
6. Вызов `assignIDsToNew(doc)` для присвоения ID новым узлам

**Возвращает:** Ничего (void)

#### `setAttribute(id NodeID, name, value string)`

**Описание:** Устанавливает атрибут узла.

**Параметры:**
- `id` — ID узла
- `name` — имя атрибута (преобразуется к нижнему регистру)
- `value` — значение атрибута

**Поведение:**
1. Поиск узла
2. Инициализация `Attributes` если nil
3. Установка атрибута в нижнем регистре

**Возвращает:** Ничего (void)

#### `setTextContent(id NodeID, text string)`

**Описание:** Устанавливает текстовое содержимое узла.

**Параметры:**
- `id` — ID узла
- `text` — текстовое содержимое

**Поведение:**
1. Поиск узла
2. Очистка существующих дочерних узлов
3. Создание нового текстового узла
4. Установка `tn.Parent = node`
5. Добавление в `node.Children`
6. Присвоение ID новому узлу

**Возвращает:** Ничего (void)

### Получение информации об узлах

#### `getBody() *dom.Node`

**Описание:** Возвращает элемент `body` документа.

**Поведение:**
1. Проверка существования `rootDoc`
2. Поиск `html` элемента в `rootDoc.Children`
3. Поиск `body` элемента внутри `html`
4. Возврат найденного узла или `nil`

**Возвращает:** Узел `body` или `nil` если не найден

#### `getElementByID(id string) *dom.Node`

**Описание:** Ищет элемент по атрибуту `id`.

**Параметры:**
- `id` — значение атрибута `id`

**Поведение:**
1. Перебор всех узлов в `nodes`
2. Проверка типа `ElementNode` и атрибута `id`
3. Возврат первого совпадения или `nil`

**Возвращает:** Найденный элемент или `nil`

#### `getAttribute(id NodeID, name string) string`

**Описание:** Возвращает значение атрибута узла.

**Параметры:**
- `id` — ID узла
- `name` — имя атрибута

**Поведение:**
1. Поиск узла
2. Вызов метода `.GetAttr(name)` на узле

**Возвращает:** Значение атрибута или пустая строка если атрибут не найден

#### `getNodeID(n *dom.Node) NodeID`

**Описание:** Возвращает ID узла.

**Параметры:**
- `n` — указатель на узел

**Поведение:**
1. Перебор карты `nodes`
2. Поиск совпадения по указателю
3. Возврат найденного ID или `-1` если не найден

**Возвращает:** ID узла или `-1`

### Внутренние функции

#### `assignIDsToNew(n *dom.Node)`

**Описание:** Рекурсивно присваивает ID узлам, которые ещё не имеют ID.

**Поведение:**
1. Проверка существования узла в `nodes`
2. Если нет:
   - Присвоение нового ID из `nodeNextID`
   - Увеличение счётчика
   - Сохранение в `nodes`
3. Рекурсия для всех дочерних узлов

#### `removeNodeFromParentLocked(child *dom.Node)`

**Описание:** Удаляет узел из его родителя (должно быть зажат `nodeMu`).

**Поведение:**
1. Проверка существования родителя
2. Поиск узла в слайсе `parent.Children`
3. Удаление из слайса через срез

#### `moveAllChildren(parent, source *dom.Node)`

**Описание:** Перемещает всех детей из `source` в `parent`.

**Поведение:**
1. Копирование всех детей из `source`
2. Для каждого ребёнка:
   - Установка `child.Parent = nil`
   - Установка `child.Parent = parent`
   - Добавление в `parent.Children`
3. Установление `source.Children = nil`

## Внешние зависимости

### `github.com/starframe/abyss/internal/css`

Используется тип `css.ComputedStyle` для кэширования вычисленных стилей.

### `github.com/starframe/abyss/internal/dom`

Используется тип `dom.Node` для представления узлов DOM. Предоставляет методы:
- `.Type` — тип узла (`ElementNode`, `TextNode`, `DocumentFragmentNode`)
- `.TagName` — имя тега
- `.Children` — слайс дочерних узлов
- `.Parent` — родительский узел
- `.Attributes` — карта атрибутов
- `.GetAttr(name string) string` — получение атрибута

### `C`

Внешние C-функции для взаимодействия с JavaScriptCore:
- `JSContextRef` — контекст JSC
- `JSValueRef` — JS значение
- `JSObjectRef` — JS объект
- `JSGlobalContextRef` — глобальный контекст
- `C.JSObjectRef` — тип для JS объектов в Go

## Паттерны и принципы

### Инверсия контроля (IoC)

Использование внешних C-функций для инверсии контроля над JSC.

### Стратегия

Разделение на:
- `Context` — контекст JSC
- `Node` — узел DOM
- `timer` — таймер

### Флаги состояния

Использование атомарных флагов (`dirty`, `repeat`) с блокировками для синхронизации.

### Кэширование

- `computedStyles` — кэш вычисленных стилей
- `layoutBoxes` — кэш лейаут-боксов
- `nodes` — карта узлов по ID

### Рекурсия

- `assignIDs()` — рекурсивное присвоение ID
- `assignIDsToNew()` — рекурсивное присвоение ID новым узлам

## Поток выполнения

### Инициализация

1. Вызов `InitDOM(doc)`
2. Создание корневых узлов через `createElement()`
3. Добавление детей через `appendChild()`
4. Инициализация контекста через `SetCurrentContext()`
5. Установка слушателей событий через внешние C-функции

### Перерисовка

1. Изменение DOM через публичный API
2. Вызов `SetDirty()`
3. Браузер вызывает `IsDirty()`
4. При `true` — вызов live-рендеринга через `currentCtx`
5. После завершения — вызов `MarkClean()`

### Таймеры

1. Создание таймера через внешние C-функции
2. Сохранение в `timers`
3. При наступлении дедлайна — вызов `Callback`
4. При `Repeat = true` — перезапуск таймера

## Обработка ошибок

- Возврат `nil` вместо паники при отсутствии узла
- Возврат `""` (пустая строка) при отсутствии атрибута
- Возврат `-1` при невозможности найти ID
- Явная проверка существования узлов через `ok`

## thread-safety

Все функции, модифицирующие глобальное состояние, используют соответствующие `sync.Mutex`:
- `nodeMu` — операции с узлами
- `computedStylesMu` — операции с кэшем стилей
- `layoutBoxesMu` — операции с кэшем лейаута
- `eventMu` — операции с слушателями событий
- `currentCtxMu` — операции с контекстом
- `dirtyMu` — операции с флагом перерисовки
- `timerMu` — операции с таймерами

## Известные ограничения

1. Нет явной обработки ошибок при создании узлов
2. Нет валидации HTML при `setInnerHTML`
3. Нет обработки ошибок при работе с таймерами
4. Нет обработки случаев, когда узел уже удалён
