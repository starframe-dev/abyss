# Спецификация: `internal/js/domapi/style.js`

## Описание

Фрагмент JS DOM API: `CSSStyleDeclaration` / `style` на элементах. Встраивается через `domapi_embed.go` внутрь IIFE вместе с `element.js` и `global.js`.

## Ответственность

- чтение и запись inline-стилей;
- мост к Go через существующие bridge-функции стилей.

Не является отдельным модулем рантайма: только исходный фрагмент для конкатенации.
