# Спецификация: `domapi_embed.go`

## Обзор

Файл встраивает JavaScript-фрагменты DOM API в Go-бинарник и объединяет их в одну строку IIFE. Фрагменты встраиваются директивой `go:embed` из `domapi/*.js` и считываются из встроенной файловой системы `embed.FS`.

## Переменные

- `domapiFiles` — встроенная файловая система, содержащая файлы, совпадающие с шаблоном `domapi/*.js`.
- `domapiFragments` — список имён фрагментов в порядке загрузки: `style`, `element`, `global`. Фрагменты используют общую область видимости IIFE.
- `domapiJSSource` — строка, инициализируемая при инициализации пакета вызовом `loadDOMAPI()`.

## `loadDOMAPI() string`

Создаёт срез частей с ёмкостью, равной числу фрагментов, и последовательно для каждого имени из `domapiFragments` читает `domapi/<имя>.js` из `domapiFiles`. Успешно прочитанные байты преобразуются в строки и добавляются в срез.

Если чтение любого файла завершается ошибкой, функция вызывает `panic` с сообщением `cannot load embedded domapi fragment <имя>.js: <ошибка>`; частичный результат не возвращается.

После чтения функция соединяет части символом новой строки и оборачивает результат в `(function() {\n` и `\n})()\n`. Фрагменты выполняются в общей области видимости этого IIFE.

## Зависимости и ограничения

- Все необходимые файлы должны соответствовать шаблону `domapi/*.js` при компиляции; иначе директива `go:embed` не позволит собрать пакет.
- Каждый файл, указанный в `domapiFragments`, должен присутствовать во встроенной файловой системе. Ошибка чтения приводит к `panic`.
- Фрагменты объединяются именно в порядке списка `domapiFragments`.
