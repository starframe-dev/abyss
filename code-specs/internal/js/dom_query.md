# Спецификация: dom_query

## Обзор

Файл `dom_query.go` реализует набор функций для работы с DOM-деревом в пакете `js`. Функции предоставляют интерфейс, аналогичный стандартной DOM-API JavaScript, с синтаксисом Go и использованием блокировок для многопоточной безопасности.

## Публичный API

### Типы

#### NodeID

Тип `NodeID` — идентификатор узла DOM (предположительно `int64` или аналогичный тип). Используется для идентификации узлов в глобальной карте `nodes`.

## Функции

### getParentNode(id NodeID) *dom.Node

**Описание:** Возвращает родительский узел для заданного узла.

**Параметры:**
- `id NodeID` — идентификатор узла

**Возвращаемое значение:**
- `*dom.Node` — родительский узел или `nil`, если узел не найден

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Ищет узел в глобальной карте `nodes[id]`
3. Если узел не найден, возвращает `nil`
4. Возвращает поле `Parent` найденного узла

---

### getChildren(id NodeID) []*dom.Node

**Описание:** Возвращает массив дочерних узлов для заданного узла.

**Параметры:**
- `id NodeID` — идентификатор узла

**Возвращаемое значение:**
- `[]*dom.Node` — срез дочерних узлов или `nil` (пустой срез), если узел не найден

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Ищет узел в глобальной карте `nodes[id]`
3. Если узел не найден, возвращает `nil`
4. Возвращает поле `Children` найденного узла

---

### getElementsByTagName(tagName string) []*dom.Node

**Описание:** Возвращает все элементы с заданным именем тега (case-insensitive).

**Параметры:**
- `tagName string` — имя тега

**Возвращаемое значение:**
- `[]*dom.Node` — срез элементов с заданным именем тега или `nil` (пустой срез)

**Поведение:**
1. Приводит `tagName` к нижнему регистру
2. Заблокирует и разблокирует глобальную mutex `nodeMu`
3. Проходит по всем узлам в карте `nodes`
4. Фильтрует узлы типа `dom.ElementNode` с совпадающим именем тега (case-insensitive)
5. Возвращает срез найденных элементов

---

### getElementsByClassName(className string) []*dom.Node

**Описание:** Возвращает все элементы, содержащие заданный класс.

**Параметры:**
- `className string` — имя класса

**Возвращаемое значение:**
- `[]*dom.Node` — срез элементов с заданным классом или `nil` (пустой срез)

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Проходит по всем узлам в карте `nodes`
3. Фильтрует узлы типа `dom.ElementNode` с непустым атрибутом `class`
4. Парсит классы через `strings.Fields` (пробел как разделитель)
5. Ищет точное совпадение класса в списке классов элемента
6. Добавляет элемент к результату и прерывает цикл после первого совпадения для этого класса
7. Возвращает срез найденных элементов

**Примечание:** Для каждого класса находит только один элемент, содержащий этот класс.

---

### querySelector(nodeID NodeID, selector string) *dom.Node

**Описание:** Возвращает первый элемент, соответствующий CSS-селектору, найденный в заданном узле.

**Параметры:**
- `nodeID NodeID` — идентификатор корневой узла для поиска
- `selector string` — CSS-селектор

**Возвращаемое значение:**
- `*dom.Node` — первый совпадающий элемент или `nil`, если не найден

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Ищет узел по `nodeID` в карте `nodes`
3. Если узел не найден или `nil`, возвращает `nil`
4. Вызывает метод `QuerySelector(selector)` на узле
5. Возвращает результат

---

### matches(nodeID NodeID, selector string) bool

**Описание:** Проверяет, соответствует ли узел заданному CSS-селектору.

**Параметры:**
- `nodeID NodeID` — идентификатор узла
- `selector string` — CSS-селектор

**Возвращаемое значение:**
- `bool` — `true`, если узел соответствует селектору; `false` иначе

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu` (без defer)
2. Ищет узел по `nodeID` в карте `nodes`
3. Если узел не найден или `nil`, возвращает `false`
4. Вызывает метод `Matches(selector)` на узле
5. Возвращает результат

---

**Поведение:**

### cloneNode(nodeID NodeID, deep bool) *dom.Node

**Описание:** Клонирует узел (глубокое или поверхностное копирование) и регистрирует клон в глобальной карте.

**Параметры:**
- `nodeID NodeID` — идентификатор узла для клонирования
- `deep bool` — `true` для глубокого копирования, `false` для поверхностного

**Возвращаемое значение:**
- `*dom.Node` — клон узла или `nil`, если исходный узел не найден или клонирование не удалось

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Ищет узел по `nodeID` в карте `nodes`
3. Если узел не найден или `nil`, возвращает `nil`
4. Вызывает метод `Clone(deep)` на узле
5. Если клон `nil`, возвращает `nil`
6. Второй раз блокирует `nodeMu` для регистрации клона
7. Присваивает `nodeNextID` как новый идентификатор клона
8. Увеличивает `nodeNextID`
9. Регистрирует клон в карте `nodes[id] = clone`
10. Разблокирует `nodeMu`
11. Возвращает клон

**Примечание:**
- После клонирования новый узел регистрируется в глобальной карте `nodes`
- `nodeNextID` используется как счётчик для генерации новых идентификаторов

---

### contains(parentID, childID) bool

**Описание:** Проверяет, содержит ли родительский узел дочерний узел (включая сам себя).

**Параметры:**
- `parentID NodeID` — идентификатор родительского узла
- `childID NodeID` — идентификатор дочернего узла

**Возвращаемое значение:**
- `bool` — `true`, если `parentID` содержит `childID`; `false` иначе

**Поведение:**
1. Если `parentID == childID`, возвращает `true` (узел содержит сам себя)
2. Заблокирует и разблокирует глобальную mutex `nodeMu`
3. Ищет родительский и дочерний узлы в карте `nodes`
4. Если один из узлов не найден или `nil`, возвращает `false`
5. Присваивает `parent` и `child` из найденных узлов
6. Разблокирует `nodeMu`
7. Проходит по цепочке `Parent` от `child` до корня
8. Если находит `parent` в цепочке, возвращает `true`
9. Возвращает `false`, если не найден

---

### previousElementSibling(nodeID NodeID) *dom.Node

**Описание:** Возвращает предыдущего сестру-элемент узла.

**Параметры:**
- `nodeID NodeID` — идентификатор узла

**Возвращаемое значение:**
- `*dom.Node` — предыдущий сестра-элемент или `nil`

**Поведение:**
1. Заблокирует и разблокирует глобальную mutex `nodeMu`
2. Ищет узел по `nodeID` в карте `nodes`
3. Если узел не найден или `nil` или родитель не найден, возвращает `nil`
4. Получает родительский узел
5. Перебирает детей родителя с конца в начало
6. Приходит к текущему узлу, устанавливает флаг `found = true`, пропускает
7. Если `found` и текущий узел типа `dom.ElementNode`, возвращает его
8. Возвращает `nil`, если не найден

## Внутренние детали

### Глобальные переменные

#### nodeMu

Глобальная mutex для защиты доступа к карте узлов `nodes` из нескольких потоков.

#### nodes

Глобальная карта, хранящая все узлы DOM по их идентификаторам `NodeID` -> `*dom.Node`.

#### nodeNextID

Счётчик для генерации новых идентификаторов для клонированных узлов.

### Паттерн использования

Функции используют паттерн "parse, don't validate" — входные параметры принимаются как есть, и функции работают с ними, возвращая `nil` или `false` в случае ошибок, а не вызывая паники.

### Безопасность потока

Все функции, работающие с глобальной картой `nodes`, используют блокировку `nodeMu` для предотвращения гонок данных. В `contains`, `querySelector`, `querySelectorAll` и `matches` блокировка используется дважды (без defer во втором случае) для минимизации времени блокировки.

### Обработка ошибок

Функции не возвращают ошибки — они возвращают `nil` или пустой срез в случае отсутствия узла или нехватки данных. Это соответствует паттерну `Result<T, E>` в стиле Go.
