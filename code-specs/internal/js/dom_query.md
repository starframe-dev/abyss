# Спецификация: dom_query

## Обзор

Файл `dom_query.go` содержит функции пакета `js` для поиска и навигации по DOM-узлам, проверки селекторов и клонирования узлов. Функции используют карту `nodes` и mutex `nodeMu`; некоторые возвращают узлы или срезы непосредственно, не копируя их.

## Функции

### `getParentNode(id NodeID) *dom.Node`
Блокирует `nodeMu`, ищет `nodes[id]`, возвращает `nil`, если запись отсутствует, иначе возвращает поле `Parent`.

### `getChildren(id NodeID) []*dom.Node`
Блокирует `nodeMu`, ищет `nodes[id]`, возвращает `nil`, если запись отсутствует, иначе возвращает поле `Children`.

### `getElementsByTagName(tagName string) []*dom.Node`
Под блокировкой перебирает `nodes`; приводит аргумент и теги к нижнему регистру и добавляет в результат все узлы типа `dom.ElementNode` с совпадающим тегом. Порядок обхода карты не гарантирован. При отсутствии совпадений возвращается nil-срез.

### `getElementsByClassName(className string) []*dom.Node`
Под блокировкой перебирает `nodes` и проверяет только узлы типа `dom.ElementNode` с непустым атрибутом `class`. Разбивает его с помощью `strings.Fields`; при точном совпадении одного из токенов добавляет узел один раз. Порядок результата не гарантирован. При отсутствии совпадений возвращается nil-срез.

### `querySelector(nodeID NodeID, selector string) *dom.Node`
Под блокировкой ищет корневой узел в `nodes`. Если запись отсутствует или значение равно nil, возвращает nil; иначе вызывает и возвращает результат `QuerySelector(selector)`.

### `querySelectorAll(nodeID NodeID, selector string) []*dom.Node`
Под блокировкой ищет корневой узел в `nodes`. Если запись отсутствует или значение равно nil, возвращает nil; иначе вызывает и возвращает результат `QueryAll(selector)`.

### `matches(nodeID NodeID, selector string) bool`
Блокирует mutex только на время чтения `nodes[nodeID]`, затем разблокирует. Если запись отсутствует или узел nil, возвращает false; иначе вызывает `Matches(selector)` и возвращает результат.

### `closest(nodeID NodeID, selector string) *dom.Node`
Блокирует mutex только на время чтения `nodes[nodeID]`, затем разблокирует. Если запись отсутствует или узел nil, возвращает nil; иначе вызывает `Closest(selector)` и возвращает результат.

### `cloneNode(nodeID NodeID, deep bool) *dom.Node`
Под блокировкой проверяет, что узел существует и не nil, и что `len(nodes) < dom.MaxDOMNodes`. Иначе возвращает nil. Вызывает `Clone(deep)`; при nil-клоне возвращает nil. Затем вызывает `assignIDsToNew(clone)` (ожидая, что mutex уже удерживается). Если после этого указатель клона отсутствует в `nodeIDs`, возвращает nil; иначе возвращает клон. Присвоение идентификаторов и регистрация выполняются вспомогательной функцией; эта функция сама не увеличивает `nodeNextID` и напрямую не записывает клон в `nodes`.

### `contains(parentID, childID NodeID) bool`
Если идентификаторы равны, сразу возвращает true, не проверяя наличие узла в карте. Иначе под блокировкой считывает оба узла и разблокирует mutex. Если какая-либо запись отсутствует или значение равно nil, возвращает false. Затем проходит по цепочке `Parent` от дочернего узла вверх, включая его самого; возвращает true при совпадении указателя с родительским узлом, иначе false.

### `previousElementSibling(nodeID NodeID) *dom.Node`
Блокирует mutex только для чтения `nodes[nodeID]`, затем разблокирует. Возвращает nil при отсутствующей записи, nil-узле или отсутствии родителя. Перебирает `Parent.Children` с конца; после встречи текущего узла возвращает первый встреченный ранее элементный узел. Если текущий узел не встретился или подходящего соседа нет, возвращает nil.

### `nextElementSibling(nodeID NodeID) *dom.Node`
Аналогично `previousElementSibling`, но перебирает `Parent.Children` с начала и возвращает первый элементный узел после текущего. Если текущий узел не встретился или подходящего соседа нет, возвращает nil.

### `firstElementChild(nodeID NodeID) *dom.Node`
Блокирует mutex только для чтения `nodes[nodeID]`, затем разблокирует. При отсутствии записи или nil-узле возвращает nil. Иначе возвращает первого ребёнка типа `dom.ElementNode`, либо nil, если такого нет.

### `lastElementChild(nodeID NodeID) *dom.Node`
Аналогично `firstElementChild`, но перебирает детей с конца и возвращает последнего ребёнка типа `dom.ElementNode`, либо nil.

## Примечания о синхронизации

Все обращения к карте `nodes` в этих функциях защищены `nodeMu`. Для `matches`, `closest`, `contains` и функций навигации mutex освобождается до обращения к структуре узла; следовательно, эта блокировка защищает чтение карты, но не гарантирует отсутствие конкурентных изменений самих узлов после разблокировки. Функции `getParentNode`, `getChildren`, `getElementsByTagName`, `getElementsByClassName`, `querySelector`, `querySelectorAll` и `cloneNode` удерживают mutex на время соответствующей операции.
