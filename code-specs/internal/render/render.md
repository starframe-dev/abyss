# Specification: internal/render/render

## Обзор

Пакет `internal/render` отвечает за отрисовку дерева разметки в буфер кадров пикселей (framebuffer). Он преобразует структуру DOM (LayoutBox) с CSS-стилями в визуальное представление.

## Публичный API

### `Render`

```go
func Render(tree *layout.LayoutBox, viewportWidth int) *framebuffer.Framebuffer
```

**Описание:**
Основная функция пакета. Рисует дерево разметки в буфер кадров.

**Параметры:**
- `tree` — корневой элемент дерева разметки. Если `nil`, возвращается пустой буфер 1x1 пикселя.
- `viewportWidth` — ширина области просмотра в пикселях.

**Возвращаемое значение:**
- `*framebuffer.Framebuffer` — заполненный буфер кадров, готовый к отображению.

**Поведение:**
1. Если передан `nil`, возвращает пустой буфер 1x1.
2. Собирает все элементы дерева (рекурсивно).
3. Вычисляет минимальный offset по X и Y (берётся из наименьших margin).
4. Сдвигает координаты дерева на вычисленный offset.
5. Вычисляет высоту необходимого буфера.
6. Создаёт буфер с заданной шириной и вычисленной высотой.
7. Очищает буфер цветом фона (по умолчанию белый, или цвет из стиля body).
8. Сортирует элементы по z-index (стабильная сортировка, чтобы сохранить порядок DOM для равных z-index).
9. Рисует каждый элемент через `drawBox`.

## Внутренние функции

### `collectBoxes`

```go
func collectBoxes(box *layout.LayoutBox, boxes *[]*layout.LayoutBox)
```

**Описание:**
Рекурсивно собирает все `LayoutBox` в дерево в плоский слайс.

**Поведение:**
- Добавляет текущую коробку в слайс.
- Рекурсивно обрабатывает всех детей.
- Порядок в слайсе соответствует preorder обходу DOM.

---

### `calculateOffset`

```go
func calculateOffset(boxes []*layout.LayoutBox) (float64, float64)
```

**Описание:**
Вычисляет минимальные координаты X и Y по всем margin.

**Возвращаемое значение:**
- `(float64, float64)` — минимальные координаты для сдвига.

**Поведение:**
- Инициализирует minX и minY нулями.
- Проходит по всем коробкам и обновляет минимумы.
- Возвращает отрицательные значения, если margin имеет отрицательные координаты.

---

### `calculateHeight`

```go
func calculateHeight(box *layout.LayoutBox) int
```

**Описание:**
Вычисляет необходимую высоту буфера, учитывая текущую коробку и всех потомков.

**Возвращаемое значение:**
- `int` — высота в пикселях.

**Поведение:**
- Берёт maxY из margin.Y + margin.Height текущей коробки.
- Рекурсивно проходит по детям.
- Возвращает максимальную высоту среди всех потомков.

---

### `shiftTree`

```go
func shiftTree(box *layout.LayoutBox, offX, offY float64)
```

**Описание:**
Сдвигает координаты всех полей коробки и её потомков.

**Параметры:**
- `offX`, `offY` — значения сдвига.

**Поведение:**
- Обновляет поля X и Y для:
  - `Content`
  - `Padding`
  - `Border`
  - `Margin`
  - `TextLines` (для каждой строки текста)
- Рекурсивно применяет сдвиг ко всем детям.

---

### `drawBox`

```go
func drawBox(fb *framebuffer.Framebuffer, box *layout.LayoutBox)
```

**Описание:**
Рисует одну коробку на framebuffer.

**Поведение:**
1. **Фон:** Если задан `BackgroundColor`, рисует закруглённый прямоугольник через `fb.DrawRoundedRect`.
   - Координаты берутся из `Border.X`, `Border.Y`.
   - Размеры — из `Border.Width`, `Border.Height`.
   - Радиусы — вычисляются через `Resolve()` с учётом ширины границы.
2. **Граница:** Если заданы границы хотя бы на одной стороне, рисует через `fb.DrawBorder`.
   - Координаты и размеры берутся из `Border`.
   - Толщины и цвета берутся из соответствующих полей стиля.

## Типы

### `LayoutBox` (из пакета `layout`)

Коробка в дереве разметки. Содержит:
- `Children` — список дочерних коробок.
- `Style` — объект стилей с полями:
  - `BackgroundColor` — цвет фона.
  - `ZIndex` — z-index для сортировки.
  - `BorderTop/Bottom/Left/Right` — толщины и стили границ.
  - `BorderRadiusTopLeft/TopRight/BottomRight/BottomLeft` — радиусы закругления.
  - `Border` — объект с полями `X`, `Y`, `Width`, `Height`.
  - `Margin` — объект с полями `X`, `Y`, `Width`, `Height`.
  - `Padding` — объект с полями `X`, `Y`, `Width`, `Height`.
- `Content` — объект с полями `X`, `Y`, `Width`, `Height`.
- `TextLines` — массив строк текста с полями `X`, `Y`.

## Важные детали реализации

### Сортировка по z-index

Используется `sort.SliceStable`, чтобы:
- Меньшие z-index рисуются первыми.
- При равных z-index сохраняется порядок preorder DOM (потомки рисуются поверх предков согласно нормам paint order).

### Обработка фона

- Если `tree` — `nil`, фон не устанавливается (возвращается пустой буфер).
- Иначе берётся цвет из `tree.Style.BackgroundColor`, если поле `IsSet` истинно.
- Иначе используется белый цвет `(255, 255, 255)`.

### Обработка границ

Граница рисуется только если хотя бы одна из сторон не имеет стиль `BorderNone`.

### Вычисление высоты

Высота включает:
- margin.Y текущей коробки.
- margin.Height текущей коробки.
- максимальную высоту среди всех потомков (рекурсивно).

### Сдвиг координат

Сдвиг применяется ко всем координатным полям и ко всем потомкам рекурсивно. Это гарантирует, что координаты остаются корректными после нормализации отрицательных значений.
