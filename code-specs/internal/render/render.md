# Спецификация: internal/render/render

## Обзор

Пакет `internal/render` рисует дерево `layout.LayoutBox` в пиксельный framebuffer. Помимо CSS-фонов и границ, он поддерживает поверхность для пустых полей ввода и преобразование доступных изображений в ASCII-ячейки.

## Публичный API

### `ImageProvider`

Переменная-функция `func(src string) image.Image`. Возвращает декодированное изображение для URL `src` либо `nil`, если изображение недоступно. Вызывающая сторона задаёт provider при запуске. Без provider реальные изображения не создаются.

### `Render`

```go
func Render(tree *layout.LayoutBox, viewportWidth int) *framebuffer.Framebuffer
```

Если `tree == nil`, возвращает framebuffer размером 1x1. Иначе собирает коробки preorder, вычисляет минимальные `Margin.X` и `Margin.Y` (начальные минимумы — нули), сдвигает координаты всего дерева на отрицательные минимумы, вычисляет высоту по `calculateHeight`, создаёт framebuffer шириной `viewportWidth`, очищает его цветом фона корня либо белым `(255,255,255)`, затем стабильно сортирует коробки по возрастанию `ZIndex` и рисует их. При равном z-index сохраняется preorder.

## Внутренние функции

- `collectBoxes(box, boxes)` добавляет текущую коробку, затем рекурсивно детей; результат — preorder.
- `calculateOffset(boxes)` возвращает минимумы `Margin.X/Y`, каждый изначально равен нулю.
- `calculateHeight(box)` начинает с `int(box.Margin.Y + box.Margin.Height)`, рекурсивно выбирает максимум с результатами детей.
- `shiftTree(box, offX, offY)` прибавляет смещения ко всем X/Y координатам `Content`, `Padding`, `Border`, `Margin` и каждой строки `TextLines`, затем рекурсивно сдвигает детей.
- `drawBox(fb, box)` рисует фон и границу. Если задан `BackgroundColor`, рисует скруглённый прямоугольник в `Border` с радиусами, полученными через `Resolve(box.Border.Width)`. Иначе для `input`/`textarea` с положительной высотой границы рисует серую поверхность RGB(241,243,244) со всеми радиусами, равными половине высоты. Иначе для `img` пытается отрисовать ASCII-изображение; если оно недоступно и позиция не absolute, рисует скруглённую заглушку RGB(226,232,240) с радиусами 4. После этого при наличии хотя бы одной границы не `BorderNone` вызывает `DrawBorder` с координатами и размерами `Border`, толщинами и цветами сторон из стиля.
- `quantizeImageBox(box)` возвращает уже сохранённые `AsciiCells`, если они заданы. Иначе проверяет node, provider, непустой `src` и доступность изображения. Размер сетки определяется `Content.Width / cellmetrics.WidthPx` и `Content.Height / cellmetrics.HeightPx`, с минимумом 1 ячейка по каждому измерению. Цвет фона берётся из стиля коробки либо RGB(226,232,240). Квантует изображение через `asciirender.Quantize`, сохраняет результат в `AsciiCells`, очищает `TextLines` от placeholder-текста и возвращает сетку.
- `drawAsciiCells(fb, box, grid)` раскладывает сетку по области `Border`; ширина и высота ячеек — размеры этой области, делённые на размеры сетки, с минимумом 1. Для каждой ячейки с установленным `FG` заполняет соответствующий прямоугольник; ширина ограничивается правым краем framebuffer.

## Зависимости

Используются `image`, `sort`, а также внутренние пакеты `asciirender`, `cellmetrics`, `css`, `framebuffer` и `layout`.
