# Спецификация пакета ascii

## Обзор

Пакет `ascii` преобразует framebuffer в ASCII-арт с поддержкой ANSI-кодов цветов. Пакет предназначен для рендеринга текстового представления графического контента, который может быть отображен в терминале или использоваться в E2E-тестах.

## Публичный API

### Тип Cell

```go
type Cell struct {
    Char rune
    FG   css.Color
    BG   css.Color
}
```

Поле `Char` хранит символ терминала (буквально или пробел). Поля `FG` и `BG` содержат цвета переднего и заднего плана соответственно.

### Функция Render

```go
func Render(fb *framebuffer.Framebuffer, tree *layout.LayoutBox, viewportWidth int) []string
```

Преобразует дерево layout из framebuffer в строки обычного текста (без ANSI-кодов).

**Параметры:**
- `fb` — указатель на framebuffer, содержащий визуальную информацию
- `tree` — дерево layout с текстовыми оверлеями
- `viewportWidth` — максимальная ширина вывода в символах

**Возвращает:**
- `[]string` — массив строк, представляющих каждый ряд экрана

**Поведение:**
1. Если `fb` или `fb.Width` недействительны, возвращает `[]string{""}`
2. Вычисляет количество рядов: `numRows = fb.Height / 2` (с коррекцией нечётного `Height`)
3. Создаёт сетку из ячеек, используя `makeGrid`
4. Применяет текстовые оверлеи через `overlayText`
5. Возвращает обычные строки через `renderPlain`

### Функция RenderANSI

```go
func RenderANSI(fb *framebuffer.Framebuffer, tree *layout.LayoutBox, viewportWidth int) []string
```

Преобразует framebuffer в ANSI-цвета для отображения в терминале.

**Параметры:** те же, что у `Render`.

**Возвращает:** тот же тип, что и `Render`.

**Отличие от Render:** возвращает строки с ANSI-кодами цветов, а не чистый текст.

## Внутренняя реализация

### Функция makeGrid

```go
func makeGrid(fb *framebuffer.Framebuffer, numRows int) [][]Cell
```

Создаёт двумерную сетку ячеек на основе framebuffer. Каждый ряд сетки соответствует двум рядам framebuffer (сжатие по вертикали). Для каждого столбца выбирается один символ и цвета, комбинируя верхнюю и нижнюю ячейки framebuffer.

### Функция chooseChar

```go
func chooseChar(top, bottom css.Color) (string, css.Color, css.Color)
```

Выбирает символ и цвета для ячейки на основе цветов верхней и нижней частей пикселя.

**Логика:**
- Если оба цвета не установлены: возвращает пробел и прозрачные цвета
- Если `top.IsSet`: возвращает пробел, прозрачный FG, цвет top как BG
- Иначе: возвращает пробел, прозрачный FG, цвет bottom как BG

### Функция renderANSI

```go
func renderANSI(grid [][]Cell, maxWidth int) []string
```

Преобразует сетку ячеек в строки с ANSI-кодами цветов.

**Поведение:**
1. Для каждого ряда итерация по ячейкам
2. Генерирует ANSI-код цвета только при изменении предыдущих цветов
3. Добавляет символ ячейки
4. После ряда добавляет сброс цветов `"\033[0m"`
5. При необходимости добавляет пробелы для выравнивания

### Функция renderPlain

```go
func renderPlain(grid [][]Cell, maxWidth int) []string
```

Преобразует сетку ячеек в обычные строки текста.

**Поведение:**
1. Добавляет символ или пробел для каждой ячейки
2. Обрезает строку по количеству символов (не байтов), если превышает `maxWidth`

### Функция ansiColor

```go
func ansiColor(fg, bg, lastFG, lastBG css.Color) string
```

Генерирует ANSI-код цвета или пустую строку, если цвета не изменились.

**Поведение:**
- Если цвета равны последним: возвращает `""`
- Иначе генерирует ANSI-код с настройкой FG и BG (или сброс)
- Использует 24-битные цвета (RGB)

### Функция itoa

```go
func itoa(n int) string
```

Преобразует целое число в его строковое представление. Реализована вручную с использованием буфера без выделенной памяти.

### Функция overlayText

```go
func overlayText(grid [][]Cell, tree *layout.LayoutBox)
```

Наносит текстовые оверлеи на сетку. Сохраняет оригинальные фоновые цвета сетки, чтобы текст не появлялся на чёрном фоне.

**Поведение:**
- Собирает текстовые строки из дерева layout
- Для каждой текстовой строки:
  - Вычисляет ряд и столбец
  - Заменяет символ ячейки на символ текста
  - Применяет цвет текста

### Функция collectTextLines

```go
func collectTextLines(box *layout.LayoutBox, lines *[]layout.TextLine, colors *[]css.Color)
```

Рекурсивно собирает текстовые строки из дерева layout, включая текстовые строки самого узла и его потомков.

### Функция colorsEqual

```go
func colorsEqual(a, b css.Color) bool
```

Проверяет равенство двух цветов по всем полям (`IsSet`, `R`, `G`, `B`).

## Внутренние детали

### Сжатие по вертикали

Framebuffer имеет двойную высоту по сравнению с сеткой. Каждый ряд сетки соответствует двум рядам framebuffer (индексы `row*2` и `row*2+1`). Это позволяет достичь более гладкой визуализации.

### Обработка цветов

- Цвета `css.Color` имеют поле `IsSet`, указывающее, установлен ли цвет
- Прозрачный цвет получается через `css.Transparent()`
- Цвета RGB создаются через `css.RGB(r, g, b)`

### ANSI-коды цветов

Используются 24-битные цвета в формате `38;2;R;G;B` (FG) и `48;2;R;G;B` (BG). Цвета всегда сбрасываются перед установкой новых.

### Обработка границ

- При выходе за границы сетки (негативные индексы или превышение ширины) происходит игнорирование или обрезка
- Текст не выводится за пределы сетки

## Примеры использования

### Получение обычного текста

```go
lines := Render(fb, tree, 80)
// lines — []string с обычным текстом
```

### Получение ANSI-цвета

```go
lines := RenderANSI(fb, tree, 80)
// lines — []string с ANSI-кодами цветов
```

### E2E-тестирование

```go
lines := RenderPlain(fb, tree, 80)
// lines — []string для сравнения в тестах
```
