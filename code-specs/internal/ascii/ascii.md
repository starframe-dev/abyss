# Спецификация пакета ascii

## Обзор

Пакет `ascii` преобразует framebuffer в строки терминальных ячеек и ANSI-цвета. `Render` предназначен для текстового представления, `RenderANSI` — для вывода в терминал. Оба варианта могут накладывать предварительно подготовленные ASCII-ячейки и текст из дерева layout.

## Публичный API

### Тип Cell

```go
type Cell struct {
    Char rune
    Extra string
    Width int
    Continuation bool
    FG css.Color
    BG css.Color
}
```

`Char` — базовая руна ячейки, `Extra` — оставшиеся руны графемного кластера, `Width` — ширина в терминальных ячейках, `Continuation` отмечает продолжение широкого символа. `FG` и `BG` задают цвета переднего и заднего плана.

### Render и RenderANSI

```go
func Render(fb *framebuffer.Framebuffer, tree *layout.LayoutBox, viewportWidth int) []string
func RenderANSI(fb *framebuffer.Framebuffer, tree *layout.LayoutBox, viewportWidth int) []string
```

Обе функции ограничивают `viewportWidth` снизу нулём и возвращают `[]string{""}`, если framebuffer равен nil или его ширина равна нулю. Иначе создают сетку, накладывают ASCII-ячейки и текст layout. `Render` формирует строки без ANSI-кодов, `RenderANSI` — строки с ANSI-кодами. Ширина вывода учитывается в терминальных ячейках.

## Внутренняя реализация

### makeGrid и chooseChar

`makeGrid(fb)` создаёт сетку размером `ceil(fb.Height / cellmetrics.HeightPx)` на `floor(fb.Width / cellmetrics.WidthPx)`. Для каждой ячейки выбирает цвет пикселя framebuffer в центре соответствующей ячейки и вызывает `chooseChar` с этим цветом и прозрачным нижним цветом. `chooseChar` возвращает пробел и прозрачные цвета, если оба цвета не заданы; если задан верхний цвет — пробел, прозрачный FG и верхний цвет как BG; иначе — пробел, прозрачный FG и нижний цвет как BG.

### overlayText и overlayAsciiCells

`overlayText` сначала рекурсивно переносит `AsciiCells` узлов дерева на сетку (кроме узлов с абсолютным позиционированием), начиная с координат границы узла, затем собирает текстовые строки узлов и потомков. Цвет берётся из стиля соответствующего узла; если он не задан, используется RGB(30, 30, 30). Координаты строк переводятся в индексы ячеек. Текст разбивается на графемные кластеры; неположительная ширина пропускается, выход за ширину строки сетки останавливает обработку. Первая руна кластера записывается в `Char`, остальные — в `Extra`; для широкого кластера создаётся продолжительная ячейка. Фоновый цвет существующей ячейки сохраняется.

### renderPlain

Для каждой строки пропускает ячейки-продолжения, заменяет нулевую руну пробелом и непечатаемую руну на `�`. Ширина берётся из `Cell.Width`, а при неположительной ширине вычисляется для руны. Если следующая ячейка превышает `maxWidth`, добавляется один пробел и обработка строки прекращается; иначе записывается руна и безопасные хвостовые руны графемы. Нулевые/непечатаемые символы обрабатываются безопасно. Строки не дополняются до `maxWidth`.

### renderANSI

Для каждой строки пропускает ячейки-продолжения, ограничивает вывод шириной `maxWidth`, устанавливает изменившиеся цвета и записывает символы с проверкой печатаемости. Для широкого символа, который не помещается, записывает пробел. Непечатаемые символы заменяются на `�`. Безопасные хвостовые руны графемы сохраняются. Недостающая ширина дополняется пробелами, в конце каждой строки добавляется `\033[0m`.

### Цвета и безопасный вывод

`colorsEqual` сравнивает `IsSet`, `R`, `G`, `B`. `writeANSIColor` ничего не пишет, если цвета не изменились или оба цвета не установлены; иначе перед новым набором пишет сброс, затем параметры 24-битных FG (`38;2;R;G;B`) и/или BG (`48;2;R;G;B`). Десятичные компоненты формируются `writeByteDecimal`. `isPrintable` исключает ESC, DEL, управляющие C1 и непечатаемые руны. `writeSafeClusterTail` пропускает в вывод печатные руны, ZWNJ/ZWJ и variation selectors.

### collectTextLines

Рекурсивно добавляет текстовые строки узла и цвета его стиля, затем обходит потомков.

## Границы

Отрицательные координаты столбца текстовой строки ограничиваются нулём; строки вне сетки пропускаются. Ячейки, выходящие за границы сетки при переносе ASCII-ячеек, пропускаются. Текст, который не помещается в строку, обрезается.

## Зависимости

Используются `css`, `framebuffer`, `layout`, `cellmetrics`, `asciirender`, `go-runewidth`, `uniseg` и стандартные пакеты `strings` и `unicode`.
