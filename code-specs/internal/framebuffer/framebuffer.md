# Спецификация: Framebuffer

## Обзор

Пакет `framebuffer` предоставляет RGB-буфер пикселей для отрисовки макетных блоков, используя `css.Color`.

## Типы и ограничения

`Framebuffer` содержит публичные поля `Width int`, `Height int` и `Pixels []css.Color`. Пиксели хранятся построчно с индексом `y*Width+x`.

Константы ограничивают размеры: `MaxWidth = 4096`, `MaxHeight = 4096`, `MaxPixels = 16*1024*1024`.

## API

### New

`New(width, height int) *Framebuffer` возвращает новый буфер. Если ширина или высота не положительна, превышает соответствующий максимум либо число пикселей превышает `MaxPixels`, возвращается пустой буфер с нулевыми полями. Проверка произведения выполняется безопасно как `width > MaxPixels/height`. В допустимом случае размеры сохраняются, а `Pixels` создаётся через `make` длиной `width*height` и заполнен нулевыми значениями `css.Color`.

### Set и Get

`Set(x, y int, c css.Color)` записывает цвет по индексу `y*Width+x`, если приемник не nil и координаты находятся в пределах буфера; иначе ничего не делает.

`Get(x, y int) css.Color` возвращает пиксель при допустимом приемнике и координатах. Для nil-приёмника или координат вне диапазона возвращает `css.Transparent()`.

### Clear

`Clear(c css.Color)` заменяет цвет каждого элемента `Pixels` на `c`. Для nil-приёмника ничего не делает.

### FillRect

`FillRect(x, y, w, h float64, c css.Color)` закрашивает пиксели, попадающие в прямоугольник. Nil-приёмник, не конечные координаты/размеры, неположительная ширина или высота, а также переполнение `x+w` или `y+h` приводят к отсутствию изменений.

Диапазоны сначала ограничиваются границами буфера, затем вычисляются как `[floor(max(-size, start)), ceil(min(size, start+extent)))`; пиксели за пределами буфера отбрасываются. Частично перекрытые пиксели включаются. Для каждого выбранного пикселя используется `Set`.

### DrawBorder

`DrawBorder(x, y, w, h, topW, rightW, bottomW, leftW float64, topC, rightC, bottomC, leftC css.Color)` вызывает `FillRect` для каждой стороны, только если соответствующая толщина строго больше нуля:

- верхняя: `(x, y, w, topW)`;
- правая: `(x+w-rightW, y, rightW, h)`;
- нижняя: `(x, y+h-bottomW, w, bottomW)`;
- левая: `(x, y, leftW, h)`.

Стороны обрабатываются независимо, их пересечения возможны.

### DrawRoundedRect

`DrawRoundedRect(x, y, w, h, rtl, rtr, rbr, rbl float64, c css.Color)` сначала вызывает `FillRect(x, y, w, h, c)`, затем вызывает внутренний `clipCorner` для каждого положительного радиуса:

- верхний левый: `(x, y, rtl, 0)`;
- верхний правый: `(x+w-rtr, y, rtr, 1)`;
- нижний правый: `(x+w-rbr, y+h-rbr, rbr, 2)`;
- нижний левый: `(x, y+h-rbl, rbl, 3)`.

### clipCorner

Внутренняя функция `clipCorner(cx, cy, r float64, quadrant int)` ничего не делает для nil-приёмника, не конечных `cx`, `cy` или `r`, либо `r <= 0`. Центр окружности определяется по квадранту: по умолчанию `(cx+r, cy+r)`; для 1 — `(cx, cy+r)`, для 2 — `(cx, cy)`, для 3 — `(cx+r, cy)`. Иные значения используют центр по умолчанию.

Область пикселей ограничивается буфером по диапазонам `cx..cx+r` и `cy..cy+r` тем же способом, что в `FillRect`. Для каждого пикселя расстояние вычисляется от его центра `(px+0.5, py+0.5)` до центра окружности. Если `dx*dx+dy*dy > r*r`, пиксель очищается через `Set(px, py, css.Transparent())`.

## Примечания

- `Set`, `Get`, `Clear`, `FillRect` и `clipCorner` безопасно обрабатывают nil-приёмник.
- `DrawBorder` и `DrawRoundedRect` напрямую nil не проверяют; их вызовы с nil-приёмником безопасны благодаря вызываемым методам.
- Поля структуры публичны, поэтому вызывающий код может менять размеры и слайс; гарантии согласованности после таких изменений не предоставляются.
