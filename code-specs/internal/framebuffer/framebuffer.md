# Specification: Framebuffer

## Обзор

Пакет `framebuffer` предоставляет буфер пикселей для отрисовки макетных блоков. Основное назначение — хранение и манипуляция пиксельной информацией в формате RGB с использованием цветовой палитры `css.Color`.

---

## Типы

### Framebuffer

Структура `Framebuffer` представляет собой буфер пикселей с прямоугольной геометрией.

```go
type Framebuffer struct {
    Width  int
    Height int
    Pixels []css.Color
}
```

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `Width` | `int` | Ширина буфера в пикселях |
| `Height` | `int` | Высота буфера в пикселях |
| `Pixels` | `[]css.Color` | Одномерный слайс, хранящий пиксели в порядке `y * Width + x` |

---

## Публичный API

### Конструктор

#### New

Создаёт новый пустой буфер пикселей с указанными размерами.

```go
func New(width, height int) *Framebuffer
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `width` | `int` | Ширина буфера (в пикселях) |
| `height` | `int` | Высота буфера (в пикселях) |

**Возвращаемое значение:**

- Возвращает указатель на новый `*Framebuffer` с инициализированным слайсом пикселей размером `width * height`.

**Поведение:**

- Создаётся новый экземпляр с нулевыми значениями в `Pixels`.
- `Width`, `Height` устанавливаются из параметров.
- `Pixels` инициализируется слайсом с нулевым размером, равным `width * height`.

---

### Методы Framebuffer

#### Set

Устанавливает цвет пикселя в заданной координате.

```go
func (fb *Framebuffer) Set(x, y int, c css.Color)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | `int` | Координата X пикселя (0..Width-1) |
| `y` | `int` | Координата Y пикселя (0..Height-1) |
| `c` | `css.Color` | Цвет пикселя |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

- Если координаты `x` или `y` выходят за пределы буфера, изменение игнорируется.
- Пиксель в позиции `[y*Width+x]` заменяется на переданный цвет.
- Нет возврата ошибки — некорректные координаты игнорируются молча.

---

#### Get

Получает цвет пикселя в заданной координате.

```go
func (fb *Framebuffer) Get(x, y int) css.Color
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | `int` | Координата X пикселя (0..Width-1) |
| `y` | `int` | Координата Y пикселя (0..Height-1) |

**Возвращаемое значение:**

- `css.Color` — цвет пикселя или `css.Transparent()`, если координаты некорректны.

**Поведение:**

- Если координаты `x` или `y` выходят за пределы буфера, возвращается прозрачный цвет.
- Иначе возвращается значение из слайса `Pixels` в позиции `[y*Width+x]`.

---

#### Clear

Заполняет весь буфер одним цветом.

```go
func (fb *Framebuffer) Clear(c css.Color)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `c` | `css.Color` | Цвет для заполнения всего буфера |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

- Все пиксели в `Pixels` заменяются на переданный цвет `c`.
- Эквивалентно вызову `Set` для каждого пикселя буфера.

---

#### FillRect

Заполняет прямоугольную область цветом.

```go
func (fb *Framebuffer) FillRect(x, y, w, h float64, c css.Color)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | `float64` | Левая координата прямоугольника |
| `y` | `float64` | Верхняя координата прямоугольника |
| `w` | `float64` | Ширина прямоугольника |
| `h` | `float64` | Высота прямоугольника |
| `c` | `css.Color` | Цвет для заполнения |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

- Вычисляет целочисленные границы прямоугольника:
  - `x0 = floor(x)`, `y0 = floor(y)` — левая и верхняя границы
  - `x1 = ceil(x + w)`, `y1 = ceil(y + h)` — правая и нижняя границы
- Для каждого пикселя в диапазоне `[x0, x1)` и `[y0, y1)` вызывает `Set(px, py, c)`.
- Пиксели, частично перекрывающиеся с границами, включаются в заполнение.

---

#### DrawBorder

Нарисует границы для макетного блока с возможностью задать независимые толщины и цвета для каждой стороны.

```go
func (fb *Framebuffer) DrawBorder(x, y, w, h, topW, rightW, bottomW, leftW float64, topC, rightC, bottomC, leftC css.Color)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x, y` | `float64` | Левая и верхняя координаты прямоугольника |
| `w, h` | `float64` | Ширина и высота прямоугольника |
| `topW, rightW, bottomW, leftW` | `float64` | Толщины верхней, правой, нижней, левой границ |
| `topC, rightC, bottomC, leftC` | `css.Color` | Цвета границ для каждой стороны |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

- Если толщина границы больше 0, вызывает `FillRect` для соответствующей стороны:
  - **Верхняя**: отрисовывается по `y` с высотой `topW` и шириной `w`
  - **Правая**: отрисовывается от `x+w-rightW` с шириной `rightW` и высотой `h`
  - **Нижняя**: отрисовывается от `y+h-bottomW` с высотой `bottomW` и шириной `w`
  - **Левая**: отрисовывается от `x` с шириной `leftW` и высотой `h`
- Толщина может быть больше высоты или ширины прямоугольника — `FillRect` обрабатывает это корректно.
- Стороны нарисованы независимо друг от друга (пересечения возможны).

---

#### DrawRoundedRect

Нарисует прямоугольник со скруглёнными углами.

```go
func (fb *Framebuffer) DrawRoundedRect(x, y, w, h float64, rtl, rtr, rbr, rbl float64, c css.Color)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x, y` | `float64` | Левая и верхняя координаты прямоугольника |
| `w, h` | `float64` | Ширина и высота прямоугольника |
| `rtl, rtr, rbr, rbl` | `float64` | Радиусы скругления: top-left, top-right, bottom-right, bottom-left |
| `c` | `css.Color` | Цвет прямоугольника |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

1. Сначала заполняет весь прямоугольник цветом `c` через `FillRect`.
2. Затем для каждой стороны с радиусом скругления > 0 вызывает `clipCorner`:
   - `rtl > 0`: отрисовывает скругление верхнего левого угла
   - `rtr > 0`: отрисовывает скругление верхнего правого угла
   - `rbr > 0`: отрисовывает скругление нижнего правого угла
   - `rbl > 0`: отрисовывает скругление нижнего левого угла
3. `clipCorner` определяет круговой сектор и очищает пиксели вне радиуса `r`.

---

#### clipCorner (внутренняя функция)

Помощественная функция для отрисовки скругления угла.

```go
func (fb *Framebuffer) clipCorner(cx, cy, r float64, quadrant int)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `cx, cy` | `float64` | Центр круга (координаты угла) |
| `r` | `float64` | Радиус скругления |
| `quadrant` | `int` | Квартант: 0=верх-лево, 1=верх-право, 2=ниж-право, 3=ниж-лево |

**Возвращаемое значение:**

- Нет (процедурная функция).

**Поведение:**

- Вычисляет границы квадратной области вокруг угла:
  - `x0 = floor(cx)`, `y0 = floor(cy)`
  - `x1 = ceil(cx + r)`, `y1 = ceil(cy + r)`
- Для каждого пикселя в диапазоне проверяет расстояние до центра угла:
  - `dx = px - cx`, `dy = py - cy`
  - Если `dx*dx + dy*dy > r*r`, пиксель очищается (становится прозрачным)
- Использует `Set(px, py, css.Transparent())` для очистки.

## Внутренняя реализация

### Хранение пикселей

- Пиксели хранятся в одномерном слайсе `[]css.Color`.
- Индекс пикселя вычисляется как `y * Width + x`.
- Это соответствует памяти, выровненной по строкам (row-major order).

### Обработка ошибок

- Все методы, работающие с координатами, проверяют границы.
- При выходе за пределы:
  - `Set`: игнорирует вызов без возврата ошибки
  - `Get`: возвращает прозрачный цвет
- Нет явной обработки ошибок — предполагается, что вызывающий код должен проверять координаты или использовать безопасные методы.

### Математические вычисления

- Используются функции `math.Floor` и `math.Ceil` для работы с плавающей точкой.
- Скругление углов использует проверку расстояния до центра: `dx² + dy² > r²`.

---

## Важные замечания

1. **Границы буфера**: Все методы `Set` и `Get` проверяют, что координаты находятся в диапазоне `[0, Width)` и `[0, Height)`.

2. **Полупрозрачные границы**: `DrawBorder` рисует границы независимо, поэтому при наложении границ возможны перекрытия.

3. **Скругленные углы**: При отрисовке скругления прямоугольник сначала полностью заполняется, затем углы очищаются. Радиус скругления может быть больше размера стороны прямоугольника.

4. **Тип `css.Color`**: Все методы работают с типом `css.Color` из пакета `github.com/starframe-dev/abyss/internal/css`. Для прозрачности используется `css.Transparent()`.

5. **Изменение размера**: Размер буфера фиксирован после создания через `New()`. Изменить `Width` или `Height` можно только заново создав экземпляр.

6. **Инициализация пикселей**: При создании `Pixels` имеет нулевой размер, но должен быть инициализирован до `width * height` элементов. В текущей реализации инициализация происходит через `make([]css.Color, width*height)`.
