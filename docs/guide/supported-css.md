# Supported CSS

Abyss supports a subset of CSS. Treat the list below as partial support, not full CSS compatibility.

- **Display**: `block`, `inline`, `flex`, `grid`, `none`
- **Position**: `static`, `relative`, `absolute`
- **Box Model**: `width`, `height`, `margin`, `padding`, `border`
- **Visual**: `background-color`, inherited `color`, `border-radius`, `z-index`, `overflow`
- **Cascade**: specificity, inline declarations, `!important`, CSS custom properties
- **Conditions**: screen `min-width` / `max-width` queries in CSS pixels; simple `@supports` checks for `display` and `position`
- **Flexbox**: row and column direction, grow/shrink, justify-content, `flex-wrap`, `order`
