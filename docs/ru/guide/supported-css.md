# Поддерживаемый CSS

Abyss поддерживает часть CSS. Список ниже — частичная поддержка, а не полная совместимость.

- **Display**: `block`, `inline`, `flex`, `grid`, `none`
- **Position**: `static`, `relative`, `absolute`
- **Box Model**: `width`, `height`, `margin`, `padding`, `border`
- **Визуал**: `background-color`, наследуемый `color`, `border-radius`, `z-index`, `overflow`
- **Каскад**: специфичность, inline-объявления, `!important`, CSS-переменные
- **Условия**: `min-width` / `max-width` в CSS-пикселях; простые проверки `@supports` для `display` и `position`
- **Flexbox**: направление row и column, grow/shrink, justify-content, `flex-wrap`, `order`
