# Архитектура

У Abyss собственный движок HTML/CSS. Это не полноценная реализация браузера.

```
HTML + CSS → DOM-парсер → CSS-движок (каскад, специфичность)
    ↓
Движок раскладки (box model, flexbox, grid, absolute)
    ↓
Пиксельный буфер (вьюпорт 800 px, фоны, рамки, border-radius)
    ↓
ANSI-арт (блоки 2×1 пикселя → █▄▀ с truecolor)
    ↓
Bubble Tea TUI (вьюпорт, прокрутка)
```

Движок раскладки работает в ячейках терминала 10 × 20 px (`internal/cellmetrics`).

Abyss не запускает страницы в песочнице. JavaScript выполняется в одном контексте JavaScriptCore на вкладку.
