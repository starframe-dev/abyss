# Макет таблиц (`internal/layout/layout_table.go`)

Этот файл реализует этап компоновки строк и ячеек таблицы. Он входит во внутренний пакет компоновки и не предоставляет экспортируемых идентификаторов Go; его функции — закрытые для пакета вспомогательные средства, используемые механизмом компоновки.

## Поведение

`layoutTable` размещает найденные строки таблицы в порядке документа. Ячейки строки располагаются горизонтально, начиная с левого края области содержимого таблицы. Строки располагаются вертикально одна под другой: следующая строка начинается после самой высокой ячейки текущей строки.

Эта процедура задаёт геометрию только блокам ячеек. Блоки строк и секций таблицы (например, `thead`, `tbody` и `tfoot`) служат узлами обхода и группировки и здесь не компонуются. Функция возвращает общую высоту, занимаемую строками; если компоновка ячеек не требуется, высота равна нулю.

Ширина ячеек определяется отдельно для каждой строки:

- Ширина, отличная от `auto`, вычисляется относительно переданной ширины содержимого таблицы.
- Ячейки с автоматической шириной поровну делят неотрицательный остаток ширины таблицы.
- Если ячейки с фиксированной шириной занимают больше ширины таблицы, автоматическим ячейкам назначается нулевая ширина.
- Если ячеек с автоматической шириной нет, нераспределённая ширина таблицы остаётся незанятой.

Алгоритм вычисляет ширину независимо для каждой строки; он не выравнивает ширину столбцов между строками и не учитывает объединение столбцов.

## Внутренний API

| Функция | Назначение |
| --- | --- |
| `layoutTable(box *LayoutBox, contentWidth float64) float64` | Компоновка строк и ячеек с возвратом общей высоты строк. |
| `tableRows(box *LayoutBox) []*LayoutBox` | Рекурсивный сбор блоков элементов `tr` внутри переданного блока. |
| `rowCells(row *LayoutBox) []*LayoutBox` | Сбор непосредственных дочерних элементов `td` и `th` в порядке документа. |
| `tableColumnWidths(cells []*LayoutBox, tableWidth float64) []float64` | Вычисление ширины ячеек и распределение остатка между ячейками с автоматической шириной. |

Это незакрытые для экспорта детали реализации, а не общедоступный API пакета.

## Детали реализации

### Поиск строк и ячеек

`tableRows` выполняет обход в глубину. Встретив элемент с именем тега `tr`, функция добавляет его блок и прекращает обход его потомков. Благодаря этому строки можно находить внутри контейнеров секций таблицы, не рассматривая потомков ячеек как дополнительные строки. Блок без узла DOM или с узлом, не являющимся элементом, обходится, но строкой не считается.

`rowCells` проверяет только непосредственных потомков строки. Функция включает блоки, основанные на узлах-элементах с именами `td` или `th`, сохраняя порядок потомков; вложенные ячейки не собираются.

Строки без непосредственных ячеек пропускаются функцией `layoutTable` и не увеличивают вертикальное смещение.

### Вычисление ширины и компоновка

Для каждой строки `tableColumnWidths` создаёт по одному элементу результата на ячейку. Фиксированная ширина вычисляется с помощью разрешения ширины из `css` относительно `tableWidth`. Затем, если есть ячейки с автоматической шириной, функция поровну делит между ними `max(0, tableWidth-fixed)`.

Перед вызовом `layoutBox` функция `layoutTable` временно заменяет `Style.Width` каждой ячейки на вычисленную ширину в пикселях. В процедуру компоновки передаются ширина ячейки и её позиция (`box.Content.X + x`, `box.Content.Y + y`); последний булев аргумент установлен в `false`. После этого исходная ширина стиля восстанавливается. Горизонтальное смещение увеличивается на вычисленную ширину. Высота строки равна максимальному значению `Margin.Height` среди её ячеек, а накопленная высота строк определяет вертикальную позицию следующей строки.

Временное изменение ширины восстанавливается после каждого вызова, поэтому вычисленная геометрия компоновки не изменяет объявленную ширину ячейки в стиле.

## Зависимости и предположения

- Использует `internal/dom` для определения узлов-элементов и имён тегов (`tr`, `td` и `th`).
- Использует `internal/css` для создания ширины в пикселях во временном стиле компоновки ячейки.
- Зависит от определений `LayoutBox`, `layoutBox` и `max` в окружающем пакете компоновки.
- Предполагается, что вызывающий код передаёт ширину содержимого таблицы и что ширину ячейки можно вычислить относительно этой ширины.
