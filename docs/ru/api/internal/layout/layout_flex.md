# Flex-разметка

В этом файле реализован путь разметки flex-контейнера, используемый пакетом `layout`. Он размещает дочерние элементы `LayoutBox` в строку или столбец с поддержкой CSS-сортировки, промежутков, переноса, увеличения, сжатия и выравнивания.

## API

Все объявления в этом файле — непубличные вспомогательные функции реализации; публичный API Go не расширяется. Основная точка входа — `layoutFlex(box, contentWidth)`, вызываемая механизмом разметки пакета. Она возвращает вычисленную высоту содержимого типа `float64`.

| Вспомогательная функция | Назначение |
| --- | --- |
| `orderedFlexChildren` | Выполняет стабильную CSS-сортировку по `order`, если у какого-либо дочернего элемента порядок ненулевой. |
| `layoutFlexWrapped` | Разбивает элементы строки на линии и размещает каждую линию. |
| `layoutFlexRow` | Размещает дочерние элементы в одной строке и возвращает высоту строки/контейнера. |
| `layoutFlexColumn` | Размещает дочерние элементы по вертикали и распределяет доступную высоту. |
| `flexBasis`, `inlineContentWidth` | Определяют исходную ширину flex-элемента. |
| `flexTotals`, `flexRemaining`, `flexShrinkWeight` | Суммируют базовые размеры и коэффициенты flex, вычисляют свободное пространство. |
| `flexJustification` | Вычисляет начальное смещение или дополнительный промежуток между элементами. |
| `flexMinContentWidth`, `fieldColumns` | Сохраняют минимальную ширину вложенных элементов формы при сжатии строки. |
| `layoutFlexChild`, `flexContainerSize` | Определяют размер и положение отдельного элемента, а также высоту контейнера. |

## Поведение

`layoutFlex` возвращает ноль, если дочерних элементов нет. Для направления column сразу вызывается разметка столбца. В остальных случаях дочерние элементы временно сортируются стабильным образом по возрастанию `Style.Order` (при равных значениях сохраняется порядок DOM), после чего выбирается разметка с переносом или одной строкой. Исходный срез дочерних элементов восстанавливается после обработки строк, в том числе при переносе.

### Строки и перенос

Для строки значение `Gap` контейнера разрешается относительно `contentWidth`. Начальное доступное пространство равно ширине содержимого за вычетом промежутков между дочерними элементами. Суммируются базовые размеры элементов, а оставшееся пространство распределяется согласно flex-коэффициентам. Положительное свободное пространство распределяется пропорционально `FlexGrow`; отрицательное — пропорционально произведению базового размера элемента на `FlexShrink`, при этом ширина ограничивается нулём до применения ограничений минимального содержимого.

При `FlexWrap` элементы собираются в линии на основе их flex-базовых размеров и разрешённого промежутка. Перед добавлением элемента, из-за которого ширина превысит `contentWidth`, текущая линия завершается; каждая линия размещается как строка, а высоты линий складываются с тем же разрешённым промежутком. Решение о переносе принимается по базовым размерам до увеличения или сжатия.

Каждый элемент строки размещается от начала содержимого контейнера с учётом текущей горизонтальной позиции. Его ширина временно задаётся вычисленной шириной в пикселях для `layoutBox`, а затем восстанавливается. Минимальная ширина элемента не может быть меньше `flexMinContentWidth`.

### Столбцы

При разметке столбца дочерние элементы сначала размещаются последовательно с их естественной высотой с учётом отступов и разрешённого промежутка между элементами. Если высота контейнера задана автоматически, возвращается накопленная высота. При заданной высоте положительный остаток распределяется пропорционально значениям `FlexGrow` дочерних элементов, если такие значения есть. В противном случае `JustifyContent` может расположить последовательность в начале, по центру или в конце либо добавить пространство между элементами или вокруг них. Сжатие flex для столбцов не реализовано: расчёт оставшегося пространства для направления column возвращает ноль.

При распределении дополнительной высоты высота каждого растущего дочернего элемента временно заменяется значением в пикселях, равным высоте его содержимого плюс выделенная ему доля; после повторной разметки значение восстанавливается. Возвращаемая высота — это естественная накопленная высота плюс распределенная прибавка; смещения и дополнительные промежутки выравнивания задают положение элементов внутри указанной высоты.

### Выравнивание

`flexJustification` не возвращает смещение или дополнительный промежуток, если оставшееся пространство неположительное, дочерних элементов нет или суммарный коэффициент роста положительный. В остальных случаях:

- `center` смещает элементы на половину оставшегося пространства.
- `flex-end` смещает элементы на всё оставшееся пространство.
- `space-between` распределяет его между несколькими элементами.
- `space-around` задаёт одинаковый дополнительный промежуток для каждого элемента и половину этого промежутка по краям.

При других значениях элементы остаются в начале.

## Базовая ширина и минимальное содержимое

`flexBasis` использует разрешённую объявленную ширину дочернего элемента, если она ненулевая. В противном случае функция измеряет подходящее встроенное содержимое; если измерение недоступно или равно нулю, используется базовая ширина по умолчанию — 100 единиц разметки.

`inlineContentWidth` измеряет только узлы-элементы, дочерние узлы которых состоят исключительно из текстовых узлов или текстовых ссылок. Текст рекурсивно собирается, пробелы нормализуются, а ширина отображения измеряется с помощью `go-runewidth` и преобразуется посредством `cellmetrics.WidthPx`. Между последовательными дочерними ссылками добавляется разделитель шириной в две ячейки. Любой другой тип дочернего узла делает измерение недоступным (возвращается ноль).

Для элементов строки `flexMinContentWidth` обходит потомков и сохраняет ширину самого широкого подходящего поля формы как минимальную. Для `textarea` используется атрибут `cols`; для невидимого `input` — явно заданная положительная ширина CSS в пикселях, не выраженная в процентах, а при её отсутствии — атрибут `size`. Если значение столбцов/размера отсутствует, некорректно или неположительно, по умолчанию используется 20 столбцов. Ширина в пикселях преобразуется в число ячеек через `cellmetrics.WidthPx`. Скрытые поля `input` исключаются.

## Примечания по реализации и ограничения

- Срез копируется для сортировки по CSS `order`, только если у какого-либо дочернего элемента ненулевой порядок; стабильная сортировка сохраняет последовательность DOM для одинаковых значений.
- При расчёте увеличения/сжатия строк используется flex-база, а не измеренные после разметки размеры. Сжатие взвешивается по базовому размеру и `FlexShrink`.
- Переносимые строки используют один и тот же алгоритм разметки независимо, поэтому увеличение и выравнивание рассчитываются отдельно для каждой линии.
- В пути столбца используются разрешённые промежуток и высота контейнера, а `contentWidth` передаётся дочерним элементам; отдельная flex-база столбца не вычисляется.
- Временные изменения ширины/высоты дочерних элементов и списка дочерних элементов контейнера восстанавливаются после разметки, предотвращая сохранение этих вычислений в виде постоянных изменений стилей или дерева.
