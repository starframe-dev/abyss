# Макет сетки

Этот файл реализует внутренний путь построения сеточного макета для пакета `layout`. Он размещает дочерние элементы в сетке с заполнением строк по порядку, вычисляет размеры дорожек и координаты дочерних элементов и возвращает итоговую высоту содержимого сетки.

## API и область действия

Все функции в этом файле — неэкспортируемые вспомогательные функции реализации; здесь не определён публичный API Go. Реализация работает с `LayoutBox` и значениями CSS `Length` из окружающих пакетов макета и `internal/css`.

| Функция | Назначение |
| --- | --- |
| `layoutGrid` | Разрешает параметры сетки, размещает дочерние элементы и возвращает общую высоту строк с учётом промежутков. |
| `resolveGridColumnWidths` | Вычисляет размеры фиксированных, процентных, дробных и автоматически заданных столбцов относительно доступной ширины содержимого. |
| `finiteNonNegative` | Проверяет, является ли значение с плавающей точкой конечным и неотрицательным. |
| `resolveGridFractionalRows` | Распределяет доступную высоту между дробными дорожками строк, одновременно вычисляя процентные размеры. |
| `placeGridChildren` | Вспомогательная обёртка, определяющая поведение роста строк по их определениям. |
| `placeGridChildrenWithTrackSizing` | Размещает дочерние элементы и увеличивает подходящие дорожки строк, чтобы вместить их. |
| `gridOffsetX`, `gridOffsetY` | Вычисляют начало столбца или строки, суммируя размеры предшествующих дорожек и промежутки. |
| `sumRowHeights` | Суммирует высоты строк и промежутки между ними. |

## Поведение макета

`layoutGrid` вычисляет `Gap` относительно ширины содержимого. Если столбцы не заданы, используется один столбец шириной с содержимое. Если строки не заданы, используется одна строка с автоматическим размером. Строки помечаются как допускающие рост, если это автоматические или дробные дорожки, либо процентные дорожки в контейнере с автоматической высотой. Функция вычисляет дробные размеры строк на основе рассчитанной высоты контейнера, определяет ширину столбцов, размещает дочерние элементы и возвращает итоговую сумму высот строк.

Дочерние элементы назначаются в исходном порядке: сначала заполняются столбцы, затем переход к следующей строке:

```text
column = child index modulo number of columns
row    = child index divided by number of columns
```

Список строк может расширяться, если для дочерних элементов нужны дополнительные строки. Строки за пределами явно заданных дорожек изначально имеют нулевую высоту и допускают рост. Горизонтальная позиция каждого дочернего элемента равна началу содержимого плюс ширины и промежутки предшествующих столбцов; вертикальная позиция аналогично определяется высотами предшествующих строк и промежутками.

Перед размещением дочернего элемента его стиль ширины временно заменяется на вычисленную ширину столбца сетки в пикселях. Вызов макета получает эту ширину и вычисленную позицию. После этого исходный стиль ширины восстанавливается. Дорожка строки, допускающая рост, увеличивается, если высота области элемента с отступами превышает текущую высоту строки. Размеры дорожек, не допускающих рост, сохраняются, даже если дочерний элемент выше.

## Подробности вычисления размеров дорожек

### Столбцы

Ширина столбцов вычисляется следующим образом:

- Процентные дорожки вычисляются относительно `contentWidth` и учитываются в фиксированной ширине.
- Дробные дорожки добавляют свой конечный неотрицательный коэффициент в качестве веса.
- Автоматические дорожки изначально имеют нулевую ширину.
- Для остальных значений дорожек используется значение в пикселях, которое учитывается в фиксированной ширине.

Оставшаяся ширина равна `max(0, contentWidth - фиксированные ширины - промежутки между столбцами)`. Она распределяется между дробными столбцами пропорционально их весам. Если положительных дробных весов нет, автоматические столбцы остаются нулевыми. Недопустимые (отрицательные, NaN или бесконечные) дробные веса считаются нулевыми.

### Строки

Дробные строки делят неотрицательное пространство, оставшееся после вычитания вычисленных высот недробных строк и промежутков между строками, пропорционально конечным неотрицательным дробным весам. Процентные строки преобразуются в пиксельные значения относительно доступной высоты. Если положительных дробных весов нет, процентные размеры всё равно вычисляются, а остальные определения строк остаются без изменений.

Особенность `layoutGrid` заключается в том, что `rowCanGrow` вычисляется по исходным определениям строк до вычисления дробных и процентных размеров. Благодаря этому после преобразования размеров в пиксели сохраняется решение о том, может ли содержимое увеличивать эти дорожки.

## Ограничения и примечания к реализации

- Размещение в сетке выполняется строго последовательно, построчно; этот код не обрабатывает явное размещение дочерних элементов, охват нескольких дорожек, выравнивание или правила неявного размещения, кроме добавления строк при необходимости.
- Автоматический размер столбцов в этой реализации не зависит от содержимого: автоматические столбцы изначально имеют нулевую ширину.
- При росте строки учитывается `Margin.Height` каждого дочернего элемента; дорожка только увеличивается, но не уменьшается.
- При вычислении доступного пространства для дорожек `Gap` вычитается, а при расчёте позиций и итоговой высоты добавляется между дорожками.
- `sumRowHeights` возвращает ноль, если строк нет. Для одной или нескольких строк функция добавляет ровно `len(rows)-1` промежутков.
- Вспомогательная функция `placeGridChildren` считает допускающими рост только автоматические и дробные строки. Основной путь `layoutGrid` задаёт собственные флаги роста, дополнительно разрешая рост процентных строк в контейнере с автоматической высотой.
