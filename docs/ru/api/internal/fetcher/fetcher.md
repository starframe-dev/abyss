# `internal/fetcher`

Пакет `fetcher` получает веб-ресурсы по HTTP с ограничениями размера ответа для каждого типа ресурса. Он предоставляет функции для HTML, бинарных ресурсов, CSS и JavaScript. Запросы используют общий HTTP-клиент, устанавливают браузерный `User-Agent` и заголовок `Accept`, соответствующий запрошенному ресурсу.

## Публичный API

### Ограничения размера

| Константа | Максимальный размер тела ответа |
| --- | ---: |
| `MaxHTMLBytes` | 8 МиБ |
| `MaxImageBytes` | 16 МиБ |
| `MaxCSSBytes` | 2 МиБ |
| `MaxJSBytes` | 4 МиБ |

Эти ограничения проверяются как по известному значению `Content-Length`, так и во время чтения тела ответа. Если тело превышает соответствующий предел, возвращается ошибка, соответствующая `ErrResponseTooLarge`.

### `Fetch` и `FetchContext`

```go
func Fetch(url string) (string, error)
func FetchContext(ctx context.Context, url string) (string, error)
```

Получают HTML и возвращают тело ответа в виде строки. `Fetch` использует `context.Background`, а `FetchContext` принимает контекст вызывающего кода, позволяя отменить запрос или задать срок его выполнения. В запросе указываются типы содержимого HTML, XHTML и XML.

### `FetchBytes` и `FetchBytesContext`

```go
func FetchBytes(url string) ([]byte, string, error)
func FetchBytesContext(ctx context.Context, url string) ([]byte, string, error)
```

Получают бинарный ресурс и возвращают байты тела ответа и значение заголовка `Content-Type`. `FetchBytes` использует `context.Background`, а `FetchBytesContext` поддерживает отмену и сроки выполнения, заданные вызывающим кодом. Эти функции используют ограничение `MaxImageBytes` и указывают в заголовке `Accept` распространённые форматы изображений.

### `FetchCSS`

```go
func FetchCSS(ctx context.Context, url string) (string, error)
```

Получает CSS в виде строки с ограничением `MaxCSSBytes`. Контекст обязателен; варианта, использующего фоновый контекст, нет.

### `FetchJS`

```go
func FetchJS(ctx context.Context, url string) (string, error)
```

Получает JavaScript в виде строки с ограничением `MaxJSBytes`. Контекст обязателен; варианта, использующего фоновый контекст, нет.

### Настройка запросов

```go
const UserAgent = "..."
var DefaultClient = &http.Client{Timeout: 10 * time.Second}
```

`UserAgent` отправляется с каждым запросом. `DefaultClient` — общий клиент, используемый для всех запросов; по умолчанию он имеет тайм-аут десять секунд. Поскольку это экспортируемая переменная, вызывающий код может заменить или настроить её; следует избегать конкурентного изменения.

## Ошибки и обработка ответов

- Запросы выполняются методом HTTP `GET` с переданным контекстом.
- Принимается только статус `200 OK`. Для остальных кодов возвращается ошибка, содержащая URL и текст статуса.
- Ошибки создания запроса и транспортного уровня оборачиваются контекстом URL.
- Для слишком больших ответов возвращается ошибка, оборачивающая `ErrResponseTooLarge`, поэтому её можно обнаружить с помощью `errors.Is`.
- При ошибках чтения тела возвращается `*ResponseReadError`, сохраняющий исходную ошибку для `errors.Is`/`errors.As` и содержащий число прочитанных байтов.
- После обработки тело ответа закрывается.
- При успешном выполнении внутренняя операция получения возвращает тело ответа и `Content-Type`; функции, возвращающие строки, отбрасывают тип содержимого.

## Типы

### `ResponseReadError`

```go
type ResponseReadError struct {
    BytesRead int64
    Err       error
}
```

Описывает ошибку чтения тела ответа. Метод `Error` возвращает сообщение исходной ошибки, а `Unwrap` делает её доступной для стандартного анализа цепочки ошибок. `BytesRead` — длина частичного тела, возвращённого операцией чтения.

### `ErrResponseTooLarge`

Сентинельная ошибка для ответов, превышающих выбранный предел размера в байтах. Ошибки, возвращаемые в этом случае, оборачивают эту ошибку.

## Детали реализации

Общая внутренняя функция пакета `get` создаёт запрос, привязанный к контексту, устанавливает общие заголовки, выполняет запрос с помощью `DefaultClient`, проверяет статус и объявленный размер, а затем считывает не более `limit + 1` байта. Чтение на один байт сверх предела позволяет обнаружить слишком большие ответы, даже если сервер не указывает `Content-Length` или указывает его заниженным. Текстовые функции напрямую преобразуют тела ответа в строки; декодирование кодировки символов и проверка типа содержимого не выполняются.
