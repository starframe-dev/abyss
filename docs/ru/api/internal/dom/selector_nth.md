# Вспомогательные функции селектора nth

В этом файле реализованы внутренние вспомогательные функции, используемые для определения позиции элемента среди дочерних узлов родителя и проверки этой позиции по выражению вида `an+b`. Все функции не экспортируются и сами по себе не образуют публичный API Go.

## Поведение

### `childIndex`

```go
childIndex(n *Node, ofType bool) int
```

Возвращает позицию `n` среди дочерних элементов родителя, начиная с 1. Если `ofType` равно `true`, учитываются только дочерние элементы с именами тегов, совпадающими с `n.TagName` без учёта регистра. Неэлементные узлы всегда игнорируются. Возвращает `0`, если `n` равно `nil`, не имеет родителя или не найден среди дочерних узлов родителя.

### `lastChildIndex`

```go
lastChildIndex(n *Node, ofType bool) int
```

Использует ту же фильтрацию и обработку ошибок, что и `childIndex`, но просматривает список дочерних узлов родителя с конца. Поэтому возвращаемая позиция отсчитывается назад от последнего подходящего дочернего элемента.

### `matchNth`

```go
matchNth(arg string, idx int) bool
```

Удаляет пробелы по краям и приводит `arg` к нижнему регистру, затем проверяет, соответствует ли `idx` выражению. Поддерживаются следующие формы:

- `even` и `odd` (на основе остатка от деления на 2)
- Целое число, которому индекс должен точно равняться
- Выражение `an+b`, например `2n+1`, `3n`, `-n+3` или `n`

Некорректные и пустые выражения возвращают `false`. Нулевой коэффициент (`a == 0`) означает, что совпадает только `b`. Для ненулевых коэффициентов реализация требует, чтобы индекс находился по соответствующую сторону от `b` (`idx >= b` при положительном `a`, `idx <= b` при отрицательном `a`), после чего проверяет делимость `idx-b` на `a`.

Выражение `0` обрабатывается `matchNth` особым образом и совпадает только с индексом `0`. Это отличается от обычных позиций CSS-элементов, которые нумеруются с 1; вызывающим функциям следует учитывать это поведение. `even` и `odd` также проверяют переданный индекс напрямую.

### `parseNth`

```go
parseNth(s string) (a, b int, ok bool)
```

Разбирает формулу на коэффициент и смещение, чтобы `matchNth` могла её вычислить. Перед разбором пробелы удаляются. Парсер допускает отсутствие коэффициента (в этом случае он равен `1`), коэффициент `-` (он трактуется как `-1`) и отсутствие смещения (оно равно `0`). Также распознаётся `0` как допустимая формула `(0, 0, true)`. Входные данные без `n` или с некорректными целочисленными компонентами приводят к `ok == false`.

## Подробности реализации и ограничения

- Функции определения позиции напрямую обходят `n.Parent.Children` и сравнивают узлы по идентичности указателей.
- В расчёте позиций участвуют только узлы с `Type == ElementNode`.
- Фильтрация `ofType` использует `strings.EqualFold` для сравнения имён тегов.
- `matchNth` сначала пытается разобрать формулу, а если она некорректна, пробует разобрать обычное целое число.
- В вычислениях используются значения Go типа `int`; вспомогательные функции не проверяют переполнение и не проверяют, что `idx` положителен.
