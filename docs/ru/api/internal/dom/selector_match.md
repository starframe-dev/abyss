# Сопоставление селекторов

`internal/dom/selector_match.go` реализует сопоставление в механизме DOM-селекторов. Он проверяет разобранные структуры селекторов на соответствие значениям `Node`, включая простые селекторы, комбинаторы, операторы атрибутов и определённый набор псевдоклассов.

## API

Все функции и типы, используемые в этом файле, не экспортируются; файл не добавляет экспортируемый API Go. Сопоставитель работает с типами селекторов и узлов, объявленными в других местах пакета `dom`:

- `Node` представляет узел DOM с полями `Type`, `TagName`, `Attributes`, `Children`, `Parent` и текстовым содержимым, используемыми сопоставителем.
- `ComplexSelector` содержит упорядоченный срез `Parts`.
- `SelectorPart` хранит тег, идентификатор, список классов, селекторы атрибутов, псевдоклассы и комбинатор.
- `AttrSelector` содержит имя атрибута, оператор и сравниваемое значение.
- `PseudoSelector` содержит имя псевдокласса и необязательный аргумент.

Пакетный API селекторов (например, `MatchesSelector`) определён в другом месте. Эта реализация вызывает `MatchesSelector` для проверки аргументов селекторов в `:not()`, `:is()` и `:where()`.

## Поведение сопоставления

### Составные селекторы и комбинаторы

`matchesComplex` отклоняет селектор без частей. В противном случае сопоставление начинается с последней части, после чего `matchPart` движется назад по селектору согласно комбинатору этой части:

| Комбинатор | Значение |
| --- | --- |
| ` ` или пустая строка | Предыдущей части должен соответствовать предок. Подойти может любой предок. |
| `>` | Должен соответствовать непосредственный родитель. |
| `+` | Должен соответствовать непосредственно предшествующий элемент-сосед. |
| `~` | Может соответствовать любой предшествующий элемент-сосед. |

Сначала часть должна пройти `matchesSimple`. Первая часть считается успешно сопоставленной, если её простой селектор совпал. Неэлементные узлы не могут соответствовать простым селекторам.

Поиск соседей просматривает `Children` родителя в обратном порядке, пропуская неэлементные узлы. Предполагается, что узел присутствует в срезе дочерних узлов родителя.

### Простые селекторы

`matchesSimple` применяет все заданные условия совместно:

- **Тег:** `*` и пустой тег не ограничивают тег. Остальные имена тегов сравниваются без учёта регистра.
- **ID:** сравнивается с атрибутом `id` с точным совпадением строки.
- **Классы:** каждый указанный класс должен присутствовать в атрибуте `class` как токен, разделённый пробелами.
- **Атрибуты:** должны совпасть все селекторы атрибутов.
- **Псевдоклассы:** должны совпасть все псевдоклассы.

### Операторы атрибутов

`matchesAttr` реализует следующие операторы:

| Оператор | Поведение |
| --- | --- |
| пустой | Атрибут существует независимо от значения. |
| `=` | Точное совпадение значения. |
| `~=` | Значение атрибута содержит запрошенное значение как токен, разделённый пробелами. |
| `|=` | Точное совпадение либо значение начинается с запрошенного значения, за которым следует `-`. |
| `^=` | Значение начинается с запрошенного префикса. |
| `$=` | Значение заканчивается запрошенным суффиксом. |
| `*=` | Значение содержит запрошенную подстроку. |

Неизвестный оператор не даёт совпадения. Сравнение строк учитывает регистр. Для проверки существования совпадение есть и тогда, когда атрибут присутствует, но его значение пусто.

### Поддерживаемые псевдоклассы

Перед поиском имена псевдоклассов приводятся к нижнему регистру. Сопоставитель распознаёт:

- Структурные: `:first-child`, `:last-child`, `:only-child`, `:first-of-type`, `:last-of-type`, `:only-of-type`, `:nth-child()`, `:nth-of-type()`, `:nth-last-child()` и `:nth-last-of-type()`.
- Аргументы-селекторы: `:not()`, `:is()` и `:where()`; проверка передаётся в `MatchesSelector` вместе с аргументом псевдокласса.
- Содержимое и состояние: `:empty`, `:checked`, `:disabled`, `:enabled` и `:selected`.
- `:focus`, который всегда возвращает `false`, поскольку сопоставитель не моделирует состояние фокуса.
- `:root`, которому соответствуют узлы типа `DocumentNode`.

Позиции в структуре и вычисление выражений `nth` делегируются вспомогательным функциям, например `childIndex`, `lastChildIndex` и `matchNth`, определённым в других местах пакета. Этот файл не задаёт грамматику их выражений.

Псевдоклассы состояния используют `GetAttr`: `checked`, `disabled` и `selected` совпадают, если возвращённое значение не пусто; `enabled` совпадает, если значение `disabled` пусто. Таким образом, поведение зависит от того, как `GetAttr` различает отсутствующий и пустой атрибут, а не от отдельной модели состояния элементов управления браузера.

Для `:empty` узел считается непустым, если у него есть дочерний элемент или текстовый дочерний узел с непустым после удаления пробелов текстом. Другие типы дочерних узлов и текст, состоящий только из пробелов, не делают узел непустым.

## Детали реализации

Функции псевдоклассов хранятся в карте уровня пакета, которая лениво инициализируется с помощью `sync.Once`. Инициализация безопасна при конкурентных вызовах; после неё сопоставление выполняет поиск по нормализованному имени псевдокласса. Нераспознанные псевдоклассы возвращают `false`.

Сопоставление составных селекторов выполняется рекурсивно и может проверять несколько предков или предшествующих соседей для комбинаторов потомка и общего соседа. Сопоставитель проверяет дерево `Node` в памяти и не изменяет его.
