# API селекторов DOM

Этот пакет реализует небольшой парсер CSS-подобных селекторов и средство сопоставления для дерева `dom.Node`. Он поддерживает группы селекторов, составные селекторы, комбинаторы, селекторы атрибутов и псевдоселекторы, представленные экспортируемыми типами данных. Это не полноценная реализация селекторов CSS для браузера.

## Публичный API

### `SelectorGroup`

```go
type SelectorGroup struct {
    Selectors []ComplexSelector
}
```

Разделённая запятыми коллекция сложных селекторов. Группа считается соответствующей, если совпадает хотя бы один её элемент.

### `ComplexSelector`

```go
type ComplexSelector struct {
    Parts []SelectorPart
}
```

Последовательность частей простого селектора. У первой части нет предшествующего комбинатора; последующие части описывают связь с предыдущей.

### `SelectorPart`

```go
type SelectorPart struct {
    Tag        string
    ID         string
    Classes    []string
    Attributes []AttrSelector
    Pseudos    []PseudoSelector
    Combinator string
}
```

Составной селектор. Пустое значение `Tag` означает отсутствие ограничения по тегу; значение `"*"` обозначает универсальный селектор. `Combinator` принимает одно из значений `""`, `" "` (потомок), `">"` (дочерний элемент), `"+"` (соседний элемент) или `"~"` (любой последующий соседний элемент). Идентификаторы, классы, атрибуты и псевдоселекторы хранятся независимо и могут встречаться в исходном тексте в любом порядке.

### `AttrSelector`

```go
type AttrSelector struct {
    Name  string
    Op    string
    Value string
}
```

Ограничение по атрибуту. Поддерживаются операторы наличия (`""`), точного совпадения (`"="`), токена, разделённого пробелами (`"~="`), языкового префикса (`"|="`), префикса (`"^="`), суффикса (`"$="`) и подстроки (`"*="`). Имена при разборе преобразуются в нижний регистр.

### `PseudoSelector`

```go
type PseudoSelector struct {
    Name string
    Arg  string
}
```

Ограничение, подобное псевдоклассу, с необязательным аргументом в скобках. Синтаксис псевдоэлементов с двумя двоеточиями разбирается как имя с одним двоеточием для сопоставления.

### `ParseSelectorGroup`

```go
func ParseSelectorGroup(s string) (*SelectorGroup, error)
```

Удаляет пробелы по краям и разбирает разделённые запятыми селекторы. Пустая строка или строка только из пробелов возвращает пустую группу без ошибки. Пустые элементы, образованные запятыми, пропускаются. Некорректный синтаксис возвращает ошибку; вызывающая сторона не должна рассчитывать на возврат частично разобранной группы.

### `MatchesSelector`

```go
func MatchesSelector(n *Node, selector string) bool
```

Возвращает `true`, если `n` соответствует хотя бы одному селектору во входной группе. Для нулевых узлов и узлов, не являющихся `ElementNode`, возвращает `false`. Ошибки разбора также приводят к `false`, поэтому этот вспомогательный API не предоставляет сведения о синтаксических ошибках.

### `QueryAllSelector`

```go
func QueryAllSelector(root *Node, selector string) []*Node
```

Возвращает соответствующие элементы-потомки в порядке обхода дерева. Сам корневой узел не проверяется. Некорректный селектор возвращает `nil`; корректный селектор без совпадений возвращает пустой срез результатов.

### `QuerySelectorSelector`

```go
func QuerySelectorSelector(root *Node, selector string) *Node
```

Возвращает первый соответствующий потомок, найденный `QueryAllSelector`, либо `nil`, если совпадений нет или разбор завершился ошибкой.

## Синтаксис селекторов и поведение парсера

- Запятые разделяют группы селекторов, кроме случаев внутри скобок, круглых скобок или строк в кавычках.
- Составной селектор может включать селектор тега или универсальный селектор, `#id`, `.class`, `[attribute]` или `[attribute operator value]`, а также формы `:pseudo` и `:pseudo(argument)`.
- Пробелы между составными селекторами означают потомка. Явные комбинаторы `>`, `+` и `~` могут окружаться пробелами.
- Идентификаторы ограничены буквами и цифрами Unicode, а также символами `-` и `_`; экранирование не реализовано.
- Значения атрибутов можно заключать в одинарные или двойные кавычки либо задавать как идентификатор. Имена атрибутов приводятся к нижнему регистру, значения сохраняются в разобранном виде.
- Вложенность круглых скобок в аргументах псевдоселекторов отслеживается. Запятые во вложенных конструкциях и строках в кавычках не разделяют внешнюю группу.

## Сопоставление и особенности реализации

Сопоставление выполняется внутренней логикой `matchesComplex` для узлов DOM; разобранные структуры передаются дальше без отдельного представления скомпилированного селектора. Запрос рекурсивно обходит каждый дочерний элемент, проверяет его на соответствие элементам группы, добавляет его не более одного раза, даже если совпали несколько элементов группы, а затем обходит его потомков. Дочерние узлы, не являющиеся элементами, не рассматриваются как кандидаты.

Парсер намеренно упрощён и не реализует полную грамматику CSS: не поддерживаются экранирование, селекторы пространств имён, флаги селекторов атрибутов и многие специфичные для браузеров правила грамматики. `MatchesSelector` и функции запросов преобразуют ошибки разбора в `false` или пустые результаты; используйте `ParseSelectorGroup`, если важно отличить некорректный синтаксис от отсутствия совпадений.
