# Операции запросов JavaScript-моста

В `internal/js/bridge_query.go` реализованы доступные из JavaScript адаптеры для запросов к модели документа и узлов. Каждая функция получает `Context` JavaScriptCore и переданные JavaScript аргументы, вызывает соответствующую операцию запросов Go и преобразует результаты обратно в значения JavaScript.

Эти функции-адаптеры доступны только внутри пакета. Они предназначены для регистрации или вызова окружающим мостом; сам этот файл не определяет глобальные имена JavaScript или поведение регистрации.

## Соглашения об аргументах и результатах

- Аргументы-узлы преобразуются во внутренние идентификаторы узлов с помощью `jsToNodeID`. Отрицательный результат считается недопустимой ссылкой на узел.
- Строковые аргументы считываются с помощью `getArgString`. Большинство адаптеров игнорируют ошибки преобразования; `matchesJS` и `closestJS` явно считают ошибку преобразования неудачей.
- Узлы представляются в JavaScript с помощью `nodeToJS`.
- При отсутствии аргументов и недопустимых ссылках возвращается указанный в таблице маркер. Различие между JavaScript `null` и `undefined` намеренно.
- Результаты-коллекции являются массивами JavaScript, в том числе если результатов нет.

## Операции моста

| Адаптер | Аргументы | Результат и поведение |
| --- | --- | --- |
| `getBodyJS` | Нет | Преобразует тело документа в значение JavaScript; возвращает `null`, если тела нет. Дополнительные аргументы игнорируются. |
| `getElementByIdJS` | Строка `id` | Ищет элемент по ID и возвращает преобразованный узел либо `null`, если аргумент отсутствует или узел не найден. |
| `querySelectorJS` | `nodeID`, строка-селектор | Выполняет запрос внутри указанного узла и возвращает первый совпавший узел либо `null` при отсутствии или недопустимости входных данных, а также если совпадений нет. |
| `querySelectorAllJS` | `nodeID`, строка-селектор | Выполняет запрос внутри указанного узла и возвращает массив преобразованных совпадений. При отсутствии аргументов или недопустимом ID узла возвращает `undefined`; при отсутствии совпадений — пустой массив. |
| `getAttributeJS` | `nodeID`, имя атрибута | Возвращает значение атрибута как строку JavaScript. При отсутствии аргументов или недопустимом ID узла возвращает `null`. Строка, возвращённая базовым поиском, преобразуется напрямую. |
| `getParentNodeJS` | `nodeID` | Возвращает родительский узел либо `null`, если входные данные отсутствуют или недопустимы либо родителя нет. |
| `getChildrenJS` | `nodeID` | Возвращает массив преобразованных дочерних узлов. При отсутствии аргументов или недопустимом ID узла возвращает `undefined`; если дочерних узлов нет — пустой массив. |
| `getElementsByTagNameJS` | Имя тега | Возвращает массив совпавших узлов. Если аргумент отсутствует, возвращает `undefined`; если совпадений нет — пустой массив. |
| `getElementsByClassNameJS` | Имя класса | Возвращает массив совпавших узлов. Если аргумент отсутствует, возвращает `undefined`; если совпадений нет — пустой массив. |
| `matchesJS` | `nodeID`, строка-селектор | Возвращает логическое значение JavaScript. При отсутствии аргументов, недопустимом ID узла или ошибке преобразования селектора возвращает `false`; в остальных случаях вызывает `matches`. |
| `closestJS` | `nodeID`, строка-селектор | Возвращает ближайший совпавший узел либо `null`. При отсутствии или недопустимости входных данных, ошибке преобразования селектора или отсутствии совпадений возвращает `null`. |
| `previousElementSiblingJS` | `nodeID` | Возвращает предыдущий соседний элемент либо `null`, если он недоступен или входные данные недопустимы. |
| `nextElementSiblingJS` | `nodeID` | Возвращает следующий соседний элемент либо `null`, если он недоступен или входные данные недопустимы. |
| `firstElementChildJS` | `nodeID` | Возвращает первый дочерний элемент либо `null`, если он недоступен или входные данные недопустимы. |
| `lastElementChildJS` | `nodeID` | Возвращает последний дочерний элемент либо `null`, если он недоступен или входные данные недопустимы. |

## Детали реализации

Адаптеры сохраняют правила сопоставления и обхода базовых функций запросов; разбор селекторов, обход дерева и поиск узлов реализованы в других местах. Преобразование результатов централизовано в `nodeToJS`, а для примитивных значений используются конструкторы `Context`.

Для операций со списками каждый узел Go по отдельности преобразуется в `C.JSValueRef`, после чего `_makeArray` создаёт массив JavaScript. Для пустых результатов `_makeArray` вызывается с нулевым указателем на значения и нулевым количеством. Ссылка на локальное исключение передаётся вспомогательной функции C, но этот файл не проверяет её и не преобразует в ошибку Go.

Для `getBodyJS` и `getElementByIdJS` аргумент с ID узла не требуется. Все остальные операции, работающие с узлом, отклоняют ID, преобразовавшийся в отрицательное значение, до вызова уровня запросов. `getAttributeJS`, `querySelectorJS` и поиск по тегу или классу игнорируют ошибки преобразования строк, тогда как ошибки преобразования селектора явно обрабатываются в `matchesJS` и `closestJS`.
