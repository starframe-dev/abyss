# Мост JavaScript для стилей и журналирования

В этом файле реализованы обработчики, вызываемые из JavaScript, для получения вычисленных стилей, геометрии элементов и записи сообщений в журнал. Обработчики находятся в пакете `js` и обмениваются значениями JavaScriptCore через обёртку `Context` пакета и вспомогательные функции преобразования идентификаторов узлов.

## Обработчики

Эти функции — внутренние для пакета точки входа обратных вызовов, а не экспортируемый API Go. Предполагается, что они регистрируются или вызываются мостом JavaScript.

### `getComputedStyleJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

- Требует как минимум один аргумент. Если аргументов нет, возвращает JavaScript `null`.
- Преобразует первый аргумент в идентификатор узла с помощью `jsToNodeID`.
- Если результат преобразования — отрицательный идентификатор, возвращает JavaScript `null`.
- В противном случае напрямую возвращает результат `getComputedStyle(id)`.
- Дополнительные аргументы игнорируются.

### `getBoundingClientRectJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

- Требует как минимум один аргумент и допустимый неотрицательный идентификатор узла; в противном случае возвращает JavaScript `null`.
- Получает прямоугольник с помощью `getBoundingClientRect(id)` и создаёт обычный JavaScript-объект с числовыми свойствами:

| Свойство | Значение |
| --- | --- |
| `x` | `rect.X` |
| `y` | `rect.Y` |
| `width` | `rect.Width` |
| `height` | `rect.Height` |
| `top` | `rect.Y` |
| `left` | `rect.X` |
| `bottom` | `rect.Y + rect.Height` |
| `right` | `rect.X + rect.Width` |

Объект преобразуется в `JSValueRef` с помощью `jsObjToVal`. Свойства создаются без специальных атрибутов JavaScript. Дополнительные входные аргументы игнорируются.

### `logJS(ctx *Context, args []C.JSValueRef) C.JSValueRef`

Преобразует каждый аргумент с помощью `getArgString` и записывает одну строку в стандартный поток ошибок. Неудачные преобразования представлены как `<error>`. Вывод состоит из префикса `[JS] `, аргументов, разделённых одиночными пробелами, и завершающего символа новой строки.

Перед записью управляющие символы заменяются символом Unicode замены (`�`), за исключением новой строки и табуляции; завершающая новая строка сообщения сохраняется. Символ DEL (`0x7f`) также заменяется. Полученная строка передаётся вспомогательной функции C-моста `_fprintf_stderr`. Обработчик возвращает JavaScript `undefined`.

## Примечания по реализации

- В этом файле используются cgo и API JavaScriptCore на C для создания объекта прямоугольника и его числовых свойств.
- Временные строки C и имена свойств `JSStringRef` освобождаются после установки каждого свойства; строка C, составленная для журнала, также освобождается после записи.
- Объявления вспомогательных функций в преамбуле cgo предоставлены реализацией моста. В этом файле напрямую используется лишь часть из них.
- Поиск узла, вычисление стилей, расчёт прямоугольника, преобразование аргументов в строки и преобразование значений JavaScript делегированы вспомогательным функциям в других местах пакета.
