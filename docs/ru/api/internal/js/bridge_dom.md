# Мост JavaScript для DOM

`internal/js/bridge_dom.go` реализует адаптеры для вызова операций DOM из JavaScript. Каждый обработчик получает контекст JavaScriptCore и массив исходных аргументов JavaScript, преобразует значения во внутренние идентификаторы узлов или строки, вызывает реализацию DOM, а затем возвращает соответствующее значение JavaScript.

Эти функции Go являются непубличными функциями пакета, а не экспортируемым API Go. Предполагается, что они регистрируются и вызываются через мост JavaScript в другом месте пакета `internal/js`.

## Сводка API

| Обработчик | Порядок аргументов | Результат |
| --- | --- | --- |
| `createElementJS` | `tagName` | Обёртка только что созданного элемента; при отсутствии аргумента возвращается `undefined`. Пустое имя тега заменяется на `div`. |
| `appendChildJS` | `parent, child` | Исходный аргумент `child` при успехе; иначе `undefined`. |
| `setInnerHTMLJS` | `node, html` | `undefined`. |
| `setAttributeJS` | `node, name, value` | `undefined`. |
| `setTextContentJS` | `node, text` | `undefined`. |
| `createTextNodeJS` | `text` | Обёртка только что созданного текстового узла; при отсутствии аргумента возвращается `undefined`. |
| `createDocumentFragmentJS` | нет | Обёртка только что созданного фрагмента документа. |
| `getInnerHTMLJS` | `node` | Строка HTML; при отсутствии или недопустимости узла возвращается пустая строка. |
| `getTextContentJS` | `node` | Текстовая строка; при отсутствии или недопустимости узла возвращается пустая строка. |
| `removeChildJS` | `parent, child` | Исходный аргумент `child` при успехе; иначе `undefined`. |
| `insertBeforeJS` | `parent, newNode, referenceNode` | Исходный аргумент нового узла при успехе; иначе `undefined`. |
| `replaceChildJS` | `parent, newNode, oldNode` | Исходный аргумент старого узла при успехе; иначе `undefined`. |
| `cloneNodeJS` | `node, deep?` | Обёртка клона; при отсутствии или недопустимости узла либо ошибке клонирования возвращается `null`. Значение `deep` преобразуется с учётом истинности JavaScript и по умолчанию равно `false`. |
| `containsJS` | `parent, child` | Логическое значение; при отсутствии или недопустимости аргументов возвращается `false`. |
| `insertAdjacentHTMLJS` | `node, position, html` | `undefined`. |
| `insertAdjacentTextJS` | `node, position, text` | `undefined`. |
| `insertAdjacentElementJS` | `node, element, position` | Исходный аргумент элемента; при отсутствии или недопустимости аргументов-узлов возвращается `null`. |
| `outerHTMLJS` | `node` | Сериализованная строка внешнего HTML; при отсутствии или недопустимости узла возвращается пустая строка. |
| `setOuterHTMLJS` | `node, html` | `undefined`. |

Аргументы-узлы преобразуются с помощью `jsToNodeID`; отрицательный идентификатор считается недопустимым. Строковые аргументы преобразуются с помощью `getArgString`. Обработчики обычно игнорируют ошибки преобразования и используют возвращённое строковое значение, поэтому вызывающим сторонам следует передавать значения ожидаемого формата.

## Изменения DOM и состояние отрисовки

После успешного изменения обработчики вызывают `SetDirty()`, чтобы хост мог обновить отрисованное состояние. `appendChildJS`, `removeChildJS`, `setInnerHTMLJS` и `setAttributeJS` также вызывают `css.InvalidateCache()`, поскольку эти операции могут повлиять на разрешение стилей. Остальные адаптеры изменения помечают DOM как требующий обновления, но в этом файле явно не инвалидируют кэш CSS.

Адаптеры не передают ошибки изменения в виде исключений JavaScript. Большинство некорректных вызовов возвращает `undefined`; запросы возвращают пустые строки или `false`, а клонирование и вставка соседнего элемента — `null` в указанных случаях ошибки. Детали изменения дерева и сериализации определяются базовыми функциями DOM.

## Детали реализации

- Обёртки возвращаемых узлов создаются с помощью `nodeToJS`; создаваемые узлы поступают из `createElement`, `createTextNode` и `createDocumentFragment`.
- Методы изменения возвращают исходный аргумент JavaScript в тех случаях, когда операции в стиле DOM обычно возвращают узел. Так сохраняется переданное значение JS вместо создания другой обёртки.
- `insertBeforeJS` передаёт идентификатор опорного узла без явной проверки на отрицательное значение; перед вызовом `insertBefore` проверяются только идентификаторы родителя и нового узла.
- `outerHTMLJS` преобразует строку Go в строку C, вызывает вспомогательную функцию моста JavaScriptCore `_makeString` и освобождает временное выделение памяти C с помощью `C.free`.
- Файл импортирует объявления JavaScriptCore через cgo и использует пакет CSS только для явной инвалидации кэша.
