# Встроенный DOM API

`internal/js/domapi_embed.go` упаковывает фрагменты JavaScript, реализующие DOM API, и собирает их в один исполняемый скрипт. Фрагменты встраиваются во время сборки Go, поэтому получившемуся исходному коду не требуется доступ к файловой системе во время выполнения.

## Публичный API

В этом файле не объявлены экспортируемые идентификаторы. Его переменные и функция являются закрытыми деталями реализации пакета `internal/js`.

## Встраиваемые файлы и порядок загрузки

Директива `//go:embed domapi/*.js` встраивает каждый файл JavaScript, соответствующий этому шаблону, в `domapiFiles` типа `embed.FS`. Сборщик считывает только фрагменты, указанные в `domapiFragments`, строго в следующем порядке:

1. `domapi/style.js`
2. `domapi/element.js`
3. `domapi/global.js`

Фрагменты объединяются в указанном порядке с разделителем в виде символа новой строки. Комментарий к `domapiFragments` поясняет, что фрагменты используют общую область видимости IIFE; поэтому порядок может иметь значение, если в последующих фрагментах используются объявления или состояние, созданные ранее.

## Инициализация и выполнение

`domapiJSSource` инициализируется при инициализации пакета вызовом `loadDOMAPI()`. Эта функция считывает каждый указанный файл из встроенной файловой системы и формирует единое JavaScript-выражение:

```js
(function() {
// fragment contents, joined with newlines
})()
```

В конец добавляется символ новой строки. Обёртывание объединённого кода в немедленно вызываемое функциональное выражение обеспечивает фрагментам общую локальную область видимости и изолирует их объявления от окружающей области видимости JavaScript. Полученную строку предполагается использовать в другом коде пакета, который выполняет или передаёт исходный код DOM API.

## Ошибки и замечания по сопровождению

`loadDOMAPI` вызывает панику, если не удаётся прочитать какой-либо указанный фрагмент; сообщение содержит имя фрагмента и исходную ошибку чтения. Поскольку файлы встраиваются во время сборки, отсутствие указанного фрагмента или невозможность его прочитать означает ошибку упаковки или структуры исходного кода, а не сбой доступа к файловой системе во время выполнения.

При добавлении фрагмента внесите его базовое имя в `domapiFragments` в нужную позицию. Сам по себе шаблон встраивания не приводит к загрузке файла. При изменении порядка учитывайте предположения об общей области видимости и зависимости между фрагментами.
