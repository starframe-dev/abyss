# Мост стилей DOM

`internal/js/dom_style.go` связывает вычисленные CSS-стили и результаты компоновки с мостом DOM на базе JavaScriptCore. Он хранит снимки с ключами в виде узлов DOM Go, разрешает идентификаторы узлов моста в эти узлы и предоставляет JavaScript данные о геометрии и вычисленных стилях.

## Публичный API

### `SetComputedStyles(styles map[*dom.Node]css.ComputedStyle)`

Заменяет снимок вычисленных стилей, используемый мостом DOM. Ключами карты являются указатели на узлы. Присваивание защищено мьютексом `computedStylesMu`; функция не объединяет данные с предыдущим снимком и не копирует карту.

### `SetLayoutBoxes(boxes map[*dom.Node]Rect)`

Заменяет снимок прямоугольников компоновки, используемый мостом `getBoundingClientRect`. Ключами карты являются указатели на узлы; присваивание выполняется под мьютексом `layoutBoxesMu` без объединения данных и копирования.

Оба сеттера принимают `nil`. Снимок `nil` ведёт себя как отсутствующий результат: поиск вычисленного стиля возвращает JavaScript `null`, а поиск геометрии — нулевой `Rect`.

## Поведение моста

### Поиск ограничивающего прямоугольника

Внутренняя функция `getBoundingClientRect(nodeID NodeID) Rect` блокирует снимок компоновки, затем разрешает `nodeID` через глобальный реестр узлов под мьютексом `nodeMu`. Она возвращает связанный прямоугольник, только если существуют снимок, идентификатор узла, указатель на узел и запись в карте. Во всех случаях отсутствующих данных возвращается `Rect{}`. Эта функция возвращает значение Go и сама не создаёт объект JavaScript.

### Поиск вычисленного стиля

Внутренняя функция `getComputedStyle(nodeID NodeID) C.JSValueRef` разрешает узел тем же способом и ищет его `css.ComputedStyle` в текущем снимке. Если отсутствует снимок, узел или запись стиля, функция возвращает JavaScript `null` с помощью `eventCtx`.

При успешном поиске функция создаёт обычный объект JavaScript в `eventCtx` и заполняет следующие свойства:

| Свойство | Значение JavaScript | Источник |
| --- | --- | --- |
| `display` | Строка | Перечисление отображения преобразуется в текст, похожий на CSS |
| `position` | Строка | Перечисление позиции преобразуется в текст, похожий на CSS |
| `overflow` | Строка | Перечисление переполнения преобразуется в текст |
| `width` | Число | `Width.Px` |
| `widthUnit` | Строка | `Width.String()` |
| `height` | Число | `Height.Px` |
| `heightUnit` | Строка | `Height.String()` |
| `color` | Строка | `Color.String()` |
| `backgroundColor` | Строка | `BackgroundColor.String()` |
| `marginTop`, `marginRight`, `marginBottom`, `marginLeft` | Число | Соответствующие значения `Px` для отступов |
| `paddingTop`, `paddingRight`, `paddingBottom`, `paddingLeft` | Число | Соответствующие значения `Px` для внутренних отступов |
| `borderTopWidth`, `borderRightWidth`, `borderBottomWidth`, `borderLeftWidth` | Число | Соответствующая ширина границы |
| `flexDirection` | Строка | Направление flex-преобразования преобразуется в текст |
| `justifyContent` | Строка | Выравнивание по главной оси преобразуется в текст |
| `alignItems` | Строка | Выравнивание элементов преобразуется в текст |
| `flexGrow`, `flexShrink` | Число | Соответствующие вычисленные значения |
| `zIndex` | Число | Целое число преобразуется в `float64` |
| `gap` | Число | `Gap.Px` |

Созданный объект возвращается через `jsObjToVal`. Числовые размеры и интервалы предоставляются в пикселях; для ширины и высоты дополнительно сохраняются исходные отформатированные строки единиц измерения в `widthUnit` и `heightUnit`.

## Преобразование перечислений в строки

Внутренние функции преобразования задают поддерживаемое мостом текстовое представление:

- Отображение: `inline`, `inline-block`, `flex`, `grid` или `none`; неизвестные значения и значение по умолчанию преобразуются в `block`.
- Позиция: `relative` или `absolute`; остальные значения преобразуются в `static`.
- Переполнение: `hidden` для `css.OverflowHidden`, иначе `visible`.
- Направление flex: `column` для `css.FlexDirectionColumn`, иначе `row`.
- Выравнивание по главной оси: `center`, `flex-end`, `space-between` или `space-around`; остальные значения преобразуются в `flex-start`.
- Выравнивание элементов: `center`, `flex-end` или `stretch`; остальные значения преобразуются в `flex-start`.

## Примечания по реализации

Карты снимков и реестр узлов являются общим состоянием моста. Каждый сеттер защищает замену своей карты соответствующим мьютексом. При поиске блокируется мьютекс снимка во время проверки карты; для разрешения идентификатора ненадолго захватывается `nodeMu`, который затем освобождается до обращения к записи снимка. Поэтому вызывающим сторонам следует публиковать согласованные снимки и не изменять карту после передачи её сеттеру: сеттер сохраняет ссылку на карту, а не создаёт защитную копию.

Имена свойств JavaScript и строковые значения создаются с помощью C API JavaScriptCore; для свойств используется `kJSPropertyAttributeNone`. Этот файл зависит от уже существующих в пакете `eventCtx`, реестра узлов, `NodeID`, `Rect` и вспомогательной функции преобразования значений JavaScript; он не определяет эти типы и не выполняет вычисление CSS или компоновку.
