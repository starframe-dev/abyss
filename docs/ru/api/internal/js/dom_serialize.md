# Сериализация DOM

Этот модуль реализует вспомогательные функции сериализации HTML и текста для DOM, доступного из JavaScript, а также замену узла содержимым HTML-фрагмента. Функции доступны только внутри пакета: они используются пакетом `internal/js` и не экспортируются как API Go.

## Поведение

### Внутренний HTML и текстовое содержимое

`getInnerHTML(id NodeID) string` находит узел под блокировкой `nodeMu` и сериализует все его дочерние узлы по порядку. Сам выбранный узел не сериализуется. Для отсутствующего ID возвращается пустая строка.

`getTextContent(id NodeID) string` находит узел под той же блокировкой и объединяет текст потомков в порядке обхода дерева. Для текстового узла `collectText` возвращает его текст без изменений; для узлов других типов функция рекурсивно объединяет дочерние узлы. Для отсутствующего ID возвращается пустая строка. Текстовое содержимое не экранируется для HTML.

### Сериализация HTML

`serializeNode` сериализует текстовые узлы, экранируя их текст, а узлы-элементы — как открывающий тег, атрибуты, дочерние узлы и закрывающий тег. Атрибуты выводятся в лексикографически отсортированном порядке ключей, поэтому результат не зависит от порядка перебора map. Значения атрибутов экранируются и заключаются в кавычки, только если они не пусты; пустые значения выводятся как имя атрибута без значения.

При экранировании текста и атрибутов символы `&`, `<`, `>` и `"` заменяются соответствующими HTML-сущностями. Остальные символы не изменяются. Имена тегов и атрибутов выводятся в сохранённом виде, без нормализации и экранирования. Узлы, не являющиеся текстовыми узлами или элементами, ничего не добавляют в результат.

Элемент из `voidElements`, у которого нет дочерних узлов, сериализуется с окончанием ` />` и без закрывающего тега. Распознаются имена `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `link`, `meta`, `param`, `source`, `track` и `wbr`. Элемент без дочерних узлов, но с детьми сериализуется обычным способом — парой тегов.

`outerHTMLString(nodeID NodeID) string` возвращает результат `OuterHTML()` для узла. Функция ненадолго блокирует `nodeMu`, чтобы получить узел, а затем вызывает `OuterHTML` после снятия блокировки. Если узел отсутствует или равен nil, возвращается пустая строка.

### Замена внешнего HTML

`setOuterHTML(nodeID NodeID, html string)` заменяет узел дочерними узлами из `dom.ParseFragment(html)`, помещая их на то же место в родительском узле. Функция ничего не делает, если узел отсутствует, равен nil, отсоединён (не имеет родителя), разбор возвращает nil или узел не удаётся найти среди дочерних узлов родителя.

При успешной замене старый узел отсоединяется, каждому вставленному узлу назначается родитель и вызывается `assignIDsToNew`, а кэш CSS инвалидируется с помощью `css.InvalidateCache()`. Пустой разобранный фрагмент удаляет целевой узел, не вставляя замену.

## Синхронизация и примечания по реализации

Для карты узлов и изменений дерева используется пакетная блокировка `nodeMu`. При получении внутреннего HTML и сборе текста блокировка удерживается во время рекурсивного обхода. `outerHTMLString` и первоначальный поиск в `setOuterHTML` снимают блокировку перед вызовом методов узла или разбором; `setOuterHTML` повторно захватывает её для поиска и изменения списка дочерних узлов родителя. Разбор выполняется до захвата блокировки для изменения дерева. При координации параллельных операций с DOM следует учитывать эти границы блокировок.

Сериализация формирует результат с помощью `strings.Builder`; проверка и нормализация HTML на уровне браузера не выполняются. Экранирование намеренно ограничено четырьмя перечисленными выше символами.

## Справочник API

| Функция | Видимость | Назначение |
| --- | --- | --- |
| `getInnerHTML(id NodeID) string` | Не экспортируется | Сериализовать дочерние узлы узла в HTML. |
| `getTextContent(id NodeID) string` | Не экспортируется | Объединить текст потомков. |
| `collectText(n *dom.Node) string` | Не экспортируется | Рекурсивно собрать текст узла. |
| `serializeNode(b *strings.Builder, n *dom.Node)` | Не экспортируется | Добавить HTML-представление узла. |
| `escapeHTML(s string) string` | Не экспортируется | Экранировать поддерживаемые специальные символы HTML. |
| `outerHTMLString(nodeID NodeID) string` | Не экспортируется | Вернуть внешний HTML узла или пустую строку, если узел отсутствует. |
| `setOuterHTML(nodeID NodeID, html string)` | Не экспортируется | Заменить узел разобранным HTML-фрагментом. |
