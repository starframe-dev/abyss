# Вставка в DOM

Этот модуль реализует операции вставки в DOM для реестра узлов в `internal/js`. Изменения защищены мьютексом `nodeMu`; успешные операции, влияющие на структуру CSS, инвалидируют кэш CSS.

## Публичный API

### `InsertAdjacentHTML(nodeID NodeID, position, html string)`

Разбирает `html` с помощью `dom.ParseFragment` и вставляет полученные узлы верхнего уровня относительно зарегистрированного узла. Обёртка фрагмента не вставляется, поэтому текстовые узлы верхнего уровня сохраняются как обычные соседи или потомки. Новым вставленным узлам назначаются идентификаторы реестра с помощью `assignIDsToNew`.

Поддерживаемые позиции:

| Позиция | Результат |
| --- | --- |
| `beforebegin` | Вставить непосредственно перед целевым узлом среди дочерних узлов его родителя. Требуется родитель. |
| `afterbegin` | Добавить в начало списка дочерних узлов целевого узла. |
| `beforeend` | Добавить в конец списка дочерних узлов целевого узла. |
| `afterend` | Вставить непосредственно после целевого узла среди дочерних узлов его родителя. Требуется родитель. |

Неизвестные позиции, отсутствующие целевые узлы, пустые результаты разбора и пустые фрагменты не приводят к изменениям. Для позиций `beforebegin` и `afterend` у целевого узла должен быть родитель.

## Внутренние операции

### `insertBefore(parentID, newNodeID, refNodeID NodeID)`

Вставляет зарегистрированный узел перед дочерним узлом-ориентиром либо добавляет его в конец, если ориентир отсутствует, имеет отрицательный идентификатор или не является дочерним узлом указанного родителя. Ничего не делает, если родитель или новый узел отсутствует либо равен nil, новый узел совпадает с ориентиром или его перемещение создало бы цикл. Перед вставкой существующая связь с родителем удаляется.

Для `DocumentFragmentNode` действует особое правило: его дочерние узлы вставляются по порядку перед ориентиром (или добавляются в конец), а сам фрагмент опустошается. Перед изменением проверяется, не создаст ли цикл каждый дочерний узел фрагмента.

### `replaceChild(parentID, newNodeID, oldNodeID NodeID)`

Заменяет `oldNode` в списке дочерних узлов указанного родителя. Отсутствующие узлы, недопустимые идентификаторы, совпадение нового узла с родителем или старым узлом, отсутствие старого дочернего узла и перемещения, создающие цикл, игнорируются. При обычной замене новый узел сначала отсоединяется от текущего родителя, затем очищается указатель родителя старого узла и устанавливается новый узел.

Если вместо узла передан фрагмент документа, его дочерние узлы по порядку заменяют старый дочерний узел, а сам фрагмент опустошается. Старый узел отсоединяется. Если старый узел не является дочерним узлом указанного родителя, замена не выполняется.

### `insertAdjacentText(nodeID NodeID, position, text string)`

Создаёт `TextNode` и вставляет его в одну из четырёх соседних позиций, перечисленных выше. Это внутренний вспомогательный метод. В отличие от `InsertAdjacentHTML`, он не назначает идентификатор реестра и не инвалидирует кэш CSS в этой функции. Недопустимые целевые узлы игнорируются. Обработка позиции реализована с помощью `switch`; неподдерживаемые позиции не приводят к вставке.

### `insertAdjacentElement(nodeID, elemID NodeID, position string)`

Перемещает существующий зарегистрированный узел в одну из четырёх соседних позиций. Метод проверяет целевой узел и элемент, требует наличия родителя для соседних позиций, отклоняет неподдерживаемые позиции и перемещения, создающие цикл, отсоединяет элемент от текущего родителя и затем вставляет его. Успешные вызовы инвалидируют кэш CSS.

### `insertSiblingNodes(n *dom.Node, newNodes []*dom.Node, after bool)`

Внутренний вспомогательный метод, вставляющий узлы в список дочерних узлов родителя `n` непосредственно до или после `n`. Устанавливает указатель родителя для каждого вставленного узла. Ничего не делает, если у `n` нет родителя или он отсутствует в списке дочерних узлов этого родителя.

### `insertFragmentChildrenLocked(parent, fragment, refNode *dom.Node)`

Внутренний вспомогательный метод для вставки фрагмента. Вызывающий код должен удерживать блокировку `nodeMu`. Метод копирует срез дочерних узлов фрагмента перед вставкой, задаёт каждому дочернему узлу родителя `parent`, вставляет узлы перед совпадающим ориентиром или добавляет их в конец и очищает `fragment.Children`.

## Примечания по реализации

- Поиск узлов и изменение дерева используют реестр пакета `nodes` и блокировку `nodeMu`.
- Для предотвращения циклов при перемещении узлов и дочерних узлов фрагмента, где применимо, используется `wouldCreateCycle`.
- При вставке фрагмента переносятся его дочерние узлы, а сам узел фрагмента не добавляется.
- Кэш инвалидируется после успешных изменений через `insertBefore`, `replaceChild`, `InsertAdjacentHTML` и `insertAdjacentElement`. `insertAdjacentText` здесь его не инвалидирует.
- Недопустимые операции обычно молча игнорируются; эти вспомогательные методы не возвращают ошибки или результаты.
