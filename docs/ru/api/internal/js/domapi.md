# Скрипт DOM API

Пакет `internal/js` предоставляет `DOMAPIScript` — средство Go для доступа к исходному коду JavaScript, реализующему мост DOM API.

## Публичный API

### `DOMAPIScript() string`

Возвращает исходный код JavaScript, хранящийся в значении уровня пакета `domapiJSSource`. Возвращённая строка предназначена для выполнения вызывающей стороной в среде выполнения JavaScript.

Скрипт DOM API необходимо выполнять **после** того, как `RegisterBridgeFunctions` зарегистрирует используемые им функции моста. Этот порядок является частью контракта API; если выполнить скрипт раньше, его зависимости от моста могут оказаться недоступны.

## Подробности реализации

`DOMAPIScript` — это простой метод доступа: он напрямую возвращает `domapiJSSource` и самостоятельно не выполняет код, не регистрирует функции, не проверяет данные и не обрабатывает ошибки. Вызывающая сторона отвечает за выполнение возвращённого исходного кода и за то, чтобы регистрация функций моста уже была произведена.
