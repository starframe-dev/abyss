# DOM API `internal/js`

`dom_api.go` предоставляет вызываемые из Go вспомогательные функции для работы с DOM из пакета `js`. Эти функции представляют собой тонкие обёртки над каноническими реализациями моста пакета и работают со значениями `*internal/dom.Node` или дескрипторами `NodeID`. В файле эти функции описаны именно как публичные Go-хелперы для работы с DOM, используемые интеграционными тестами; отдельную реализацию DOM он не определяет.

## Типы и дескрипторы

- **`NodeID`** — идентификатор уровня пакета для зарегистрированных узлов. Его базовое представление и правила выделения определены в другом месте пакета `js`.
- **`*dom.Node`** — тип узла, возвращаемый конструкторами и операциями поиска и обхода.
- **`GetNodeByID`** возвращает и узел, и флаг `ok`, позволяя отличить отсутствующий идентификатор от действительного соответствия. Остальные обёртки предоставляют поведение соответствующих канонических функций моста; этот файл не добавляет результатов ошибок или проверок.

## Создание узлов и поиск

| Функция | Поведение |
| --- | --- |
| `CreateElement(tagName string) *dom.Node` | Создаёт элемент с указанным именем тега. |
| `CreateTextNode(text string) *dom.Node` | Создаёт текстовый узел с указанным текстом. |
| `CreateDocumentFragment() *dom.Node` | Создаёт узел-фрагмент документа. |
| `GetNodeID(n *dom.Node) NodeID` | Возвращает идентификатор узла. |
| `GetNodeByID(id NodeID) (*dom.Node, bool)` | Ищет идентификатор в реестре узлов пакета. |
| `GetBody() *dom.Node` | Возвращает элемент body документа. |
| `GetElementByID(id string) *dom.Node` | Находит элемент по атрибуту `id`. |

При чтении общего реестра `nodes` функция `GetNodeByID` захватывает `nodeMu` и освобождает его перед возвратом. Если запись в реестре отсутствует, возвращаются нулевой указатель на узел и `false`.

## Изменение дерева

| Функция | Поведение |
| --- | --- |
| `AppendChild(parentID, childID NodeID)` | Добавляет указанный узел-потомок к указанному родителю. |
| `InsertBefore(parentID, newNodeID, refNodeID NodeID)` | Вставляет узел перед опорным узлом. |
| `ReplaceChild(parentID, newNodeID, oldNodeID NodeID)` | Заменяет дочерний узел другим узлом. |
| `RemoveChild(parentID, childID NodeID)` | Удаляет дочерний узел из родителя. |
| `CloneNode(id NodeID, deep bool) *dom.Node` | Клонирует узел; параметр `deep` определяет, клонировать ли его потомков. |

Эти функции напрямую делегируют работу вспомогательным функциям моста. Их сигнатуры не предоставляют ошибок или сведений о результате изменения; при обработке недопустимых идентификаторов или ограничений дерева следует обращаться к описанию поведения канонических функций.

## Содержимое и атрибуты

| Функция | Поведение |
| --- | --- |
| `SetInnerHTML(id NodeID, html string)` | Задаёт внутренний HTML узла. |
| `GetInnerHTML(id NodeID) string` | Возвращает внутренний HTML узла. |
| `SetAttribute(id NodeID, name, value string)` | Задаёт атрибут с указанным именем. |
| `GetAttribute(id NodeID, name string) string` | Возвращает значение указанного атрибута. |
| `SetTextContent(id NodeID, text string)` | Задаёт текстовое содержимое узла. |
| `GetTextContent(id NodeID) string` | Возвращает текстовое содержимое узла. |

Слой обёрток не описывает и не изменяет семантику разбора, сериализации, отсутствующих атрибутов или недопустимых узлов: она определяется делегируемыми реализациями.

## Инспекция дерева и селекторы

| Функция | Поведение |
| --- | --- |
| `Contains(id, otherID NodeID) bool` | Сообщает, содержит ли узел с идентификатором `id` другой узел. |
| `FirstElementChild(id NodeID) *dom.Node` | Возвращает первый дочерний элемент. |
| `LastElementChild(id NodeID) *dom.Node` | Возвращает последний дочерний элемент. |
| `QuerySelector(id NodeID, selector string) *dom.Node` | Возвращает первый подходящий элемент в соответствующей области поиска. |
| `QuerySelectorAll(id NodeID, selector string) []*dom.Node` | Возвращает все подходящие элементы в соответствующей области поиска. |
| `Matches(id NodeID, selector string) bool` | Сообщает, соответствует ли указанный элемент селектору. |
| `Closest(id NodeID, selector string) *dom.Node` | Возвращает ближайшего подходящего предка согласно делегированной реализации. |

Синтаксис селекторов, детали области поиска, порядок результатов и поведение при отсутствии совпадений в этом файле не реализованы и определяются каноническими функциями моста.

## Примечания по реализации

Все функции, кроме `GetNodeByID`, напрямую делегируют работу и не добавляют собственной синхронизации, преобразования, проверки или обработки ошибок. Исключение — `GetNodeByID`: она защищает доступ к реестру мьютексом пакета. Таким образом, API представляет собой удобный интерфейс к внутренним компонентам пакета, а не самостоятельную абстракцию с дополнительными гарантиями.
