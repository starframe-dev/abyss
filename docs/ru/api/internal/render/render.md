# `internal/render`

Пакет `render` отображает дерево layout в пиксельный фреймбуфер. Он рисует фоны блоков, границы и растровые изображения, преобразованные в цветные ASCII-ячейки. Полученный фреймбуфер можно считывать или иным образом использовать в вызывающем коде.

## Публичный API

### `ImageProvider`

```go
var ImageProvider func(src string) image.Image
```

Необязательная переменная обратного вызова уровня пакета для получения изображения по URL источника. Возвращает декодированное `image.Image` или `nil`, если изображение недоступно. Предполагается, что вызывающий код настроит её при запуске. Если она не задана, URL источника отсутствует или функция возвращает `nil`, квантование изображения пропускается.

### `Render`

```go
func Render(tree *layout.LayoutBox, viewportWidth int) *framebuffer.Framebuffer
```

Отрисовывает `tree` и возвращает новый фреймбуфер шириной `viewportWidth`; его высота определяется протяжённостью внешних границ блоков дерева с учётом отступов. Для nil-дерева возвращается фреймбуфер размером 1 на 1.

Отрисовка выполняется следующим образом:

1. Собираются корневой узел и все его потомки в порядке прямого обхода.
2. Определяются отрицательные минимальные координаты отступов, затем вся геометрия макета и координаты строк текста сдвигаются так, чтобы эти минимумы стали неотрицательными.
3. Определяется максимальная вертикальная протяжённость и выделяется фреймбуфер.
4. Он очищается цветом фона корневого узла, если он задан, иначе белым (`RGB(255, 255, 255)`).
5. Блоки стабильно сортируются по возрастанию z-index и отрисовываются. Блоки с одинаковым z-index сохраняют порядок прямого обхода, поэтому потомки рисуются поверх предков.

Входное дерево макета изменяется на месте при сдвиге координат. При отрисовке изображений также могут заполняться `AsciiCells` и очищаться строки-заполнители `TextLines` у блоков макета.

## Поведение отрисовки

Каждый блок обрабатывается в порядке рисования:

- Если задан цвет фона, рисуется скруглённый прямоугольник по границам блока с четырьмя вычисленными радиусами углов.
- Иначе узлы `input` и `textarea` с положительной высотой границы получают светло-серую скруглённую поверхность (`RGB(241, 243, 244)`); радиус равен половине высоты границы.
- Иначе узлы `img` квантуются и рисуются в виде ASCII-ячеек, если доступны данные изображения. Если изображения нет, для изображений, не позиционированных абсолютно, отображается нейтральная скруглённая заглушка (`RGB(226, 232, 240)`). Абсолютно позиционированные изображения без квантированного содержимого пропускаются, чтобы заглушка не перекрывала содержимое под ними.
- Настроенные границы рисуются после фона или изображения с использованием ширины и цвета каждой стороны. Отрисовка границ включается, если стиль хотя бы одной стороны отличается от `BorderNone`.

## Квантование изображений и ячейки

Для блока изображения рендерер сначала повторно использует уже заполненные `LayoutBox.AsciiCells`. В противном случае он получает у узла `src`, запрашивает декодированное изображение через `ImageProvider` и квантует его с помощью `asciirender.Quantize`.

Размеры сетки вычисляются делением размеров содержимого соответственно на `cellmetrics.WidthPx` и `cellmetrics.HeightPx`; каждый размер ограничивается снизу одной ячейкой. В качестве фона квантователя используется фон блока, если он задан, иначе `RGB(226, 232, 240)`. Полученная сетка кэшируется в блоке. Поскольку при раскладке в `TextLines` могла быть помещена строка-заполнитель с alt-текстом изображения, при создании настоящих ASCII-ячеек эти строки очищаются, чтобы заглушка не перекрывала изображение.

`drawAsciiCells` распределяет ячейки сетки по прямоугольнику границ блока. Для ячеек с заданным цветом переднего плана заполняется соответствующий срез фреймбуфера; ячейки без такого цвета не закрашивают срез. Справа отрисовка обрезается по ширине фреймбуфера.

## Примечания по реализации

- Высота фреймбуфера рекурсивно вычисляется по `Margin.Y + Margin.Height` каждого блока и результатам для его потомков. Отдельное ограничение по высоте области просмотра не применяется.
- Отрицательные смещения рассчитываются по координатам X и Y отступов, начиная с нуля, и рекурсивно применяются к координатам содержимого, внутренних отступов, границ, внешних отступов и строк текста.
- `collectBoxes`, `calculateOffset`, `calculateHeight`, `shiftTree`, `drawBox`, `quantizeImageBox` и `drawAsciiCells` — вспомогательные функции, доступные только внутри пакета; они не входят в экспортируемый API.
- `ImageProvider` — общее состояние пакета. Настраивайте её до отрисовки, а не изменяйте одновременно с вызовами `Render`.
