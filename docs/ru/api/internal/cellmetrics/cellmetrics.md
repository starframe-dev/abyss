# `internal/cellmetrics`

Пакет `cellmetrics` задаёт общие размеры ячейки терминала в CSS-пикселях. Макетирование, отрисовка и выборка ASCII могут использовать эти константы, чтобы сохранять согласованность.

## Публичный API

| Константа | Значение | Описание |
| --- | ---: | --- |
| `WidthPx` | `10` | Ширина одной ячейки терминала в CSS-пикселях. |
| `HeightPx` | `20` | Высота одной строки терминала в CSS-пикселях. |

Обе константы — целочисленные константы без заданного типа; их можно использовать как в вычислениях на этапе компиляции, так и в обычной арифметике.

## Поведение и реализация

Пакет не имеет поведения во время выполнения и изменяемого состояния. Его размеры задают общую основу для преобразования координат терминала в размеры в CSS-пикселях:

- Область просмотра шириной `N` столбцов имеет ширину `N * WidthPx` пикселей.
- Строки текста разделены по вертикали на `HeightPx` пикселей.

Значения определены централизованно, чтобы компоненты, вычисляющие макет, отрисовывающие ячейки или выполняющие выборку ASCII, могли использовать одни и те же метрики.
