# `internal/framebuffer`

Пакет `framebuffer` предоставляет ограниченный буфер RGB-пикселей и операции растеризации, используемые для отрисовки блоков макета. Пиксели хранятся как значения `css.Color` из внутреннего CSS-пакета.

## Публичный API

### Ограничения

| Константа | Значение | Описание |
| --- | ---: | --- |
| `MaxWidth` | 4096 | Максимальная допустимая ширина буфера кадров. |
| `MaxHeight` | 4096 | Максимальная допустимая высота буфера кадров. |
| `MaxPixels` | 16,777,216 | Максимальное количество выделяемых пикселей. |

Все три ограничения применяются при создании буфера.

### `Framebuffer`

```go
type Framebuffer struct {
    Width  int
    Height int
    Pixels []css.Color
}
```

`Width` и `Height` задают размеры растра. `Pixels` — срез в построчном порядке: пиксель в точке `(x, y)` занимает индекс `y*Width + x`. Поля и срез экспортированы, поэтому вызывающий код может напрямую проверять или изменять хранилище; при прямом изменении следует сохранять ожидаемые размеры и длину среза.

### `New`

```go
func New(width, height int) *Framebuffer
```

Создаёт буфер, инициализированный нулями. Если хотя бы один размер неположителен, превышает соответствующий лимит или произведение размеров превышает `MaxPixels`, функция возвращает ненулевой пустой `Framebuffer` с нулевыми размерами и без выделенных пикселей. Ограничение на произведение проверяется условием `width > MaxPixels/height`, что позволяет избежать переполнения при умножении после проверки положительности размеров.

### Операции с пикселями

```go
func (fb *Framebuffer) Set(x, y int, c css.Color)
func (fb *Framebuffer) Get(x, y int) css.Color
func (fb *Framebuffer) Clear(c css.Color)
```

- `Set` задаёт цвет, только если получатель не равен nil, а целочисленные координаты находятся в пределах буфера. Запись за пределами буфера игнорируется.
- `Get` возвращает пиксель по координатам внутри буфера. Для nil-получателя или координат за пределами буфера возвращается `css.Transparent()`.
- `Clear` заполняет весь срез пикселей переданным цветом. Для nil-получателя ничего не делает.

### Операции рисования

```go
func (fb *Framebuffer) FillRect(x, y, w, h float64, c css.Color)
func (fb *Framebuffer) DrawBorder(x, y, w, h, topW, rightW, bottomW, leftW float64,
    topC, rightC, bottomC, leftC css.Color)
func (fb *Framebuffer) DrawRoundedRect(x, y, w, h, rtl, rtr, rbr, rbl float64, c css.Color)
```

`FillRect` заполняет прямоугольник с координатами с плавающей точкой, обрезая его по границам буфера. Диапазон покрываемых целочисленных пикселей определяется округлением начала вниз, а конца вверх, поэтому включается любая ячейка пикселя, пересекающая координатный диапазон прямоугольника. Неположительные размеры, координаты или размеры NaN либо бесконечные значения, а также диапазоны, не пересекающиеся с буфером, не приводят к записи пикселей. Вычисления обрезки ограничивают преобразование координат в целые числа безопасным диапазоном.

`DrawBorder` рисует каждый край с положительной шириной посредством `FillRect` в следующем порядке: верхний, правый, нижний, левый. Поэтому при наложении углов их вид определяется более поздним краем в этом порядке. Края с неположительной шириной пропускаются; обрезка выполняется согласно правилам `FillRect`.

`DrawRoundedRect` сначала заполняет весь прямоугольник, затем для каждого заданного угла очищает пиксели за пределами круговой дуги. Радиусы углов задаются в порядке: верхний левый, верхний правый, нижний правый, нижний левый (`rtl`, `rtr`, `rbr`, `rbl`). Обрезка выполняется только для положительных радиусов. Реализация не ограничивает радиусы размерами прямоугольника; перекрывающиеся или слишком большие области углов обрабатываются последовательно, поэтому очистка до прозрачного цвета может затрагивать пиксели, ранее заполненные или обрезанные другим углом.

## Детали растеризации

Внутренняя функция `clippedRange` отклоняет неп конечные начальные координаты и размеры, неположительные размеры и неп конечные конечные координаты. Она ограничивает нужный диапазон интервалом `[0, maxSize]`, затем округляет нижнюю границу вниз, а верхнюю вверх. Для скруглённых углов используется выборка в центрах пикселей: каждый рассматриваемый пиксель проверяется в точке `(px+0.5, py+0.5)` относительно окружности радиуса `r`; пиксели, квадрат расстояния до центра которых превышает `r*r`, становятся прозрачными. Функция обработки угла игнорирует nil-получателей, а также недопустимые или неположительные радиусы и координаты.

Пакет не выполняет смешивание цветов или сглаживание: операции рисования присваивают полные значения `css.Color`, а при обрезке углов пиксели очищаются до прозрачного цвета.
