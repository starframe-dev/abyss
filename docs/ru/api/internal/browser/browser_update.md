# Обновление браузера

`internal/browser/browser_update.go` реализует обработку сообщений для модели Bubble Tea терминального браузера. Она обновляет состояние модели и вкладок в ответ на ввод, изменение размера окна, события таймера и асинхронные результаты загрузки и отрисовки страниц.

## Публичный API

| Символ | Описание |
| --- | --- |
| `(*Model).Update(msg tea.Msg) (tea.Model, tea.Cmd)` | Реализация `Update` для Bubble Tea. Применяет одно сообщение и возвращает обновлённую модель и команду, если она есть. |

Метод имеет получатель-указатель, но возвращает модель как интерфейс `tea.Model`. Его поведение зависит от `Model`, вспомогательных функций вкладок, типов сообщений и команд, определённых в других местах пакета `browser`.

## Обработка сообщений

### Выход и размер окна

- `tea.QuitMsg` отменяет незавершённые загрузки, закрывает контекст JavaScript и возвращает `tea.Quit`.
- `tea.WindowSizeMsg` обновляет размеры модели, задаёт ширину поля адреса равной `width - 4`, а размеры области просмотра — `width` на `height - 4`.
- При просмотре страницы изменение размера обновляет содержимое области просмотра из ANSI-строк активной вкладки. Если изменилась ширина, также планируется команда отрисовки активной вкладки, если она доступна.

### Ввод с клавиатуры

`ctrl+c` сохраняет сеанс, отменяет загрузки, закрывает контекст JavaScript и завершает работу в любом режиме. Если открыто несколько вкладок, `tab` и `shift+tab` сохраняют текущую вкладку, циклически переключают вкладки, восстанавливают состояние новой активной вкладки и возвращают управление без команды.

#### Режим адреса

- `enter` ничего не делает, если адрес пуст. Иначе добавляет `https://`, если значение ещё не начинается с `http://` или `https://`, сохраняет состояние активной вкладки и запускает новую отменяемую загрузку.
- При запуске загрузки отменяется предыдущая загрузка этой вкладки, создаётся контекст с отменой, увеличивается идентификатор запроса, устанавливаются состояние загрузки и URL, масштаб сбрасывается до `1`, а горизонтальное смещение — до `0`; также обновляется поле адреса. Возвращаемая команда загружает страницу с текущей шириной, идентификатором вкладки и идентификатором запроса.
- `q` сохраняет сеанс, отменяет загрузки, закрывает контекст JavaScript и завершает работу.
- Обработка остальных клавиш передаётся текстовому полю адреса.

#### Режим просмотра

| Клавиша | Поведение |
| --- | --- |
| `ctrl+l` | Сохраняет состояние активной вкладки, переключается в режим адреса, переводит фокус на поле адреса и запускает команду мигания курсора. |
| `r` | Возвращает команду отрисовки активной страницы. |
| `+` или `=` | Увеличивает масштаб на `0.5` (не выше `3`), затем запрашивает отрисовку. |
| `-` или `_` | Уменьшает масштаб на `0.5` (не ниже `0.5`), затем запрашивает отрисовку. |
| `left` | Сдвигает содержимое влево на `10`, но не ниже нуля. |
| `right` | Сдвигает содержимое вправо на `10`. |
| `t` | Сохраняет состояние текущей вкладки, создаёт и активирует пустую вкладку в режиме адреса, очищает и фокусирует поле адреса и область просмотра, запускает мигание курсора ввода. |
| `w` | Если вкладок больше одной, отменяет загрузку активной вкладки, закрывает её контекст JavaScript, удаляет вкладку, выбирает допустимый индекс оставшейся вкладки и восстанавливает её состояние. Последнюю вкладку этой клавишей закрыть нельзя. |
| `tab` / `shift+tab` | Переключает вкладки по кругу и восстанавливает состояние. |
| `q` | Сохраняет сеанс, отменяет загрузки, закрывает контекст JavaScript и завершает работу. |
| Остальные клавиши | Передаются области просмотра; возвращается её команда. |

Изменения масштаба и горизонтальная прокрутка обновляют активную вкладку, если она существует. Команда отрисовки может быть nil, если активную вкладку невозможно отрисовать.

#### Режим ошибки

`ctrl+l` возвращает в режим адреса, фокусирует поле адреса и запускает мигание курсора. `q` сохраняет сеанс, отменяет загрузки, закрывает контекст JavaScript и завершает работу. Остальные клавиши не вызывают действий, специфичных для режима.

### События таймера

При получении `tickMsg` в режиме загрузки планируется следующий тик, а обработка таймера пропускается. В противном случае, если у активной вкладки есть таймеры JavaScript для обработки, модель планирует отрисовку, а затем следующий тик. Команды, накопленные в этом обработчике, объединяются с помощью `tea.Batch`.

### Асинхронные результаты страниц

Результаты сопоставляются с вкладкой по `TabID` и `RequestID`; несовпадающие или устаревшие результаты игнорируются.

- `PageRenderedMsg` заменяет ANSI- и ASCII-строки соответствующей вкладки. Если эта вкладка активна, её строки также объединяются переводами строк и отображаются в области просмотра.
- `PageLoadedMsg` отменяет и очищает функцию отмены загрузки вкладки, сохраняет итоговый URL, ANSI- и ASCII-строки, а также внешние CSS-стили, сбрасывает вертикальное смещение и переводит вкладку в состояние просмотра. Для активной вкладки также обновляются режим модели и содержимое загруженной страницы, задаётся содержимое области просмотра, прокрутка возвращается в начало и планируется тик.
- `PageErrorMsg` отменяет и очищает загрузку соответствующей вкладки, сохраняет ошибку и переводит вкладку в состояние ошибки. Режим модели меняется только в том случае, если эта вкладка активна.

## Состояние и детали реализации

- `ensureTabIDs()` вызывается в начале каждого обновления, до обработки сообщения.
- При переключении вкладок состояние каждой вкладки сохраняется и восстанавливается, чтобы отображаемая модель соответствовала активной вкладке.
- Для загрузок используется `context.WithCancel`; при замене или закрытии вкладки её текущая загрузка отменяется. При выходе отменяются незавершённые загрузки и закрываются ресурсы контекста JavaScript.
- Идентификаторы запросов не позволяют поздним результатам предыдущей навигации перезаписать более новое состояние вкладки.
- Большинство обработчиков сообщений немедленно возвращают управление, если для них предусмотрена отдельная команда или дальнейшая обработка не требуется. Оставшиеся накопленные команды возвращаются как `tea.Batch(cmds...)`.
- Нормализация адреса выполняется простой проверкой префикса: уже заданными схемами считаются только строчные `http://` и `https://`.
