# Конвейер загрузки страниц браузера

`internal/browser/browser_page.go` реализует загрузку и отображение страниц пакета браузера. Он получает документ, разбирает его и выполняет скрипты, загружает внешние таблицы стилей и изображения, вычисляет стили и макет, а затем формирует вывод для терминала. Команды Bubble Tea выполняют работу асинхронно и возвращают типизированные сообщения, обрабатываемые приложением.

## Загрузка страницы

Внутренние точки входа `loadPage`, `loadPageContext` и `loadPageForTab` создают `tea.Cmd`. `loadTabPage` добавляет идентификаторы вкладки и запроса в итоговое сообщение об успехе или ошибке. Вариант с контекстом проверяет отмену после получения и разбора данных, а также на последующих этапах конвейера.

Последовательность загрузки:

1. Получить HTML через `fetcher.FetchContext` и разобрать его в DOM.
2. Под мьютексом жизненного цикла JavaScript приостановить ранее активную среду выполнения, удалить старую среду для этой вкладки, создать контекст, инициализировать мосты DOM и систему событий, а затем выполнить скрипт API DOM.
3. Установить `document._url`, предоставить мост JavaScript `window.getComputedStyle`, выполнить скрипты документа и отправить событие `DOMContentLoaded`. Ошибки выполнения скриптов обрабатывает исполнитель скриптов; ошибки инициализации моста или API DOM преобразуются в ошибки `PageErrorMsg`.
4. Сохранить полученную среду выполнения для вкладки и освободить блокировку жизненного цикла.
5. Загрузить внешние CSS и изображения, вычислить стили с учётом ширины области просмотра, построить блоки макета, обновить данные вычисленных стилей и макета в контексте JavaScript, если этот контекст всё ещё актуален, и сформировать обычный вывод и вывод ANSI.
6. Вернуть `PageLoadedMsg` с отрисованными строками, URL и внешним CSS.

Если задан `ABYSS_DUMP_ANSI`, строки ANSI также записываются по указанному пути; ошибки записи игнорируются, а диагностическое сообщение выводится в стандартный поток ошибок после попытки записи.

`reRenderCmd` повторно использует среду выполнения JavaScript вкладки и имеющиеся данные DOM/CSS. Он помечает среду как чистую, заново вычисляет стили и макет для ширины с учётом масштаба (не менее 10 ячеек), обновляет сведения о макете в среде выполнения и возвращает `PageRenderedMsg`. При отсутствии, устаревании или непригодности контекста сообщение не возвращается (`nil`).

## Жизненный цикл среды выполнения JavaScript

Контексты JavaScript являются состоянием уровня процесса пакета, управляемым через `jsLifecycleMu`. В нижележащем пакете JS одновременно может быть активна не более чем одна среда выполнения. Неактивные среды сохраняются в `jsRuntimes` по идентификатору вкладки и активируются при возобновлении работы с этой вкладкой. При переключении вкладок сначала сохраняется активная среда. При закрытии вкладки закрываются и её активный контекст (если он есть), и сохранённая среда. `processJSTimers` активирует указанную вкладку, обрабатывает таймеры только при совпадении текущего URL с ожидаемым, сообщает, стала ли среда выполнения изменённой, и снова сохраняет её.

## Внешние ресурсы

### Таблицы стилей

`fetchExternalCSS` — обёртка для фонового контекста вокруг `fetchExternalCSSContext`. Загрузчик разрешает ссылки на таблицы стилей относительно URL страницы, пропускает пустые или некорректные ссылки и строки media длиннее 256 байт, а также устраняет дубликаты одинаковых пар URL и media. Он загружает не более 64 таблиц стилей с помощью максимум четырёх рабочих потоков, сохраняет порядок документа в результате и ограничивает суммарный объём тел CSS размером 4 МиБ. Ошибки загрузки и тела, превышающие бюджет, пропускаются. Непустой атрибут media оборачивает таблицу стилей в блок `@media`.

### Изображения

`fetchImages` вызывает `fetchImagesContext` с фоновым контекстом. Источники изображений обрезаются и разрешаются относительно URL страницы; разрешённые URL записываются обратно в DOM, чтобы ключ поиска отрисовщика совпадал с ключом кэша. URL данных декодируются локально, а внешние изображения загружаются максимум двумя рабочими потоками. Рассматривается не более 64 различных внешних источников, а общий допустимый объём тел ответов ограничен 64 МиБ. Изображения декодируются через `asciirender.Decode`; неудачные загрузки и ошибки декодирования не кэшируются.

Кэш изображений индексируется по URL источника и защищён RW-мьютексом. Его консервативный бюджет декодированных изображений составляет 64 МиБ: размер оценивается как восемь байт на пиксель, а некорректные или чрезмерно большие границы отклоняются. При вставке старейшие записи удаляются, пока не освободится место. URL данных должны быть закодированы в base64 и ограничены 16 МиБ. `render.ImageProvider` инициализируется функцией `cachedImage`, которая проверяет кэш и при необходимости лениво декодирует допустимые URL данных.

## Публичный API

| Имя | Поведение |
| --- | --- |
| `ResolveURL(base, rel string) string` | Разрешает относительную ссылку относительно базового URL. Если базовый URL разобрать не удалось, возвращает `rel`; если не удалось разобрать ссылку, возвращает пустую строку. В противном случае возвращает `baseURL.ResolveReference(relURL).String()`. |
| `ResolveURLForTest(base, rel string) string` | Экспортированный вспомогательный метод для тестов, делегирующий вызов `ResolveURL`. |
| `FetchExternalCSSForTest(doc *dom.Node, baseURL string) []string` | Экспортированный вспомогательный метод для тестов, загружающий таблицы стилей с фоновым контекстом. |

В файле также используются `PageLoadedMsg`, `PageErrorMsg`, `PageRenderedMsg` и `tea.Cmd` из зависимостей пакета/приложения; их определения находятся за пределами этого файла. Конструкторы команд загрузки и отрисовки не экспортируются.

## Ограничения и параллелизм

| Ресурс | Ограничение |
| --- | ---: |
| Длина URL данных base64 | 16 МиБ |
| Кэш декодированных изображений | 64 МиБ (оценка 8 байт на пиксель) |
| Внешние источники изображений на страницу | 64 |
| Суммарный объём тел ответов внешних изображений | 64 МиБ |
| Внешние таблицы стилей на страницу | 64 |
| Суммарный объём тел внешнего CSS | 4 МиБ |
| Атрибут media таблицы стилей | 256 байт |
| Рабочие потоки загрузки таблиц стилей | 4 |
| Рабочие потоки загрузки изображений | 2 |

Результаты рабочих потоков собираются и применяются в исходном порядке. Отмена контекста передаётся запросам ресурсов; загрузка страницы проверяет отмену и закрывает среду выполнения вкладки в предусмотренных точках очистки. Общие кэши и состояние среды выполнения JavaScript защищены отдельными мьютексами.
