# Сопоставление блоков макета браузера

В этом файле описан `internal/browser/browser_layout.go`, который преобразует дерево макета в таблицу соответствия DOM-узлов и абсолютных прямоугольников содержимого.

## Поведение

Сопоставитель начинает с корневого блока макета и нулевого смещения `(x, y)`, затем рекурсивно обходит его потомков. Для каждого блока с ненулевым `Node` он:

1. Прибавляет `Content.X` и `Content.Y` блока к накопленному смещению родителя.
2. Сохраняет для этого узла `js.Rect`, используя полученную абсолютную позицию, а также ширину и высоту содержимого.
3. Обходит дочерние блоки, передавая им вычисленную абсолютную позицию в качестве смещения.

Нулевой блок или блок с нулевым `Node` пропускается вместе со всеми его потомками. Возвращаемая таблица инициализируется, даже если корневой блок равен nil. Поскольку в качестве ключей таблицы используются указатели на узлы, повторное появление одного и того же указателя на узел перезаписывает предшествующий прямоугольник; порядок обхода соответствует порядку `Children` каждого блока.

Позиции являются абсолютными в системе координат, представленной деревом макета. Расчёт использует геометрию `Content`, а не внешний прямоугольник рамки или отступов.

## API

### `BuildLayoutBoxMapForTest`

```go
func BuildLayoutBoxMapForTest(root *layout.LayoutBox) map[*dom.Node]js.Rect
```

Экспортированная обёртка для тестов над закрытой для пакета функцией `buildLayoutBoxMap`. Возвращает соответствие узлов и прямоугольников для переданного дерева макета. В API используются указатели на `dom.Node` в качестве ключей таблицы и значения типа `js.Rect`.

## Детали реализации

- `buildLayoutBoxMap` выделяет таблицу результатов и передаёт обход функции `buildLayoutBoxRecursive` со смещениями `(0, 0)`.
- `buildLayoutBoxRecursive` рекурсивно накапливает смещения; координаты содержимого каждого дочернего блока считаются относительно начала содержимого родителя.
- Проверка на nil выполняется до чтения полей блока, предотвращая разыменование nil-блоков и обход блока с nil-узлом.
- Рекурсивная вспомогательная функция не экспортируется. Единственный экспортируемый символ в этом файле явно обозначен как тестовый помощник.

## Зависимости

В реализации используются:

- `internal/layout` для `LayoutBox` и его полей `Content` и `Children`.
- `internal/dom` для указателей на узлы.
- `internal/js` для результирующего типа `Rect`.
