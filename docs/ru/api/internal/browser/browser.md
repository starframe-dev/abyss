# `internal/browser`

Пакет `browser` реализует интерфейс браузера в терминале с помощью Bubble Tea. Он моделирует ввод адреса, загрузку, просмотр страниц, ошибки, вкладки, состояние области просмотра и асинхронные результаты загрузки страниц.

## Режимы

`Mode` — целочисленное перечисление, описывающее состояние вкладки или всего интерфейса:

| Константа | Значение |
| --- | --- |
| `ModeAddress` | Ввод адреса; также начальное состояние новой вкладки. |
| `ModeLoading` | Выполняется запрос страницы. |
| `ModeView` | Просмотр загруженной страницы. |
| `ModeError` | Активна ошибка загрузки или отображения страницы. |

## Публичные типы

### `Tab`

Хранит состояние одной вкладки браузера.

| Поле | Назначение |
| --- | --- |
| `ID`, `RequestID` (`uint64`) | Идентификатор вкладки и поколение текущего запроса; используются для сопоставления асинхронных результатов с запросом, который их создал. |
| `URL` (`string`) | Адрес, связанный с вкладкой. |
| `Mode` (`Mode`) | Состояние интерфейса вкладки. |
| `ANSILines`, `ASCIILines` (`[]string`) | Строки отображённой страницы в формате ANSI и обычном ASCII. |
| `ExternalCSS` (`[]string`) | Ссылки на внешние таблицы стилей, связанные со страницей. |
| `Err` (`error`) | Ошибка, связанная с вкладкой. |
| `ZoomFactor` (`float64`), `OffsetX`, `OffsetY` (`int`) | Масштаб и положение области просмотра для вкладки. |

Функция отмены загрузки является приватной и используется внутри пакета для отмены незавершённых операций.

### `Model`

Основная модель Bubble Tea. Она предоставляет текущий режим `Mode`, поле ввода адреса (`Address`), область просмотра страницы `Viewport`, вкладки `Tabs`, индекс активной вкладки `ActiveTab`, а также ширину и высоту терминала (`Width` и `Height`). Другие поля хранят внутреннюю последовательность идентификаторов вкладок и отображённое содержимое страницы.

`Model` предоставляет `Init() tea.Cmd` в качестве хука инициализации Bubble Tea. Он объединяет команду мигания текстового поля и команду периодического тика.

### Асинхронные сообщения

- `PageLoadedMsg` содержит `TabID`, `RequestID`, отображённые строки `Lines` и строки `ANSI`, итоговый `URL` и `ExternalCSS` после завершения загрузки.
- `PageRenderedMsg` содержит обновлённые `Lines` и `ANSI` для вкладки и запроса, не заменяя метаданные навигации.
- `PageErrorMsg` содержит идентификаторы вкладки и запроса, а также ошибку загрузки.

Результаты сопоставляются одновременно по идентификатору вкладки и идентификатору запроса; устаревшие результаты не сопоставляются с текущей вкладкой. Внутренний поиск отклоняет нулевой идентификатор вкладки.

## Публичные функции и методы

### `New() Model`

Создаёт модель с областью просмотра размером 80 на 24, сфокусированным полем ввода адреса с подсказкой `Enter URL...` и шириной 50, а также одной вкладкой в режиме ввода адреса. Если в сохранённом сеансе есть URL, вместо этого они создают вкладки в режиме ввода адреса, а последняя восстановленная вкладка становится активной. Вкладкам без идентификатора назначаются ID.

### `TickCmd() tea.Cmd`

Возвращает команду Bubble Tea, отправляющую внутреннее сообщение тика каждые 500 миллисекунд.

### `(*Model).GetActiveTab() *Tab`

Возвращает указатель на активную вкладку или `nil`, если `ActiveTab` выходит за границы среза вкладок.

### `(*Model).SaveActiveTab()`

Копирует текущий адрес, режим, строки ANSI и ASCII, масштаб, горизонтальное смещение и вертикальное смещение области просмотра в активную вкладку. Ничего не делает, если активная вкладка отсутствует или недействительна.

### `(*Model).RestoreActiveTab()`

Восстанавливает режим, адрес и содержимое области просмотра ASCII активной вкладки. Ограничивает вертикальное смещение доступным диапазоном содержимого. Ничего не делает, если активная вкладка отсутствует или недействительна.

## Сохранение сеанса и примечания по реализации

Данные сеанса хранятся приватно в `$HOME/.abyss/session.json` в виде JSON-объекта с массивом `urls`. При сохранении пустые URL пропускаются; сохранение ничего не делает, если вкладок нет или все URL пусты. Для создания каталогов и записи файлов используются права `0755` и `0644`; ошибки сохранения и JSON намеренно игнорируются. При невозможности прочитать или декодировать файл загрузка возвращает пустой список URL.

Идентификаторы вкладок, если они отсутствуют, назначаются в модели монотонно; существующие идентификаторы при необходимости увеличивают счётчик следующего ID. Каждая вкладка может хранить функцию отмены текущей загрузки; внутренняя отмена вызывает и очищает эти функции. Получение активной вкладки проверяет границы. При восстановлении области просмотра строки ASCII объединяются символами новой строки, а сохранённое вертикальное смещение ограничивается текущими границами содержимого.
