# Утилиты обрезки ANSI-текста

В этом файле описаны неэкспортируемые вспомогательные функции разбора и обрезки ANSI в пакете `browser` (`internal/browser/ansi_clip.go`). Это детали реализации, а не публичный API Go; вызывающий код за пределами пакета не может к ним обращаться.

## Поведение

Вспомогательные функции преобразуют ориентированный на терминал текст в безопасный для отображения видимый текст и позволяют измерять и обрезать его по столбцам терминальных ячеек. Сохраняются только выбранные 24-битные стили SGR переднего плана и фона. Остальные escape-последовательности и управляющие символы отбрасываются.

### `splitANSI`

```go
func splitANSI(s string) []ansiSegment
```

Разбивает входные данные на текстовые сегменты с активными последовательностями стилей. Функция:

- Удаляет исходные управляющие последовательности C1 вместе с их данными до декодирования UTF-8, а затем удаляет некорректные последовательности UTF-8.
- Распознаёт последовательности CSI с префиксом ESC и сохраняет только корректные последовательности SGR для 24-битных цветов переднего плана (`38;2;r;g;b`) и фона (`48;2;r;g;b`). Каждый компонент цвета должен быть целым числом от 0 до 255. Можно объединять несколько спецификаций цвета.
- Сбрасывает накопленный стиль при SGR `0` или пустом списке параметров SGR. Неподдерживаемые или некорректные последовательности SGR отбрасываются, не меняя текущий стиль.
- Отбрасывает OSC, DCS, SOS, PM, APC, прочие escape-последовательности, последовательности C1, управляющие символы Unicode и форматирующие символы, кроме разделителя нулевой ширины (`U+200C`) и соединителя нулевой ширины (`U+200D`).
- Создаёт сегмент, если в нём есть текст; каждый сегмент получает копию текущего списка стилей.

### `ansiSegment`

```go
type ansiSegment struct {
    style []string
    text  string
}
```

Внутренний сегмент, состоящий из накопленных совместимых с рендерером строк SGR и соответствующего обычного текста. Он не экспортируется.

### `visibleWidth`

```go
func visibleWidth(line string) int
```

Возвращает сумму ширин текста в ячейках по `go-runewidth` для разобранных сегментов. ANSI-стили и отбрасываемые управляющие символы не учитываются.

### `clipANSI`

```go
func clipANSI(line string, start, width int) string
```

Возвращает часть строки, занимающую указанный интервал столбцов ячеек `[start, start+width)`. При неположительной ширине возвращает пустую строку; отрицательное начальное значение ограничивается нулём. Конец интервала вычисляется как ограниченное начальное значение плюс ширина.

Обрезка выполняется по графемным кластерам (`uniseg`), поэтому кластеры из нескольких рун не разделяются. Кластеры, целиком попадающие в интервал, сохраняются. Если интервал пересекает только часть ширины кластера в ячейках, пересечение представляется пробелами, поскольку графему нельзя вывести частично. Кластеры нулевой ширины включаются только при присоединении к ранее включённому целому кластеру. Для непустого выбранного текста выводятся последовательности стилей, за которыми следует `\x1b[0m`, чтобы стиль не влиял на последующий вывод. Для полностью пустого фрагмента стили не выводятся.

## Примечания по реализации

- `stripRawC1Controls` сканирует исходную строку байтов, чтобы удалить некорректные байты UTF-8, представляющие управляющие символы C1, вместе с данными этих последовательностей до преобразования в руны. Функция обрабатывает CSI, OSC (включая завершение BEL) и строковые управляющие последовательности, завершаемые ST (`U+009C` или ESC с обратной косой чертой).
- `validRendererSGR` принимает только пустые параметры, параметры сброса или группы, разделённые точками с запятой и состоящие ровно из `38;2;r;g;b` и/или `48;2;r;g;b`; все остальные формы SGR отклоняются.
- `clipANSI` увеличивает счётчик столбцов на ширину графемы в ячейках, а не на длину в байтах, число рун или ширину escape-последовательностей.
