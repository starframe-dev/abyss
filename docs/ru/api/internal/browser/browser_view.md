# Отрисовка представления браузера

В этом файле описан `internal/browser/browser_view.go`, который отображает модель браузера в виде терминального интерфейса. Для оформления используется Lipgloss, для вычисления ширины в терминальных ячейках — `go-runewidth`, а для усечения с учётом графем — `uniseg`.

## Публичный API

### `Model.View() string`

`View` реализует метод представления `tea.Model` из Bubble Tea для `Model`. Метод возвращает полное представление интерфейса в терминале в виде строки; он не записывает данные непосредственно в терминал и не изменяет модель.

Вывод формируется в следующем порядке:

1. **Панель вкладок.** URL каждой вкладки очищается для отображения в терминале. Если после очистки URL пуст, отображается `New Tab`; в противном случае удаляется префикс HTTP или HTTPS. Подписи шириной более 20 терминальных ячеек усекаются до 19 ячеек и завершаются символом `…`. Для активной вкладки используются отличающиеся цвета фона и текста, а также полужирное начертание.
2. **Заголовок.** В режиме `ModeAddress` после подписи `Abyss` отображается поле ввода адреса. В остальных режимах показывается текущий адрес или `Abyss`, если адрес пуст. Если масштаб отличается от 100%, в заголовок добавляется масштаб в процентах, округлённый до целого числа.
3. **Содержимое.** Содержимое выбирается в зависимости от режима:
   - `ModeLoading`: сообщение `Loading...` по центру.
   - `ModeError`: очищенное сообщение об ошибке и подсказка по клавиатуре по центру (`Ctrl+L` для редактирования URL или `Q` для выхода).
   - `ModeAddress`: очищенное значение поля ввода адреса по центру.
   - `ModeView`: видимые строки документа с ANSI-разметкой выбираются по смещению и высоте области просмотра, затем обрезаются по горизонтали с учётом горизонтальной прокрутки.

Панель вкладок и заголовок завершаются символом новой строки. Содержимое конкретного режима добавляет собственные начальные символы новой строки, как предусмотрено реализацией; режим просмотра напрямую выводит объединённые видимые строки.

## Подробности отрисовки

### Безопасность текста в терминале

`safeTerminalText` заменяет символы Unicode, не предназначенные для печати, на `�`, кроме символов нулевой ширины — non-joiner (`U+200C`) и joiner (`U+200D`), которые сохраняются. Эта обработка применяется к подписям вкладок, тексту заголовка, содержимому режима ввода адреса и тексту ошибки. Значение поля ввода адреса очищается в локальной копии модели ввода перед отрисовкой.

### Ширина, усечение и выравнивание по центру

Ширина определяется количеством ячеек, занимаемых текстом в терминале, а не числом байтов. При усечении текста вкладок выполняется перебор кластеров графем, поэтому последовательности комбинируемых символов не разделяются. Функция `center` добавляет слева половину доступного горизонтального пространства, если текст уже запрошенной ширины; справа отступ не добавляется. Если ширина текста не меньше запрошенной, он возвращается без изменений.

### Область просмотра и горизонтальная обрезка

В режиме `ModeView` неположительная высота области просмотра по умолчанию равна 24 строкам, а неположительная ширина модели — 80 столбцам. Вертикальное смещение ограничивается так, чтобы выбранный фрагмент не начинался за концом доступных строк ANSI; затем его длина ограничивается количеством строк. Горизонтальная обрезка применяется к каждой строке с использованием горизонтального смещения модели и `clipANSI`, что сохраняет обработку ANSI-разметки при обрезке. Перед обрезкой строки копируются в отдельный выходной срез, поскольку видимые строки могут ссылаться на содержимое вкладки; это не позволяет отрисовке разрушительно изменять исходные строки и обеспечивает возможность отмены горизонтальной прокрутки.

## Внутренние вспомогательные функции

| Функция | Поведение |
|---|---|
| `safeTerminalText(text string) string` | Заменяет непечатаемые символы, как описано выше. |
| `truncateTerminalText(text string, maxWidth int) string` | Возвращает безопасный для графем префикс, суммарная отображаемая ширина которого не превышает заданное значение. Графемы нулевой ширины сохраняются; отрицательная ширина, если она встречается, не уменьшает накопленную ширину. |
| `center(text string, width int) string` | Добавляет слева отступ для приблизительного центрирования текста по ширине терминальных ячеек. |

Эти функции не экспортируются и являются деталями реализации пакета браузера.
