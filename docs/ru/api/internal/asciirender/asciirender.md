# `internal/asciirender`

Пакет `asciirender` декодирует растровые изображения и преобразует их в ограниченную сетку ячеек терминала. В каждой ячейке используется символ, выбранный из шкалы яркости, и усреднённый цвет переднего плана; `Flatten` позволяет получить обычный текстовый предпросмотр без стилей ANSI.

## Публичный API

### Константы

| Константа | Значение | Назначение |
| --- | ---: | --- |
| `MaxImageWidth` | `8192` | Максимальная допустимая ширина исходного изображения. |
| `MaxImageHeight` | `8192` | Максимальная допустимая высота исходного изображения. |
| `MaxImagePixels` | `8 * 1024 * 1024` | Максимальное число пикселей исходного изображения. |
| `MaxOutputColumns` | `4096` | Максимальное число столбцов результата. |
| `MaxOutputCells` | `1 << 18` | Максимальное общее число ячеек результата. |

### `Cell`

`Cell` представляет одну символьную ячейку терминала:

- `Char rune` — выбранный символ плотности.
- `FG css.Color` — усреднённый цвет исходного изображения для ячейки.
- `BG css.Color` — настроенный цвет фона или цвет по умолчанию.
- `IsHalfRow bool` отмечает верхнюю половину пикселя, соединённую с нижней половиной в следующей строке. Текущий квантователь это поле не устанавливает.

Тип цвета импортируется из `internal/css`.

### `Options`

`Options` задаёт параметры [`Quantize`](#quantize):

| Поле | Поведение |
| --- | --- |
| `Columns int` | Число выходных столбцов. Значения не больше нуля выбирают значение по умолчанию — 60; значения выше максимума ограничиваются им. |
| `Rows int` | Число выходных строк. Нулевое или отрицательное значение вычисляет число строк по соотношению сторон изображения; положительные значения ограничиваются лимитом общего числа ячеек. |
| `BGColor css.Color` | Цвет подложки. Если цвет не задан, используется RGB `(226, 232, 240)`. |

### `Palette`

`Palette` — экспортируемый срез рун для отображения плотности, упорядоченный от светлых/редких символов к тёмным/плотным:

```text
 .,:;i1tfLCG08@#
```

`pickRune` сопоставляет низкую яркость с более поздними, плотными символами, а высокую — с более ранними, светлыми. Поскольку `Palette` — изменяемый экспортируемый срез, вызывающий код может изменить это соответствие; во время рендеринга его не следует изменять параллельно.

### `Decode`

```go
func Decode(data []byte) (image.Image, error)
```

Декодирует PNG, JPEG и GIF (зарегистрированные этим пакетом), а также форматы, зарегистрированные стандартным пакетом Go `image`. Сначала считывает конфигурацию изображения и отклоняет неположительные размеры, размеры, превышающие ограничения ширины или высоты, а также число пикселей больше `MaxImagePixels`; только после этого декодирует пиксели. Ошибки декодирования или чтения конфигурации возвращаются вызывающему коду. При превышении ограничений размеров возвращается ошибка с описанием отклонённых размеров.

### `Quantize`

```go
func Quantize(img image.Image, opts Options) [][]Cell
```

Преобразует изображение в строки ячеек терминала. Для изображения `nil` или изображения с некорректными либо превышающими ограничения размерами границ возвращается `nil`. В противном случае результат содержит выбранное число строк и столбцов, причём каждая ячейка охватывает соответствующий пропорциональный прямоугольник пикселей исходного изображения. Число строк по умолчанию приблизительно соответствует пропорции терминальных ячеек: две вертикальные единицы исходного изображения на столбец; оно вычисляется как `Columns * sourceHeight / sourceWidth / 2` и ограничивается снизу единицей. Размер результата ограничен `MaxOutputColumns` и `MaxOutputCells`.

RGB-цвет переднего плана каждой ячейки равен среднему значению её выбранных пикселей. Пиксели с альфа-каналом перед усреднением компонуются поверх белого. Для вычисления яркости используются коэффициенты ITU-R BT.601 (`0.299R + 0.587G + 0.114B`), а `Char` выбирается из `Palette`. Фон берётся из `Options.BGColor`, если он задан, иначе используется RGB `(226, 232, 240)`.

### `Flatten`

```go
func Flatten(grid [][]Cell) string
```

Записывает символ каждой ячейки в порядке строк и добавляет перевод строки после каждой строки. Нулевое значение `Char` представляется пробелом. Результат не содержит кодов цвета ANSI; цвета остаются доступными в ячейках, чтобы вызывающий код мог отобразить их отдельно.

## Примечания по реализации

- Проверка размеров использует деление (`width <= MaxImagePixels/height`), чтобы избежать перемножения размеров и риска целочисленного переполнения.
- `Decode` проверяет конфигурацию до полного декодирования, чтобы применять ограничения до выделения памяти под пиксели.
- При квантовании учитываются границы изображения, в том числе ненулевое начало координат.
- Исходные пиксели распределяются по пропорциональным областям ячеек с помощью целочисленного деления. Если область не содержит пикселей, её выборка считается чёрной с нулевой яркостью.
- Внутренние вспомогательные функции (`imageDimensionsAllowed`, `sampleCell`, `pickRune`, `luminance` и `rgba`) реализуют проверку, выборку и преобразование цветов и не входят в экспортируемый API.
