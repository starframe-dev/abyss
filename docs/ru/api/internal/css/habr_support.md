# Поддержка Habr в CSS

Этот файл пакета добавляет разбор таблиц стилей для обычных правил CSS и вложенных блоков `@media` / `@supports`, а также подстановку ссылок на пользовательские свойства CSS. Он является частью внутреннего пакета `css`.

## Публичный API

### `ParseStylesheet(source string) []Rule`

Разбирает текст таблицы стилей и возвращает собранные значения `Rule`. Каждое обычное правило как минимум с одним разобранным объявлением становится `Rule`, содержащим селекторы, объявления и охватывающие его условия media/supports.

- Селекторы разделяются запятыми, а пробелы по краям удаляются.
- Вложенные условия media объединяются через ` and `; вложенные условия supports объединяются таким же образом.
- Регистр `@media` и `@supports` не учитывается. Текст условия сохраняется в исходном виде после удаления пробелов по краям.
- Прочие at-правила пропускаются вместе с их содержимым.
- При некорректных или незавершённых блоках разбор останавливается в месте, где не удаётся найти закрывающую фигурную скобку.

Разбор объявлений передаётся функции `ParseInline`, поэтому его поведение определяется этой функцией. Правила без разобранных объявлений не включаются в результат.

### `ResolveCustomProperties(value string, properties map[string]string) (string, bool)`

Подставляет ссылки `var(...)`, используя предоставленную карту соответствий имён свойств и значений. Возвращает итоговую строку и флаг успешности.

- Известная переменная заменяется сопоставленным ей значением.
- Если ссылка содержит запятую, текст после первой запятой используется как запасное значение, когда переменная отсутствует; пробелы по краям запасного значения удаляются.
- Если переменная отсутствует и запасного значения нет или у `var(` нет закрывающей `)`, возвращается `false`, а неразрешённая ссылка остаётся в возвращённом значении.
- Подстановка выполняется итеративно, поэтому заменяющие значения могут содержать другие ссылки; максимум — 32 итерации. Результат считается успешным, только если после этого лимита `var(` больше не осталось.

Реализация распознаёт первую закрывающую круглую скобку после `var(` и не разбирает вложенный синтаксис функций или комментарии CSS. Запасное значение, содержащее другой `var(...)`, может быть разрешено на следующей итерации.

## Детали реализации

Неэкспортируемая функция `parseStylesheetBlock` проходит по байтам исходного текста, пропуская пробелы и точки с запятой между конструкциями. Она находит заголовок каждого блока до `{`, находит соответствующую закрывающую фигурную скобку, а затем либо рекурсивно обрабатывает поддерживаемые условные at-правила, либо разбирает блок объявлений. Текущие строки media и supports передаются рекурсивно и копируются в созданные правила.

`matchingBrace` подсчитывает вложенные фигурные скобки и игнорирует их символы внутри строк в одинарных или двойных кавычках. Кавычка считается экранированной, если непосредственно перед ней стоит обратная косая черта. Функция возвращает индекс скобки, закрывающей заданную открывающую скобку, или `-1`, если совпадение не найдено.

## Типы и зависимости

Экспортируемые функции используют тип `Rule` пакета, определённый в другом месте пакета `css`. Важные для этого файла поля: `Selectors`, `Declarations`, `MediaQuery` и `SupportsQuery`. Разбор встроенных объявлений также предоставляется в другом месте пакета функцией `ParseInline`.
