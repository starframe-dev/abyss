# Вычисленные типы CSS

`internal/css/computed_types.go` определяет типизированные значения для представления CSS-свойств после вычисления. Файл содержит перечисления поддерживаемых значений свойств, компактное представление `Length` с функциями для создания, разрешения и сериализации, RGB-цвета, структуры границ и блочной модели, а также `ComputedStyle` с инициализатором значений по умолчанию.

## Типы значений свойств

Следующие целочисленные типы кодируют поддерживаемые значения. Их константы используют `iota`, поэтому числовые значения являются деталями реализации; используйте именованные константы, а не полагайтесь на их порядковые номера.

| Тип | Константы |
| --- | --- |
| `DisplayType` | `DisplayBlock`, `DisplayInline`, `DisplayInlineBlock`, `DisplayFlex`, `DisplayGrid`, `DisplayNone` |
| `PositionType` | `PositionStatic`, `PositionRelative`, `PositionAbsolute` |
| `TextAlignType` | `TextAlignLeft`, `TextAlignCenter`, `TextAlignRight` |
| `OverflowType` | `OverflowVisible`, `OverflowHidden` |
| `FlexDirection` | `FlexDirectionRow`, `FlexDirectionColumn` |
| `JustifyContent` | `JustifyFlexStart`, `JustifyCenter`, `JustifyFlexEnd`, `JustifySpaceBetween`, `JustifySpaceAround` |
| `AlignItems` | `AlignFlexStart`, `AlignCenter`, `AlignFlexEnd`, `AlignStretch` |
| `BorderStyle` | `BorderNone`, `BorderSolid` |

`TextAlignType` задаёт только выравнивание собственного текста блока; наследование здесь не моделируется.

## Length

`Length` представляет значение в пикселях, процент, `auto` или дробный размер дорожки сетки:

```go
type Length struct {
    IsAuto     bool
    Px         float64
    IsPercent  bool
    Percent    float64
    IsFraction bool
    Fraction   float64
}
```

Создавайте значения с помощью `Auto()`, `Px(v)`, `Percent(v)` или `Fr(v)`. Эти функции задают соответствующий признак и значение. Поля экспортированы, поэтому вызывающий код может также создать `Length` напрямую; представление не гарантирует, что установлен только один признак. Если истинны несколько флагов, методы отдают приоритет `IsAuto`, затем `IsPercent`, затем `IsFraction`; в остальных случаях значение считается пиксельным.

- `Resolve(ref)` возвращает `0` для `auto` и дробных дорожек, вычисляет проценты как `Percent * ref / 100` и возвращает `Px` для пиксельных значений. Дробные дорожки этим методом не разрешаются, поскольку для них требуется распределение дорожек сетки.
- `String()` сериализует значение как `auto` либо как число с двумя знаками после запятой и соответствующим суффиксом (`%`, `fr` или `px`).

## Цвета, границы и блочная модель

`Color` хранит RGB-каналы (`uint8`) и флаг `IsSet`. `Transparent()` возвращает нулевой цвет без установленного значения; `RGB(r, g, b)` возвращает заданный цвет. `Color.String()` форматирует незаданные цвета как `transparent`, а заданные — как шестизначный шестнадцатеричный код в нижнем регистре (`#rrggbb`).

`Border` объединяет ширину в пикселях `Width`, стиль `BorderStyle` и цвет `Color`. `BoxModel` хранит значения `Top`, `Right`, `Bottom` и `Left` типа `Length`. `BoxModel.IsZero()` возвращает `true`, только если каждая сторона имеет пиксельную длину, равную нулю. Значения `auto`, проценты и дробные значения не считаются нулевыми, даже если их числовое поле равно нулю.

## ComputedStyle

`ComputedStyle` объединяет вычисленные свойства одного узла. Экспортируемые поля:

| Поле | Значение |
| --- | --- |
| `Display`, `Position`, `Overflow` | Режимы отображения, позиционирования и переполнения |
| `Width`, `Height`, `MinWidth`, `MaxWidth` | Ограничения размеров |
| `Top`, `Left`, `Right`, `Bottom` | Смещения позиции |
| `Margin`, `Padding` | Длины сторон блочной модели |
| `BorderTop`, `BorderRight`, `BorderBottom`, `BorderLeft` | Границы отдельных сторон |
| `BackgroundColor`, `Color` | Цвета фона и переднего плана |
| `ZIndex` | Значение порядка наложения |
| `TextAlign` | Выравнивание текста |
| `FlexDirection`, `JustifyContent`, `AlignItems` | Настройки flex-макета |
| `FlexGrow`, `FlexShrink`, `FlexWrap`, `Order` | Настройки flex-элемента |
| `GridTemplateColumns`, `GridTemplateRows` | Длины дорожек сетки |
| `Gap` | Промежуток между элементами макета |
| `BorderRadiusTopLeft`, `BorderRadiusTopRight`, `BorderRadiusBottomRight`, `BorderRadiusBottomLeft` | Радиусы скругления углов |

`Default()` создаёт новый стиль со следующими явно заданными значениями по умолчанию: блочное отображение, статическое позиционирование, видимое переполнение, ширина и высота `auto`, прозрачный фон, цвет переднего плана RGB `(30, 30, 30)`, направление flex-элементов в строку, выравнивание по главной оси в начале, растягивание по поперечной оси, `flex grow` `0`, `flex shrink` `1` и нулевой промежуток в пикселях. Остальные поля сохраняют нулевые значения Go: например, оставшиеся длины равны нулю пикселей, перечисления принимают первую константу, логические значения равны `false`, числовые значения равны нулю, цвета не заданы, а срезы сетки равны `nil`. Это базовое значение данных; данный файл не реализует разбор CSS, каскад, наследование или распределение пространства при макетировании.
