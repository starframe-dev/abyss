# `internal/renderer`

## Обзор

Пакет `renderer` устарел. Его исходный файл не содержит реализации рендерера, экспортируемых объявлений, типов, функций или состояния уровня пакета. В новом коде следует использовать `internal/render`.

## API

В этом пакете не определён публичный API. Объявление пакета сохранено только как устаревшая граница пакета; этот файл не предоставляет функциональность рендеринга.

## Детали реализации

`internal/renderer/renderer.go` состоит только из комментария и объявления пакета. В нём нет импортов, зависимостей, побочных эффектов или поведения во время выполнения.

## Миграция

Для рендеринга используйте пакет-замену `internal/render`. Сведения о доступных операциях см. в документации и описании API этого пакета.
