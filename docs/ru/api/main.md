# Точка входа командной строки (`main.go`)

Этот файл определяет точку входа пакета `main` для Abyss. Он предоставляет два режима выполнения: интерактивный интерфейс терминала (по умолчанию) и режим без интерфейса для сохранения ANSI-рендеринга в файл.

## Флаги командной строки

| Флаг | Значение по умолчанию | Описание |
| --- | --- | --- |
| `--headless-dump` | Пусто | Путь к выходному файлу. Если значение не пустое, включается режим без интерфейса и ANSI-рендеринг записывается по этому пути. |
| `--url` | Пусто | URL для загрузки в режиме без интерфейса. Обязателен, если указан `--headless-dump`. |
| `--width` | `200` | Ширина области просмотра, используемая в режиме без интерфейса. |

Флаги разбираются стандартным пакетом Go `flag`. В этом файле нет экспортируемых объявлений; поведение командной строки доступно через исполняемый файл, а не через API библиотеки Go.

## Поведение при выполнении

### Режим сохранения дампа без интерфейса

Если `--headless-dump` не пуст, программа проверяет, что `--url` также задан. Если URL отсутствует, программа выводит `--headless-dump requires --url` в стандартный поток ошибок и завершает работу с кодом `2`. В противном случае вызывается:

```go
browser.HeadlessDump(url, width, outputPath)
```

После этого точка входа завершается, не создавая и не запуская интерактивный интерфейс. Загрузка, рендеринг, обработка выходного файла и возможные ошибки операции сохранения дампа реализованы в `internal/browser`.

### Интерактивный режим

Если `--headless-dump` пуст, программа создаёт модель браузера с помощью `browser.New()` и запускает её через Bubble Tea с включённым альтернативным экраном. Если `tea.Program.Run` возвращает ошибку, программа выводит `Error: <error>` в стандартный поток ошибок и завершает работу с кодом `1`. При успешном выполнении программа завершается штатно.

## Примечания по реализации

- Режим без интерфейса выбирается только по тому, является ли строка `--headless-dump` непустой; `--url` и `--width` сами по себе его не включают.
- Флаг ширины напрямую передаётся в `browser.HeadlessDump`; этот файл не проверяет и не нормализует его значение.
- Команда не возвращает значений Go. Обрабатываемые здесь ошибки приводят к кодам завершения процесса: `2` — если не указан URL для режима без интерфейса, `1` — при ошибке интерактивного запуска Bubble Tea.
