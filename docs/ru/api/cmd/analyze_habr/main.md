# `cmd/analyze_habr`

Диагностическая программа командной строки, которая загружает главную страницу Habr, разбирает её HTML и выводит сводку ссылок на таблицы стилей, встроенных стилей, количества HTML-тегов и текста тела документа.

## Поведение

При запуске команда выполняет следующие действия:

1. Загружает `https://habr.com` с помощью `internal/fetcher.Fetch`.
2. При ошибке загрузки выводит `Fetch error: <error>` в стандартный поток ошибок и завершает работу с кодом 1. Разбор и формирование отчёта не выполняются.
3. Разбирает полученный HTML с помощью `internal/dom.Parse`.
4. Выводит внешние таблицы стилей, выбранные по селектору `link[rel=stylesheet]`. Значение каждого `href` отображается с усечением до 100 байт; если оно длиннее, в конце добавляется `...`. Если `href` отсутствует, выводится пустое значение.
5. Выводит все элементы `<style>`. Их текст усекается до 500 байт с добавлением `...`, если он длиннее; каждому элементу присваивается индекс, начиная с нуля.
6. Рекурсивно обходит дерево разобранного документа и выводит количество вхождений каждого уникального имени тега элемента. Имена тегов выводятся в порядке первого обнаружения при обходе в глубину.
7. Если найден хотя бы один `<body>`, выводит текст первого элемента body. Отображаемый текст обрезается по краям и усекается до 2 000 байт с добавлением `...`, если он длиннее. Указанное количество символов рассчитывается по исходному тексту body — до обрезки и усечения.

Весь вывод отчёта направляется в стандартный поток вывода. Результаты запросов и обход документа соответствуют поведению внутреннего пакета DOM.

## Публичный API

Это исполняемый файл `package main`; он не экспортирует библиотечный API. Точка входа — неэкспортируемая функция `main()`, вызываемая командой `go run ./cmd/analyze_habr` или при сборке и запуске исполняемого файла команды.

## Типы и зависимости

Команда не определяет собственных типов. Она использует:

- `internal/fetcher.Fetch` для загрузки страницы.
- `internal/dom.Parse` для создания представления документа.
- Поля `dom.Node` `Type`, `TagName` и `Children` для рекурсивного подсчёта элементов.
- `Node.QueryAll`, `Node.GetAttr` и `Node.TextContent` для поиска в документе и извлечения содержимого.

## Детали реализации и ограничения

- URL страницы задан в коде; параметры командной строки и переменные окружения не поддерживаются.
- Рекурсивный обходчик учитывает каждый узел типа `dom.ElementNode`, включая вложенные элементы.
- В map `tags` хранятся количества, а `allTags` отдельно сохраняет порядок первого появления для детерминированной сортировки отчёта относительно дерева разбора.
- Усечение выполняется по длине строк Go в байтах и срезами байтов, а не по границам рун Unicode. Поэтому при обрезке многобайтовый символ UTF-8 может быть разделён.
- Ошибки разбора и операций вывода эта команда явно не обрабатывает.
