# `cmd/test_real`

`cmd/test_real` — автономный исполняемый файл Go, который проверяет конвейер обработки реальных страниц проекта на двух URL, заданных непосредственно в коде. Для каждой страницы он загружает HTML, разбирает его и выполняет обработку JavaScript, связанную с DOM, вычисляет стили и компоновку, отрисовывает буфер кадра, преобразует его в строки ASCII и выводит в стандартный поток вывода сводку по времени и результатам.

## Поведение команды

Исполняемый файл последовательно обрабатывает следующие URL:

- `https://en.wikipedia.org/wiki/ASCII_art`
- `https://news.ycombinator.com`

Для каждого URL выполняются следующие действия:

1. Запускается таймер и вызывается `fetcher.Fetch`.
2. При ошибке загрузки выводится `[URL] FETCH ERROR: error`, после чего обработка продолжается со следующим URL. Для этой страницы дальнейшие действия не выполняются.
3. Фиксируется время загрузки, а HTML разбирается с помощью `dom.Parse`.
4. Создаётся контекст JavaScript, инициализируется его интеграция с DOM, регистрируются функции-мосты, вычисляется скрипт API DOM и выполняются скрипты из документа с URL в качестве контекста.
5. Контекст JavaScript закрывается, после чего итоговый DOM извлекается с помощью `js.GetFinalDOM`.
6. Вычисляются стили CSS, строится компоновка шириной 800, выполняется отрисовка шириной 800, а результат преобразуется в строки ASCII.
7. Выводятся URL, размер HTML в байтах, время загрузки, разбора и всего процесса, а также общее число строк и число непустых строк. Затем выводятся до первых 20 непустых строк с их индексами, нумерация которых начинается с нуля.

Время разбора измеряется от исходного момента запуска таймера, поэтому включает и загрузку, и разбор. Общее время также измеряется от этого момента и охватывает весь конвейер вплоть до преобразования в ASCII и подсчёта непустых строк. Пример строк выводится уже после фиксации общего времени.

## Публичный API

Пакет не объявляет экспортируемого библиотечного API. Это пакет `main`, предназначенный для запуска в качестве команды; его точка входа — неэкспортируемая функция `main`.

## Сведения о выводе

- Размер HTML определяется с помощью `len(html)` и указывается в байтах.
- Строка считается непустой, если `strings.TrimSpace(line)` возвращает непустую строку.
- У выводимых строк-примеров удаляются завершающие пробелы с помощью `strings.TrimRight(line, " ")`; начальные пробелы сохраняются.
- Для каждой успешно обработанной страницы выводится не более 20 непустых строк.
- Ошибки загрузки выводятся, но не мешают обработке второго URL.

## Примечания по реализации

Конвейер непосредственно собран в `main`; этот файл не предоставляет настроек или флагов командной строки. Список страниц и ширина отрисовки заданы в исходном коде. Контекст JavaScript закрывается до получения итогового DOM, что соответствует текущему жизненному циклу интеграции. Ошибки загрузки обрабатываются явно; последующие функции обработки в этом файле вызываются без локальной обработки ошибок.
