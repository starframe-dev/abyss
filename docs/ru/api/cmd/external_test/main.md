# `cmd/external_test`

## Назначение

Этот исполняемый файл служит ручным сквозным тестом для загрузки и отображения страницы, использующей внешний JavaScript. Он получает фиксированный локальный URL HTML-страницы, разбирает документ, инициализирует мост JavaScript/DOM, выполняет скрипты, вычисляет стили и компоновку, отображает результат в виде ASCII-представления и выводит строки в стандартный поток вывода.

## Публичный API

Пакет называется `main` и не предоставляет библиотечного API. Он предназначен для запуска в качестве исполняемого файла. Константы и переменная уровня пакета не экспортируются и являются деталями реализации:

| Имя | Вид | Значение / назначение |
| --- | --- | --- |
| `viewportWidth` | константа | Ширина области просмотра для отображения — 800 единиц. |
| `defaultClientTimeout` | константа | Длительность 10 секунд; объявлена, но в этом файле не используется. |
| `defaultClient` | переменная | Псевдоним `fetcher.DefaultClient`; объявлен, но в этом файле не используется. |

## Поведение во время выполнения

`main` выполняет следующие шаги по порядку:

1. Получает `http://localhost:9999/test_external_js.html` с помощью `fetcher.Fetch`.
2. При ошибке получения выводит `Fetch error: <error>` в стандартный поток ошибок и завершает работу со статусом 1.
3. Разбирает байты ответа в DOM с помощью `dom.Parse`.
4. Создаёт контекст JavaScript и откладывает вызов `Close` для освобождения ресурсов при штатном возврате.
5. Регистрирует функции моста. При ошибке выводит `Bridge init error: <error>` и завершает процесс со статусом 1.
6. Инициализирует привязку JavaScript DOM с помощью `js.InitDOM` и выполняет скрипт API DOM. Ошибки выполнения выводятся как `DOM API error: <error>` и приводят к завершению процесса.
7. Выполняет скрипты документа, используя исходный URL в качестве базового URL скрипта. Ошибки выводятся как `Script error: <error>` и приводят к завершению процесса.
8. Получает итоговый DOM после выполнения скриптов, вычисляет CSS, строит компоновку для области просмотра шириной 800 единиц, отображает кадровый буфер и преобразует его в строки ASCII.
9. Выводит каждую строку результата в стандартный поток вывода, а затем — строку-маркер `=== END ===`.

## Подробности реализации

- Целевой URL и ширина области просмотра заданы непосредственно в исходном коде; команда не принимает аргументы командной строки или настройки окружения.
- Конвейер работает синхронно. Каждый этап использует результат предыдущего, а обработка прекращается при первой обнаруженной ошибке.
- Для получения данных используется `fetcher.Fetch`; локальный псевдоним `defaultClient` и константа тайм-аута не настраивают этот вызов в текущей реализации.
- Исполняемый файл зависит от внутренних пакетов `ascii`, `css`, `dom`, `fetcher`, `js`, `layout` и `render`.
- При успешном выполнении выводится ASCII-представление, за которым следует `=== END ===`. Диагностические ошибки направляются в стандартный поток ошибок, а отображённый результат — в стандартный поток вывода.
