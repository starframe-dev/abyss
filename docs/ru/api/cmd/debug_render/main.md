# `cmd/debug_render`

`cmd/debug_render` — это отдельная диагностическая программа, которая загружает фиксированную веб-страницу, пропускает её через конвейер Abyss для разбора, выполнения JavaScript, применения стилей, компоновки и отрисовки, затем записывает текстовый результат во временные файлы и выводит сводку в стандартный вывод.

## Поведение

Программа обрабатывает `https://example.com` в следующем порядке:

1. Загружает страницу с помощью `fetcher.Fetch`. При ошибке загрузки сообщение выводится в стандартный поток ошибок, после чего программа завершается с кодом 1.
2. Разбирает ответ с помощью `dom.Parse`.
3. Создаёт контекст JavaScript, настраивает его закрытие при возврате, инициализирует мост DOM, регистрирует функции моста и выполняет скрипт API DOM. При ошибках регистрации моста или выполнения API DOM сообщение выводится в стандартный поток ошибок, после чего программа завершается с кодом 1.
4. Выполняет скрипты страницы. Ошибка выполнения скрипта выводится в стандартный поток вывода, но не останавливает оставшуюся часть конвейера.
5. Считывает итоговый DOM, вычисляет стили CSS, строит компоновку шириной 800, отрисовывает буфер кадра шириной 800 и преобразует его в строки ASCII.
6. Записывает все строки, соединённые символами новой строки, в `/tmp/abyss_full_ansi.txt`. Также создаёт упрощённую версию в `/tmp/abyss_short_ansi.txt`: ANSI escape-последовательности удаляются, каждая строка обрезается до 120 байт, а конечные пробелы удаляются.
7. Выводит пути к файлам, подсчитывает непустые сокращённые строки и печатает каждую такую строку с её индексом, отсчитываемым от нуля.

Оба файла создаются с режимом `0644`. Ошибки записи `os.WriteFile` игнорируются, поэтому сообщение об успехе не гарантирует, что файлы действительно были записаны.

## Публичный API

Это пакет `main`, не предоставляющий публичного API уровня пакета для импорта. При запуске исполняемого файла вызывается `main`; аргументы командной строки не принимаются, URL, ширина отрисовки и пути вывода заданы в коде.

### `stripANSI`

```go
func stripANSI(s string) string
```

Удаляет распознаваемые последовательности ANSI SGR вида ESC `[` с последующими цифрами и/или точками с запятой и завершающей `m`. Прочие escape-последовательности пропускаются в ходе побайтового сканирования функции; это вспомогательная функция для вывода рендерера, а не универсальный разборщик escape-последовательностей терминала. Функция не экспортируется.

## Примечания по реализации

- После создания контекст JavaScript закрывается с помощью `defer`. Вызовы `os.Exit` обходят отложенные вызовы, поэтому при раннем аварийном завершении очистка не выполняется.
- При усечении строк используется длина и срез Go по байтам (`len` и `clean[:120]`), а не по рунам Unicode. Поэтому не-ASCII текст может быть обрезан посреди символа в кодировке UTF-8.
- Полный вывод сохраняет ANSI-стили, а из сокращённого вывода перед усечением удаляются распознанные последовательности стилей.
- Ошибки выполнения скриптов не являются фатальными, в отличие от ошибок загрузки, регистрации моста и выполнения API DOM.
