# `cmd/cuetty_test`

`cmd/cuetty_test` — это автономная программа для ручного интеграционного тестирования, позволяющая проверять терминальное приложение через API `github.com/starframe-dev/cue-tty/pkg/cue`. Она запускает `./bin/abyss`, управляет его страницей так, словно с ней взаимодействует пользователь, и выводит как отрисованные строки терминала, так и удобное для чтения представление перехваченного необработанного вывода.

## Публичный API

Этот каталог содержит пакет `main` и не предоставляет повторно используемого экспортируемого API. Точка входа — `main()`.

## Ход выполнения

1. Запустить `./bin/abyss` в терминале размером 200 столбцов на 60 строк, используя текущий каталог в качестве рабочего и `TERM=xterm-256color`.
2. Если запуск не удался, вывести `Launch error: <error>` в стандартный вывод и завершить работу. При успешном запуске отложить вызов `app.Close()`, чтобы закрыть приложение при возврате из `main`.
3. Получить страницу приложения и подождать одну секунду, пока оно запустится.
4. Ввести `example.com`, подождать 200 миллисекунд и нажать Enter.
5. Подождать пять секунд, пока загрузится страница, затем получить и вывести её строки.
6. Получить необработанный журнал приложения и вывести не более последних 2 000 байт в экранированном, удобном для чтения виде.
7. Нажать `q` и подождать 200 миллисекунд перед завершением; после этого выполнится отложенный вызов закрытия.

## Подробности вывода

### Строки страницы

Программа выводит заголовок с количеством полученных строк и заданными размерами терминала. Перед каждой строкой указывается её индекс шириной в два символа, дополненный пробелом. Перед выводом удаляются завершающие пробелы ASCII. Если после этого строка пуста, выводится `(empty)`; в остальных случаях строка выводится с форматированием Go `%q`, которое заключает её в кавычки и экранирует специальные символы.

Ошибка, возвращаемая `page.Lines()`, в этой тестовой программе намеренно игнорируется. Поэтому ошибка получения строк не сообщается явно, а полученные строки всё равно обрабатываются.

### Необработанный журнал

Раздел с необработанным журналом ограничен последними 2 000 байтами (или всем журналом, если он короче). Байты отображаются следующим образом:

- ESC записывается как `\\033`.
- Перевод строки записывается как `\\n`, за которым следует настоящий перенос строки.
- Возврат каретки пропускается.
- Печатные байты ASCII (от 32 до 126) выводятся напрямую.
- Все остальные байты записываются в виде шестнадцатеричных escape-последовательностей из двух строчных цифр, например `\\x1b`.

Журнал обрезается по индексам байтов, а не символов Unicode, поэтому отображаемый фрагмент может начинаться с середины многобайтной последовательности. Реализация предполагает, что `app.RawLog()` возвращает срез байтов, пригодный для использования с `len` и индексацией.

## Предположения и ограничения во время выполнения

Программа предполагает, что `./bin/abyss` существует относительно рабочего каталога и может быть запущен пакетом cue-tty. Последовательность взаимодействия основана на фиксированных паузах, а не на проверках готовности, поэтому различия во времени запуска или загрузки страницы могут повлиять на результат. Это исполняемый диагностический пример, а не автоматизированный тест с проверками: он выводит наблюдения, но не сравнивает их с ожидаемым результатом и не возвращает код ошибки при несовпадении содержимого страницы.
